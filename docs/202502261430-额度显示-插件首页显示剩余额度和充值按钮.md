# 插件首页显示剩余额度和充值按钮

## 修改日期
2025-02-26 14:30

## 问题描述
用户需要在插件首页看到自己的剩余额度，并能够快速跳转到充值页面。

## 解决方案

### 1. 后端API支持
后端已经实现了 `/api/user/quota` API，返回详细的额度信息：
- `total_remaining`: 总剩余额度
- `free_remaining`: 免费剩余额度
- `paid_remaining`: 付费剩余额度
- `free_limit`: 免费总额度
- `free_used`: 已使用免费额度
- `is_anonymous`: 是否匿名用户

### 2. 插件前端修改

#### 文件：`src/components/Home.tsx`

**添加状态管理：**
```typescript
// 额度信息状态
const [quota, setQuota] = useState<{
  total_remaining: number;
  free_remaining: number;
  paid_remaining: number;
} | null>(null);
```

**在 useEffect 中加载额度信息：**
```typescript
// 加载用户额度信息
const loadQuota = async () => {
  try {
    const settings = await getSettings();
    const backendUrl = settings.sync?.backendUrl || 'https://memoraid.dpdns.org';
    const token = settings.sync?.token;
    const anonymousId = settings.anonymousId;
    
    // 构建请求头
    const headers: Record<string, string> = {
      'Content-Type': 'application/json'
    };
    
    // 优先使用 token，如果没有则使用匿名 ID
    if (token) {
      headers['Authorization'] = `Bearer ${token}`;
    } else if (anonymousId) {
      headers['X-Anonymous-ID'] = anonymousId;
    }
    
    const response = await fetch(`${backendUrl}/api/user/quota`, {
      method: 'GET',
      headers
    });
    
    if (response.ok) {
      const data = await response.json();
      setQuota(data);
    }
  } catch (error) {
    console.error('Failed to load quota:', error);
  }
};
loadQuota();
```

**在首页顶部显示额度信息：**
```typescript
{/* 额度显示和充值按钮 */}
{quota !== null && (
  <div className="w-full px-4 mb-2">
    <div className={`border rounded-lg px-4 py-3 text-sm flex items-center justify-between ${
      quota.total_remaining <= 0 
        ? 'bg-red-50 border-red-200'  // 额度用完：红色警告
        : quota.total_remaining <= 5 
        ? 'bg-yellow-50 border-yellow-200'  // 额度不足：黄色提醒
        : 'bg-blue-50 border-blue-200'  // 额度充足：蓝色正常
    }`}>
      <div className="flex flex-col items-start">
        <span className={`font-medium ${
          quota.total_remaining <= 0 
            ? 'text-red-700' 
            : quota.total_remaining <= 5 
            ? 'text-yellow-700' 
            : 'text-blue-700'
        }`}>
          剩余额度: {quota.total_remaining} 次
        </span>
        <span className="text-xs text-gray-500 mt-1">
          免费: {quota.free_remaining} | 付费: {quota.paid_remaining}
        </span>
      </div>
      <button
        onClick={() => window.open('https://memoraid.dpdns.org/user', '_blank')}
        className="bg-gradient-to-r from-blue-500 to-purple-600 text-white px-4 py-2 rounded-lg text-xs font-medium hover:from-blue-600 hover:to-purple-700 transition shadow-sm"
      >
        充值
      </button>
    </div>
  </div>
)}
```

## 功能特点

1. **智能颜色提示**
   - 额度充足（>5次）：蓝色背景
   - 额度不足（≤5次）：黄色背景
   - 额度用完（0次）：红色背景

2. **详细额度信息**
   - 显示总剩余额度
   - 分别显示免费和付费额度

3. **一键充值**
   - 点击充值按钮直接跳转到充值页面
   - 使用渐变色按钮，视觉效果更好

4. **身份识别**
   - 优先使用登录用户的 token
   - 未登录用户使用匿名 ID
