# 工单系统 - 添加用户反馈和管理员回复功能

## 修改时间
2026-03-24 00:50

## 功能概述
新增完整的工单系统，用户可以在用户中心创建工单反馈问题，管理员可以在后台查看和回复工单。

## 主要功能

### 1. 数据库设计
创建了两张表：
- `tickets`: 工单主表，存储工单基本信息
- `ticket_messages`: 工单消息表，存储工单的所有消息记录

字段说明：
- tickets表：id, user_id, subject（主题）, status（状态：open/replied/closed）, created_at, updated_at
- ticket_messages表：id, ticket_id, user_id, message（消息内容）, is_admin（是否管理员消息）, created_at

### 2. 后端API接口

#### 用户端API
- `POST /api/tickets` - 创建新工单
- `GET /api/tickets` - 获取用户的工单列表
- `GET /api/tickets/:id` - 获取工单详情和消息
- `POST /api/tickets/:id/messages` - 用户添加工单消息

#### 管理员端API
- `GET /api/admin/tickets` - 获取所有工单列表
- `GET /api/admin/tickets/:id` - 获取工单详情
- `POST /api/admin/tickets/:id/reply` - 管理员回复工单
- `PATCH /api/admin/tickets/:id/status` - 更新工单状态

### 3. 用户中心页面
在用户中心添加"工单反馈"模块：
- 工单列表展示：显示工单编号、主题、状态、消息数、创建时间
- 创建工单：填写主题和详细描述
- 查看工单详情：查看完整的对话记录
- 添加回复：用户可以继续回复工单
- 状态标识：待处理（橙色）、已回复（绿色）、已关闭（灰色）
- 新回复提示：有管理员回复时显示绿色圆点

### 4. 管理员后台页面
改造"用户反馈"模块为工单管理系统：
- 工单列表：显示所有用户的工单，包含用户邮箱
- 状态筛选：可按待处理/已回复/已关闭筛选
- 查看详情：查看完整的对话记录
- 管理员回复：输入回复内容并选择工单状态
- 新消息提示：有新用户消息时显示红色圆点

### 5. 定价页面优化
- 去掉定价页面重复的运营效果展示
- 修改大额度购买提示：从显示邮箱改为"联系客服"链接
- 点击"联系客服"跳转到用户中心的充值页面（#recharge）

## 技术实现

### 前端交互
- 使用模态弹窗展示工单详情
- 消息列表采用聊天界面样式，用户消息靠右，管理员消息靠左
- 实时刷新工单列表和详情
- 支持多行文本输入和换行显示

### 状态管理
- open: 待处理（用户创建工单后的初始状态）
- replied: 已回复（管理员回复后自动更新）
- closed: 已关闭（管理员手动标记）

### 权限控制
- 用户只能查看和操作自己的工单
- 管理员可以查看所有工单并回复
- 使用JWT token进行身份验证

## 使用说明

### 用户使用流程
1. 访问用户中心：https://memoraid.dpdns.org/user#tickets
2. 点击"创建新工单"按钮
3. 填写工单主题和详细描述
4. 提交后可在工单列表查看状态
5. 收到管理员回复后会显示绿色圆点提示
6. 可以继续回复工单进行沟通

### 管理员使用流程
1. 访问管理后台：https://memoraid.dpdns.org/admin#feedback
2. 查看所有用户的工单列表
3. 点击"查看详情"查看完整对话
4. 输入回复内容
5. 选择工单状态（已回复/已关闭）
6. 点击"发送回复"完成回复

## 注意事项
- 工单系统替代了原有的用户反馈功能
- 所有工单消息都会永久保存
- 管理员回复后工单状态自动更新为"已回复"
- 用户可以随时查看历史工单记录
