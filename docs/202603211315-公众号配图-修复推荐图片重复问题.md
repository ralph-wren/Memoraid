# 公众号配图 - 禁用推荐图片强制使用AI生成

## 问题描述

公众号发布文章时，即使随机选择推荐图片，多个图片占位符仍然会插入相同的图片。

从日志可以看出：
- 第1张图片：使用推荐的第1张图片
- 第2张图片：使用推荐的第6张图片
- 但实际插入的图片还是相同的

## 原因分析

问题的根本原因不在于随机选择逻辑，而在于：

1. **推荐图片来源**：微信的推荐图片是基于输入的关键词从图片库中搜索的
2. **图片库限制**：如果关键词相似或者图片库中匹配的图片有限，推荐的图片列表就会重复
3. **相同推荐列表**：每次打开AI配图弹窗时，推荐图片列表本身就是相同的，即使随机选择也无法避免重复

## 解决方案

禁用推荐图片功能，强制使用AI生成新图片：

### 修改1：禁用推荐图片检查

```typescript
// 修改：不再使用推荐图片，强制等待AI生成新图片（避免推荐图片重复）
// 原因：推荐图片是从图片库搜索的，经常重复，AI生成的图片更符合提示词且不重复
logger.log('等待AI生成图片（不使用推荐图片，避免重复）...', 'info');

// 直接开始AI生成流程
logger.log('查找创作按钮...', 'info');
```

### 修改2：移除推荐图片选择逻辑

```typescript
// 直接查找AI生成的图片（不再使用推荐图片）
logger.log('查找AI生成的图片...', 'info');
```

## 优势

1. **避免重复**：AI每次生成的图片都是新的，不会重复
2. **更符合提示词**：AI生成的图片更准确地反映提示词内容
3. **图片多样性**：每篇文章的配图都是独特的

## 劣势

1. **生成时间**：需要等待AI生成图片（约3-5秒）
2. **可能失败**：AI生成可能因为提示词敏感而失败

## 预期效果

修复后，发布公众号文章时：
- 所有图片都使用AI生成，不使用推荐图片
- 每个图片占位符都会生成不同的图片
- 完全避免图片重复问题
