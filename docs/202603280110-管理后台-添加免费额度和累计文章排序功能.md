# 管理后台 - 添加免费额度和累计文章排序功能

## 需求背景

用户希望在管理后台的用户列表中，能够对"免费额度"和"累计文章"两列进行排序，方便查看：
- 哪些用户的免费额度即将用完
- 哪些用户生成的文章最多

## 实现方案

### 1. 前端表头修改

为"免费额度"和"累计文章"添加 `sortable` 类和点击事件：

```html
<!-- 【修改2026-03-28】免费额度支持排序 -->
<th class="sortable" id="sort-free_quota" onclick="toggleSort('free_quota')" title="免费额度：剩余/总额度">免费额度</th>

<!-- 【修改2026-03-28】累计文章支持排序 -->
<th class="sortable" id="sort-total_articles" onclick="toggleSort('total_articles')" title="累计生成的文章总数">累计文章</th>
```

### 2. 后端排序逻辑

#### 累计文章排序

直接使用 `total_articles` 字段排序：

```typescript
if (sort === 'total_articles') sortField = 'total_articles';
```

#### 免费额度排序

由于免费额度是动态计算的（免费上限 - 已使用），需要在SQL中计算：

```typescript
// 免费额度剩余 = 免费上限 - min(文章总数, 免费上限)
// 匿名用户免费上限5，其他用户20
if (sort === 'free_quota') {
  sortField = '(CASE WHEN u.provider = \'anonymous\' THEN 5 ELSE 20 END) - ' +
              '(CASE WHEN total_articles <= (CASE WHEN u.provider = \'anonymous\' THEN 5 ELSE 20 END) ' +
              'THEN total_articles ELSE (CASE WHEN u.provider = \'anonymous\' THEN 5 ELSE 20 END) END)';
}
```

计算逻辑：
1. 确定免费上限：匿名用户5篇，其他用户20篇
2. 计算已使用：min(文章总数, 免费上限)
3. 计算剩余：免费上限 - 已使用

### 3. 排序示例

#### 按免费额度排序（降序）

显示免费额度最多的用户在前：

## 技术细节

### 免费额度排序的SQL表达式

```sql
-- 免费额度剩余 = 免费上限 - min(文章总数, 免费上限)
(CASE WHEN u.provider = 'anonymous' THEN 5 ELSE 20 END) - 
(CASE 
  WHEN total_articles <= (CASE WHEN u.provider = 'anonymous' THEN 5 ELSE 20 END) 
  THEN total_articles 
  ELSE (CASE WHEN u.provider = 'anonymous' THEN 5 ELSE 20 END) 
END)
```

这个表达式确保：
1. 正确识别用户类型（匿名/登录）
2. 计算实际使用的免费额度（不超过上限）
3. 得出剩余的免费额度

### 为什么不直接使用 `user_quotas` 表？

因为我们已经改为动态计算额度，不再维护 `user_quotas` 表的 `free_quota_remaining` 字段。所有额度计算都基于：
- 文章总数（`articles` 表）
- 付费总额度（`payment_orders` 表）
- 用户类型（`users.provider`）

## 注意事项

1. 免费额度排序是动态计算的，性能可能略低于直接字段排序
2. 如果用户数量很大，建议添加索引优化
3. 排序状态会在切换页面时保持
