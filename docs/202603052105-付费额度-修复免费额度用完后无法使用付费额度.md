# 付费额度修复 - 免费额度用完后无法使用付费额度

## 更新时间
2026-03-05 21:05

## 问题描述
用户反馈：免费额度用完（0次）后，即使还有付费额度（937次），系统仍然提示"403 Free limit reached (20 articles)"，无法继续使用。

### 用户界面显示
```
剩余额度: 937 次
免费: 0 | 付费: 937

❌ 403 Free limit reached (20 articles). Please upgrade or contact support.
```

## 问题原因

在 `backend/src/index.ts` 的 `/api/ai/chat/completions` 接口中，额度检查逻辑只检查了免费额度（20篇），没有考虑用户的付费额度：

```typescript
// 原来的逻辑
if (currentUsage >= usageLimit) {
   const message = userId 
     ? `Free limit reached (${usageLimit} articles). Please upgrade or contact support.`
     : `Trial limit reached (${usageLimit} articles). Please login to get 15 more free generations!`;
   return new Response(JSON.stringify({ error: {...} }), { status: 403, headers: corsHeaders });
}
```

这导致：
1. 用户免费额度用完后，即使有付费额度也无法使用
2. 系统直接返回 403 错误，阻止了 AI 调用
3. 付费额度没有被检查和扣除

## 解决方案

### 1. 修改额度检查逻辑

在免费额度用完后，检查用户的付费额度：

```typescript
let hasPaidQuota = false; // 是否有付费额度

if (userId) {
    // 已登录用户：先检查免费额度（限额 20）
    usageLimit = 20;
    trackingId = userId;
    trackingType = 'user';
    currentUsage = await env.DB.prepare(
        'SELECT COUNT(*) as count FROM ai_usage_logs WHERE user_id = ?'
    ).bind(userId).first('count') as number;
    
    // 如果免费额度用完，检查付费额度
    if (currentUsage >= usageLimit) {
        const quotaRow = await env.DB.prepare(
            'SELECT paid_quota_remaining FROM user_quotas WHERE user_id = ?'
        ).bind(userId).first();
        const paidQuota = quotaRow?.paid_quota_remaining || 0;
        
        if (paidQuota > 0) {
            // 有付费额度，允许继续使用
            hasPaidQuota = true;
            console.log(`[AI Chat] 用户 ${userId} 免费额度已用完，使用付费额度（剩余: ${paidQuota}）`);
        }
    }
}

// 只有在免费额度用完且没有付费额度时才拒绝请求
if (currentUsage >= usageLimit && !hasPaidQuota) {
   const message = userId 
     ? `Free limit reached (${usageLimit} articles). Please upgrade or contact support.`
     : `Trial limit reached (${usageLimit} articles). Please login to get 15 more free generations!`;
   return new Response(JSON.stringify({ error: {...} }), { status: 403, headers: corsHeaders });
}
```

### 2. 扣除付费额度

在 AI 调用成功后，如果使用了付费额度，需要扣除：

```typescript
if (aiResponse.ok) {
    // 3. Log Usage (Only if successful)
    try {
        if (trackingType === 'user') {
            // 记录 AI 使用日志
            await env.DB.prepare(
                'INSERT INTO ai_usage_logs (user_id, model) VALUES (?, ?)'
            ).bind(userId, body.model).run();
            
            // 如果使用了付费额度，扣除付费额度
            if (hasPaidQuota) {
                await env.DB.prepare(
                    'UPDATE user_quotas SET paid_quota_remaining = paid_quota_remaining - 1 WHERE user_id = ?'
                ).bind(userId).run();
                console.log(`[AI Chat] 已扣除用户 ${userId} 的付费额度 1 次`);
            }
        } else {
            await env.DB.prepare(
                'INSERT INTO ai_usage_logs (anonymous_id, model) VALUES (?, ?)'
            ).bind(anonymousId, body.model).run();
        }
    } catch (e) {
        console.error('Failed to log AI usage:', e);
    }
}
```

## 额度使用逻辑

### 优先级
1. **免费额度优先**：先使用免费额度（20次）
2. **付费额度备用**：免费额度用完后自动使用付费额度
3. **匿名用户**：只有免费额度（5次），无付费额度

### 扣除规则
- 免费额度未用完：不扣除付费额度，只记录 `ai_usage_logs`
- 免费额度已用完：每次调用扣除 1 次付费额度
- AI 调用失败：不扣除任何额度

### 数据库表
- `ai_usage_logs`: 记录所有 AI 调用（用于统计免费额度使用次数）
- `user_quotas`: 存储用户的付费额度（`paid_quota_remaining` 字段）

## 注意事项
1. 此修复只针对 `/api/ai/chat/completions` 接口（文章生成）
2. 匿名用户不受影响，仍然只有 5 次免费额度
3. 付费额度扣除是实时的，每次 AI 调用成功后立即扣除
4. 如果 AI 调用失败，不会扣除额度
5. 免费额度的统计基于 `ai_usage_logs` 表的记录数，不会被清零
