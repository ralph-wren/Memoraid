# 小红书登录状态保持 - 添加 Cookie 自动监听功能

## 问题描述
用户反馈：明明已经登录了小红书，但 AI 生成的文章一跳转到发布页面就要重新登录。

## 根本原因
检查代码发现，虽然之前修复了 Cookie 设置的逻辑（使用类型断言、分步更新标签页），但是**小红书的 Cookie 没有被自动监听和更新**。

在 `src/background/index.ts` 中，Cookie 自动更新监听器只包含了三个平台：
- 头条（toutiao.com）
- 知乎（zhihu.com）
- 微信公众号（qq.com）

**缺少了小红书（xiaohongshu.com）**，导致：
1. 用户在浏览器中登录小红书后，Cookie 不会自动保存到扩展设置中
2. 扩展跳转到发布页面时，没有有效的 Cookie 可以设置
3. 用户需要重新登录

## 工作原理

### Cookie 自动监听机制
1. **监听 Cookie 变化**：
   - 使用 `chrome.cookies.onChanged` API 监听所有 Cookie 变化
   - 检测 Cookie 的域名，判断是哪个平台

2. **防抖处理**：
   - 使用 2 秒防抖，避免频繁更新
   - 确保所有 Cookie 都已设置完成后再更新

3. **自动保存**：
   - 获取该平台所有有效的 Cookie（未过期、有值）
   - 拼接成字符串格式：`name1=value1; name2=value2; ...`
   - 保存到扩展设置中

4. **自动清除**：
   - 如果检测到没有有效 Cookie（用户退出登录）
   - 自动清空设置中的 Cookie

### 使用流程（修复后）
1. 用户在浏览器中访问小红书创作者平台
2. 用户登录小红书账号
3. **扩展自动监听到 Cookie 变化**（新增功能）
4. **扩展自动保存 Cookie 到设置中**（新增功能）
5. 用户生成文章并发布到小红书
6. 扩展从设置中读取 Cookie 并设置到浏览器
7. 跳转到发布页面时，用户已经是登录状态

## 注意事项

### 1. Cookie 有效期
- Cookie 可能会过期，需要重新登录
- 扩展会自动过滤过期的 Cookie
- 如果所有 Cookie 都过期，会自动清空设置

### 2. 多账号切换
- 如果在浏览器中切换账号，Cookie 会自动更新
- 扩展会使用最新的 Cookie

### 3. 隐私模式
- 隐私模式（无痕模式）的 Cookie 不会被保存
- 需要在正常模式下登录

### 4. 手动配置 Cookie
- 如果自动监听失败，仍然可以手动配置 Cookie
- 在设置页面的"小红书"部分手动填写

   [Cookie Monitor] Updating xiaohongshu cookie (X cookies)
   [Cookie Monitor] xiaohongshu cookie updated successfully

2. **检查扩展设置**：
   - 打开扩展设置页面
   - 查看小红书 Cookie 是否已保存
   - Cookie 格式应该是：`name1=value1; name2=value2; ...`

3. **手动触发更新**：
   - 在小红书页面刷新一次
   - 等待 2 秒
   - 检查设置是否更新

4. **查看 Cookie 详情**：
   - 打开浏览器开发者工具（F12）
   - 切换到 Application > Cookies
   - 查看 `.xiaohongshu.com` 域名下的 Cookie
   - 确认 Cookie 是否存在且未过期

## 技术细节

### Cookie 监听器的优势
1. **自动化**：用户无需手动配置 Cookie
2. **实时更新**：Cookie 变化时自动同步
3. **多平台支持**：统一的监听机制，易于扩展
4. **防抖优化**：避免频繁更新，提高性能

### 为什么之前没有这个功能？
- 小红书是后来添加的平台
- 添加时忘记更新 Cookie 监听器
- 其他三个平台（头条、知乎、微信）都有自动监听

### 与手动设置 Cookie 的区别
- **自动监听**：用户登录后自动保存，无需手动操作
- **手动设置**：需要用户自己复制 Cookie 并粘贴到设置中
- 两种方式都支持，自动监听更方便

## 结论
添加小红书到 Cookie 自动监听器后，用户登录小红书后，Cookie 会自动保存到扩展设置中。跳转到发布页面时，扩展会自动设置 Cookie，用户无需重新登录。

这个修复解决了用户反馈的核心问题：**明明已经登录了小红书，但跳转到发布页面就要重新登录**。
