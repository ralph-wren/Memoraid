# 官网导航栏 - 添加 GitHub 仓库链接和图标

## 功能描述
在官网右上角导航栏添加 GitHub 仓库链接和图标，方便用户访问项目源码。

## 修改内容

### 1. 添加 GitHub 图标 SVG 函数
在 `backend/src/index.ts` 中添加 `renderGithubIconSvg()` 函数，用于渲染 GitHub 图标。

### 2. 修改导航栏 HTML 结构
在 `renderMarketingNav()` 函数中，在 Chrome 按钮之前添加 GitHub 链接按钮：

```html
<a class="btn-github" href="https://github.com/ralph-wren/Memoraid" target="_blank" rel="noreferrer" aria-label="访问 GitHub 仓库（新标签页打开）" title="GitHub 仓库">
  ${githubIcon}
</a>
```

### 3. 添加 GitHub 按钮 CSS 样式
添加 `.btn-github` 样式类，实现简洁的图标按钮效果：

```css
/* GitHub 按钮样式 */
.btn-github{
  display:inline-flex;
  align-items:center;
  justify-content:center;
  width:40px;
  height:40px;
  border-radius:10px;
  background:var(--bg-soft);
  color:var(--text-3);
  text-decoration:none;
  transition:all 0.2s ease;
  border:1px solid var(--border);
}
.btn-github:hover{
  background:var(--bg);
  color:var(--text);
  transform:translateY(-1px);
  box-shadow:0 4px 12px rgba(0,0,0,.08);
}
.btn-github svg{
  width:20px;
  height:20px;
  display:block;
}
```

同时在 `focus-visible` 样式中添加 `.btn-github:focus-visible`，确保键盘导航时有焦点提示。

## 设计说明

### 视觉效果
- 使用 40x40px 的正方形按钮，与导航栏高度协调
- 圆角 10px，与整体设计风格一致
- 图标大小 20x20px，清晰可见
- 使用 `currentColor` 填充图标，自动适配主题颜色

### 交互效果
- 鼠标悬停时：背景色加深，图标颜色变深，按钮轻微上移，添加阴影
- 键盘焦点时：显示蓝色外边框，符合无障碍访问标准
- 点击后在新标签页打开 GitHub 仓库

### 位置布局
GitHub 按钮位于导航栏右侧，在"登录/个人中心"按钮和"免费添加到 Chrome"按钮之间，形成清晰的视觉层次：
```
[Logo] [导航链接...] [登录] [GitHub图标] [Chrome按钮]
```
