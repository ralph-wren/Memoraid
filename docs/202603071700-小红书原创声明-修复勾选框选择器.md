# 小红书原创声明修复 - 修复勾选框选择器

## 问题描述
用户反馈：小红书原创声明弹窗已经打开，但是没有勾选"我已阅读并同意《原创声明须知》"。

## 根本原因
通过浏览器 Console 调试发现，勾选框的 DOM 结构与代码中的选择器不匹配：

### 实际的 DOM 结构
```html
<div class="d-grid d-checkbox d-checkbox-main-label d-clickable bg-red">
  <span class="d-checkbox-simulator --color-bg-white unchecked"></span>
  <span class="d-checkbox-indicator --color-bg-white --color-bg-fill-light-opaque"></span>
  <span class="d-checkbox-label">我已阅读并同意《原创声明须知》...</span>
</div>
```

### 关键发现
1. **可点击的元素**：`.d-checkbox.d-clickable`（整个容器）
2. **状态指示器**：`.d-checkbox-simulator`（显示 `unchecked` 或 `checked`）
3. **视觉指示器**：`.d-checkbox-indicator`（显示勾选框的视觉效果）

### 问题所在
代码中的选择器优先查找：
- `:has-text("我已阅读并同意")`
- `.d-checkbox-indicator`
- `.d-checkbox-simulator`

但这些元素都**不是可点击的**！真正可点击的是 `.d-checkbox.d-clickable` 容器。

## 解决方案

### 修改选择器优先级

在 `SELECTORS.originalityConsentCheckbox` 中，将 `.d-checkbox.d-clickable` 放在最前面：

```typescript
originalityConsentCheckbox: [
    // 修复：应该查找整个 checkbox 容器（可点击的）
    '.d-checkbox.d-clickable',
    '.d-checkbox',
    // 通过文本定位同意项所在行
    ':has-text("我已阅读并同意")',
    ':contains("我已阅读并同意")',
    // 通过 role / input 兜底
    '[role="checkbox"]',
    'input[type="checkbox"]',
    'span.d-checkbox-simulator',
    '.d-checkbox-indicator'
],
```

### 验证方法

在浏览器 Console 中测试：

```javascript
// 找到可点击的 checkbox 容器
const checkbox = document.querySelector('.d-checkbox.d-clickable');
console.log('找到 checkbox:', checkbox);

// 点击它
checkbox.click();
console.log('已点击 checkbox');

// 检查状态
setTimeout(() => {
    const simulator = document.querySelector('.d-checkbox-simulator');
    console.log('点击后的类名:', simulator?.className);
    // 应该从 "unchecked" 变成 "checked"
}, 500);
```

**测试结果**：
- 点击后的类名：`d-checkbox-simulator --color-bg-white checked --color-border-primary`
- 是否已勾选：`true` ✅

## 技术细节

### 为什么之前的选择器不工作？

1. **`.d-checkbox-indicator`**：
   - 这只是一个视觉指示器（显示勾选框的样式）
   - 不是可点击的元素
   - 点击它不会触发状态变化

2. **`.d-checkbox-simulator`**：
   - 这是状态指示器（显示 `unchecked` 或 `checked`）
   - 也不是可点击的元素
   - 点击它也不会触发状态变化

3. **`:has-text("我已阅读并同意")`**：
   - 这会匹配包含文本的元素
   - 但可能匹配到文本节点或标签，而不是容器
   - 不一定是可点击的

### 正确的做法

点击 `.d-checkbox.d-clickable` 容器：
- 这是整个勾选框的容器
- 有 `d-clickable` 类，表示可点击
- 点击它会触发框架的事件处理
- 状态会从 `unchecked` 变成 `checked`

### 类名结构说明

```
d-checkbox                    // 勾选框组件
d-checkbox-main-label         // 主标签样式
d-clickable                   // 可点击标记
bg-red                        // 背景色（红色主题）

d-checkbox-simulator          // 状态模拟器
--color-bg-white              // 背景色（白色）
unchecked / checked           // 状态（未勾选/已勾选）

d-checkbox-indicator          // 视觉指示器
--color-bg-white              // 背景色
--color-bg-fill-light-opaque  // 填充色
```

## 经验总结

### 1. 不要假设选择器
- 不要根据类名猜测哪个元素可点击
- 使用浏览器 Console 实际测试
- 查看元素的事件监听器

### 2. 查找可点击元素的方法
- 查找有 `cursor: pointer` 样式的元素
- 查找有 `onclick` 事件的元素
- 查找有 `d-clickable` 类的元素
- 查找有 `role="button"` 的元素

### 3. 测试点击效果
- 点击前后对比 DOM 变化
- 检查类名变化（如 `unchecked` → `checked`）
- 检查属性变化（如 `disabled` → 可点击）

### 4. 选择器优先级
- 最具体的选择器放在前面
- 通用的选择器放在后面
- 作为兜底方案

## 结论
修复后，代码会优先查找 `.d-checkbox.d-clickable` 容器并点击它，这样就能正确触发勾选框的状态变化，原创声明功能应该可以正常工作了。
