### 4. 定时任务（自动化创作）⭐ 重点功能

**【需要截图：定时任务列表页面】**

定时任务是 Memoraid 的核心功能之一，可以实现 24/7 全自动内容创作，真正解放双手！

#### 什么是定时任务？

定时任务就像一个"自动写作机器人"，你只需要设置好规则，它就会：
1. 在指定时间自动抓取热门话题
2. AI 智能筛选优质素材
3. 自动生成符合平台风格的文章
4. 自动发布到指定平台

![alt text](docs/assets/新人指南-Memoraid使用教程/image-10.png)

#### 如何创建定时任务？

**第一步：进入定时任务页面**
1. 打开 Memoraid 扩展
2. 点击顶部的"定时任务"标签
3. 点击"新建任务"按钮

**第二步：配置任务基本信息**

![alt text](docs/assets/新人指南-Memoraid使用教程/image-11.png)

1. **任务名称**：给任务起个容易识别的名字
   - 示例：`每日科技热点 - 头条号`
   - 示例：`早间新闻 - 知乎专栏`
   - 示例：`生活分享 - 小红书`

2. **新闻源选择**：选择内容来源
   - **今日热榜**（推荐）：聚合 50+ 热门平台的热榜
     - 包括：微博热搜、知乎热榜、B站热门、抖音热点等
     - 支持按分类筛选（科技、娱乐、财经、体育等）
   - **NewsNow API**：国际新闻源（英文内容为主）

**第三步：选择内容分类**


填写 **Node ID**（节点 ID）：

**热门分类的 Node ID 对照表**：

#### 定时任务运行流程

**【需要截图：任务执行流程图或状态显示】**

当定时任务触发时，会自动执行以下步骤：

1. **抓取热门话题**（5-10秒）
   - 从今日热榜获取最新热点
   - 根据 Node ID 筛选对应分类

2. **AI 智能选题**（10-20秒）
   - 分析话题热度和讨论度
   - 根据自定义提示词筛选
   - 选择最适合的话题

3. **生成文章**（20-40秒）
   - 为每个平台生成对应风格的文章
   - 自动适配标题、正文、配图等

4. **自动发布**（10-20秒）
   - 自动跳转到平台发布页面
   - 填充标题、正文、图片等
   - 自动点击发布按钮

5. **任务完成**
   - 记录执行状态（成功/失败）
   - 保存生成的文章到历史记录
   - 等待下一次执行

#### 查看任务状态

**【需要截图：任务列表 - 显示状态】**

在定时任务列表中，可以看到：

- **任务名称**：你设置的任务名
- **执行时间**：下次执行的时间
- **上次执行**：最后一次执行的时间和状态
  - ✅ 成功：绿色标记

  - 🔄 运行中：蓝色标记
- **发布平台**：配置的平台列表
- **开关按钮**：快速启用/禁用任务

- **编辑任务**：点击任务卡片，修改配置
- **删除任务**：点击删除按钮，确认删除
- **启用/禁用**：点击开关，快速控制任务
- **查看日志**：点击"查看详情"，查看执行历史

#### 定时任务最佳实践

**1. 合理安排时间**
- 避开平台流量高峰（如晚上 8-10 点）
- 分散执行时间，避免同时发布多篇
- 考虑目标用户的阅读习惯

**2. 内容分类策略**
- 不同时段发布不同类型的内容
- 早上：新闻资讯、行业动态
- 中午：轻松娱乐、生活分享
- 晚上：深度分析、专业讨论

**3. 平台组合建议**
- 头条 + 知乎：适合新闻热点
- 公众号 + 小红书：适合生活分享
- 知乎 + 公众号：适合深度内容

**4. 监控和优化**
- 定期查看任务执行状态
- 分析哪些话题更受欢迎
- 调整提示词和发布时间
- 关注额度消耗情况

#### 常见问题

**Q1: 定时任务会消耗额度吗？**
A: 是的，每次生成文章都会消耗额度。建议合理设置任务数量和频率。

**Q2: 任务失败了怎么办？**
A: 查看错误信息，常见原因：
- Cookie 过期：重新配置平台 Cookie
- 额度不足：充值或通过推广赚取额度
- 网络问题：稍后重试

**Q3: 可以同时运行多个任务吗？**
A: 可以，但建议不要设置太多任务同时执行，避免额度快速消耗。

**Q4: 如何暂停任务？**
A: 点击任务卡片上的开关按钮，即可快速禁用任务。

**Q5: 任务生成的文章在哪里查看？**
A: 在主界面的"历史记录"中可以查看所有生成的文章。

## 常见问题

### Q1: 免费额度用完了怎么办？

**A**: 有两种方式获取更多额度：

1. **充值**：点击主界面的"充值"按钮，跳转到充值页面
2. **推广赚钱**：点击"💰 推广赚钱"按钮，邀请好友使用，赚取收益

### Q2: 为什么点击发布按钮没反应？

**A**: 可能的原因：

1. **未配置 Cookie**：需要先在设置中配置平台 Cookie
2. **Cookie 过期**：重新抓取或手动更新 Cookie
3. **未登录平台**：先在浏览器中登录对应平台

### Q3: 生成的文章可以修改吗？

**A**: 当然可以！

1. 生成文章后，点击"预览"查看效果
2. 点击"复制"按钮，复制到编辑器中修改
3. 或者使用"继续优化"功能，输入修改要求，AI 会重新生成

### Q4: 如何提高文章原创性？

**A**: Memoraid 已经内置了多项原创性增强机制：

- 深度改写，不直接复述原文
- 增加个人分析和解读
- 提供新的观察角度
- 去除平台痕迹
- 语言表达个性化

### Q5: 支持哪些 AI 模型？

**A**: 在设置中可以选择：

- OpenAI（GPT-3.5、GPT-4）
- Claude（Sonnet、Opus）
- Gemini
- DeepSeek
- 其他兼容 OpenAI API 的模型

### Q6: 如何导出文章到 GitHub？

**A**: 

1. 在设置中配置 GitHub Token 和仓库
2. 生成文章后，点击"保存"按钮
3. 选择目录和文件名
4. 点击"Push to GitHub"

### Q7: 定时任务会消耗额度吗？

**A**: 是的，定时任务生成文章会消耗额度。建议：

- 合理设置任务数量和频率
- 定期查看额度余额
- 及时充值或通过推广赚取额度

### Q8: 如何反馈问题或建议？

**A**: 

1. 点击主界面右上角的"反馈"图标
2. 选择反馈类型（体验反馈/功能建议/Bug 报告）
3. 填写反馈内容
4. 提交后可以在反馈列表中查看回复

## 💡 使用技巧

### 技巧 1：批量生成文章

如果你有多个网页需要转成文章：

1. 打开第一个网页，生成文章
2. 不要关闭扩展窗口
3. 切换到下一个标签页
4. 再次点击生成按钮

### 技巧 2：利用历史记录

主界面下方的"历史记录"保存了所有生成的文章：

- 点击任意历史记录，快速查看
- 可以重新发布到其他平台
- 支持导出和删除

### 技巧 3：组合使用定时任务

创建多个定时任务，覆盖不同时间段和平台：

- 早上 9:00 发布头条（科技新闻）
- 下午 3:00 发布知乎（深度分析）
- 晚上 9:00 发布小红书（生活分享）

### 技巧 4：善用自定义提示词

针对不同主题，使用不同的提示词：

- 科技类：`请用专业但不晦涩的语言，多用数据和案例`

- 搞笑类：`请用幽默风趣的语言，多用网络梗和段子`
