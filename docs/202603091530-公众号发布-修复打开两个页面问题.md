# 公众号发布 - 修复打开两个页面问题

## 问题描述
公众号发表文章时会打开两个发布页面：一个首页 + 一个编辑页面。

## 问题原因

### 原有流程
1. Background script (`handlePublishToWeixin`) 查找已有的微信页面标签页
2. 如果找到首页标签页，会 reload 这个页面
3. Content script 在页面加载后自动执行 `autoFillContent()`
4. `autoFillContent()` 检测到在首页，调用 `clickArticleButton()` 点击"文章"按钮
5. 点击"文章"按钮会打开一个新的编辑页面
6. 结果：原来的首页 + 新打开的编辑页面 = 两个页面

### 根本原因
Background script 和 Content script 之间的协作问题：
- Background 打开/激活了首页
- Content script 检测到首页后自动点击按钮打开编辑页
- 导致同时存在两个页面

## 解决方案

### 修改位置
文件：`src/background/index.ts`
函数：`handlePublishToWeixin`

### 修改内容
不再让 Content script 去点击"文章"按钮，而是直接在 Background script 中导航到编辑器页面URL。

```typescript
// 编辑器页面URL（直接进入新建文章页面，避免content script点击按钮打开新页面）
const editorUrl = 'https://mp.weixin.qq.com/cgi-bin/appmsg?t=media/appmsg_edit_v2&action=edit&isNew=1&type=10&createType=0&token=&lang=zh_CN';
```

### 修改逻辑


1. **找到编辑器页面** - 复用并reload（保持原逻辑）
2. **找到其他微信页面（如首页）** - 直接导航到编辑器URL（修改点）
3. **没有微信页面** - 直接创建编辑器页面（修改点）

```typescript
if (editorTabs.length > 0) {
  // 找到编辑器页面，复用它
  tab = editorTabs[0];
  await chrome.tabs.update(tab.id!, { active: true });
  await chrome.tabs.reload(tab.id!);
} else if (allTabs.length > 0) {
  // 如果已有其他微信页面（如首页），直接导航到编辑器页面
  // 这样可以避免content script检测到首页后点击"文章"按钮打开新页面
  tab = allTabs[0];
  await chrome.tabs.update(tab.id!, { active: true, url: editorUrl });
} else {
  // 否则创建新标签页，直接打开编辑器页面
  tab = await chrome.tabs.create({
    url: editorUrl,
    active: true
  });
}
```

## 效果
- 不再打开两个页面
- 直接进入编辑器页面，Content script 自动填充内容
- 用户体验更流畅

## 测试验证
执行 `npm run build` 构建成功，无报错。
