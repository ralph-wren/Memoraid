# 额度提示：未登录用户额度用完提示登录

## 修改日期
2026-03-12 14:45

## 功能描述
当未登录用户的免费额度用完后，在插件首页显示醒目的提示信息，引导用户登录账号以获取更多免费额度。

## 需求背景
- 未登录用户只有有限的免费额度（默认5次）
- 额度用完后，用户可能不知道如何获取更多额度
- 登录用户可以获得额外的免费额度奖励
- 需要友好的提示引导用户完成登录

## 实现方案

### 判断逻辑
1. 检查用户是否已登录（通过 `settings.sync?.token` 判断）
2. 检查免费额度和付费额度是否都为0
3. 同时满足以上两个条件时，显示登录提示

### 提示内容
- 标题：免费额度已用完
- 说明：登录账号即可获赠更多免费额度，继续创作精彩内容！
- 按钮：立即登录领取

## 修改内容

### 前端修改（src/components/Home.tsx）

#### 1. 添加登录状态管理
```typescript
// 用户登录状态
const [isLoggedIn, setIsLoggedIn] = useState<boolean>(false);

// 加载语言设置和额度信息
useEffect(() => {
  const loadLanguage = async () => {
    const settings = await getSettings();
    setT(getTranslation(settings.language || 'zh-CN'));
    // 检查用户是否已登录（有token表示已登录）
    setIsLoggedIn(!!settings.sync?.token);
  };
  loadLanguage();
  
  // 首次加载额度信息
  loadQuota();
}, []);
```

**说明**：
- 添加 `isLoggedIn` 状态，用于判断用户是否已登录
- 在加载设置时，检查 `settings.sync?.token` 是否存在
- 有 token 表示已登录，没有 token 表示未登录（匿名用户）

## 用户体验

### 显示时机
- 未登录用户首次打开插件：不显示（有免费额度）
- 使用完免费额度后：立即显示提示
- 登录后：提示消失（即使额度为0，也可以充值）

### 交互流程
1. 用户看到"免费额度已用完"提示
2. 点击"立即登录领取"按钮
3. 跳转到用户中心页面
4. 完成登录后，获得额外免费额度
5. 返回插件，可以继续使用

## 技术细节

### 登录判断
- 使用 `settings.sync?.token` 判断是否登录
- 有 token：已登录用户
- 无 token：未登录用户（使用匿名ID）

### 额度判断
- `quota.free_remaining === 0`：免费额度用完
- `quota.paid_remaining === 0`：付费额度用完
- 两者都为0时，才显示提示

### 响应式设计
- 提示框宽度自适应（`w-full`）
- 内边距适中（`px-4 py-3`）
- 文字大小合理（`text-sm`, `text-xs`）
