# 提示词优化：禁止透露内容来源

## 修改日期
2026-03-09

## 问题描述
AI生成的文章中会出现"微博网友评论说"、"Reddit用户表示"等透露内容来源的表述，这会影响平台的原创识别算法，导致文章被判定为非原创内容。

## 解决方案
在 `src/utils/prompts.ts` 文件中强化了关于内容来源的限制规则：

### 1. 在通用提示词的"语气"部分添加了严格限制
```
❌❌❌ CRITICAL：严禁透露内容来源（非常重要，影响平台原创识别）：
- 禁止提及"微博"、"微博网友"、"微博评论"、"微博上"
- 禁止提及"Reddit"、"贴吧"、"知乎"、"豆瓣"、"论坛"等任何平台名称
- 禁止说"根据XX平台"、"来自XX网站"、"XX上看到"
- 禁止说"某网友在XX评论说"、"XX平台用户表示"
- ✅ 正确做法：直接把观点当作你自己的分析，或者用"有人说"、"网友评论"这种不指明来源的表述
```

### 2. 强化了引用评论的规则
```
### 4.3 引用评论时的特殊规则（CRITICAL - 影响原创识别）
- ❌❌❌ 严禁透露评论来源平台：
  - 禁止说"微博网友评论说"、"微博评论区"、"微博上有人说"
  - 禁止说"Reddit用户表示"、"贴吧网友认为"、"知乎评论"
  - 禁止说"XX平台评论区"、"XX网站用户"
- ✅ 正确的引用方式：
  - 格式："有人评论说：'...'"
  - 格式："看到一条评论：'...'"
  - 格式："网友评论：'...'"
  - 格式："评论区有人说：'...'"（不指明是哪个平台的评论区）
- ⚠️ 重要：这条规则非常关键，会直接影响平台的原创识别算法
```

## 修改文件
- `src/utils/prompts.ts`

## 影响范围
- 所有平台的文章生成（头条、知乎、微信公众号、小红书）
- 通用文章生成提示词
- 平台专属提示词（继承通用规则）

## 测试建议
1. 生成文章后检查是否还有"微博"、"Reddit"等平台名称
2. 检查评论引用是否使用了正确的格式
3. 确认文章观点是否以第一人称表达，而不是转述

## 注意事项
- 这个修改非常重要，直接影响平台的原创识别
- 所有观点应该直接表达为作者自己的分析，而不是转述他人观点
- 引用评论时只能用"网友评论"、"有人说"等不指明来源的表述
