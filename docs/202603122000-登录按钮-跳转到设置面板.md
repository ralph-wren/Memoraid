# 登录按钮 - 修改跳转行为到设置面板

## 修改内容

将"立即登录领取"按钮的行为从打开外部网页改为打开插件内的设置面板。

## 修改原因

用户反馈希望点击"立即登录领取"按钮后,能够在插件内选择登录方式(Google或GitHub),而不是直接跳转到外部网页。

## 修改位置

**文件:** `src/components/Home.tsx`

**修改前:**
```typescript
<button
  onClick={() => window.open('https://memoraid.dpdns.org/user', '_blank')}
  className="bg-gradient-to-r from-orange-500 to-yellow-500 text-white px-3 py-1.5 rounded text-xs font-medium hover:from-orange-600 hover:to-yellow-600 transition shadow-sm"
>
  立即登录领取
</button>
```

**修改后:**
```typescript
<button
  onClick={() => onOpenSettings()}
  className="bg-gradient-to-r from-orange-500 to-yellow-500 text-white px-3 py-1.5 rounded text-xs font-medium hover:from-orange-600 hover:to-yellow-600 transition shadow-sm"
>
  立即登录领取
</button>
```

## 功能说明

### 触发条件
当满足以下条件时,会显示"免费额度已用完"提示框和"立即登录领取"按钮:
1. 用户未登录 (`!isLoggedIn`)
2. 额度信息已加载 (`quota !== null && quota !== undefined`)
3. 免费额度为0 (`quota.free_remaining === 0`)
4. 付费额度为0 (`quota.paid_remaining === 0`)

### 点击行为
- **修改前:** 在新标签页打开 `https://memoraid.dpdns.org/user` 网页
- **修改后:** 调用 `onOpenSettings()` 函数,打开插件的设置面板

### 用户体验改进
1. **更流畅的操作流程:** 用户无需离开插件即可完成登录
2. **更清晰的选择:** 在设置面板中可以看到Google和GitHub两种登录方式
3. **减少跳转:** 避免在浏览器标签页之间来回切换
