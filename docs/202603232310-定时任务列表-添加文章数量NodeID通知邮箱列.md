# 定时任务列表 - 添加文章数量、Node ID、通知邮箱列

## 功能描述
在用户中心页面（https://memoraid.dpdns.org/user#tasks）的定时任务列表表格中，添加三个新列：文章数量、Node ID、通知邮箱，方便用户快速查看任务配置。

## 修改内容

### 新增列
在定时任务表格中添加以下列：

| 列名 | 说明 | 示例 | 备注 |
|------|------|------|------|
| 文章数量 | 每次执行生成的文章数量 | 2 篇 | 从 `task.articleCount` 获取，默认1 |
| Node ID | 今日热榜的节点ID | 3QeLwJEd7k | 从 `task.tophubNodeId` 获取，超过10字符截断显示 |
| 通知邮箱 | 任务完成后的通知邮箱 | iuyuger@gmail.com | 从 `task.notificationEmail` 获取，超过20字符截断显示 |

### 表格结构（修改后）
| 任务名称 | 状态 | 目标平台 | 执行周期 | 文章数量 | Node ID | 通知邮箱 | 上次执行 | 操作 |
|---------|------|---------|---------|---------|---------|---------|---------|------|
| 公众号 | 运行中 | 公众号 | 每天 09:00 | 3 篇 | Jb0vmloB1G | iuyuger@gm... | 2026-03-23 22:30 ✅ | 📋 记录 |

### 实现细节

#### 1. 文章数量显示
```javascript
const articleCount = task.articleCount || 1;
// 显示：2 篇
```

#### 2. Node ID显示（截断+悬停提示）
```javascript
const nodeId = task.tophubNodeId || '-';
const nodeIdDisplay = nodeId.length > 10 ? nodeId.substring(0, 10) + '...' : nodeId;
// HTML: <span title="完整NodeID">截断显示</span>
```

#### 3. 通知邮箱显示（截断+悬停提示）
```javascript
const email = task.notificationEmail || '-';
const emailDisplay = email.length > 20 ? email.substring(0, 20) + '...' : email;
// HTML: <span title="完整邮箱">截断显示</span>
```

## 用户体验优化

### 截断显示
- Node ID 超过10个字符时截断，显示前10个字符 + "..."
- 通知邮箱超过20个字符时截断，显示前20个字符 + "..."
- 鼠标悬停时显示完整内容（通过 `title` 属性）

### 空值处理
- 如果字段为空，显示 "-"
- 文章数量默认显示 "1 篇"

### 样式
- Node ID 使用等宽字体（`font-family: monospace`）
- 所有新增列使用较小字号（`font-size: 0.85rem`）
- 颜色使用 `var(--text-muted)` 保持一致性

## 代码修改

**文件**: `backend/src/index.ts` - `renderScheduledTasks` 函数

```javascript
// 添加三个新列的数据
const articleCount = task.articleCount || 1;
const nodeId = task.tophubNodeId || '-';
const nodeIdDisplay = nodeId.length > 10 ? nodeId.substring(0, 10) + '...' : nodeId;
const email = task.notificationEmail || '-';
const emailDisplay = email.length > 20 ? email.substring(0, 20) + '...' : email;

// 在表格行中添加新列
'<td><span style="color:var(--text);font-size:0.85rem">' + articleCount + ' 篇</span></td>' +
'<td><span style="color:var(--text-muted);font-size:0.85rem;font-family:monospace" title="' + nodeId + '">' + nodeIdDisplay + '</span></td>' +
'<td><span style="color:var(--text-muted);font-size:0.85rem" title="' + email + '">' + emailDisplay + '</span></td>' +
```
