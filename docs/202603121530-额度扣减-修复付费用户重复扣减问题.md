# 额度扣减：修复付费用户重复扣减问题

## 修改日期
2026-03-12 15:30

## 问题描述
付费用户生成1篇文章，额度被扣减2次：
- 免费额度扣减1次
- 付费额度扣减1次

## 问题原因
AI聊天接口的额度扣减逻辑有问题：
1. 先记录 `ai_usage_logs`（影响免费额度统计）
2. 然后如果有付费额度，再扣除付费额度

这导致有付费额度的用户，每次AI调用都会：
- 记录1次 `ai_usage_logs`（免费额度-1）
- 扣除1次付费额度（付费额度-1）
- 总共扣减2次

## 解决方案
修改AI聊天接口的额度扣减逻辑：
- 如果有付费额度：只扣除付费额度，不记录 `ai_usage_logs`
- 如果没有付费额度：记录 `ai_usage_logs`（使用免费额度）

## 修改内容

### 后端修改（backend/src/index.ts）

#### 修改AI聊天接口的额度扣减逻辑
```typescript
try {
    if (trackingType === 'user') {
        // 如果使用了付费额度，只扣除付费额度，不记录 ai_usage_logs
        if (hasPaidQuota) {
            await env.DB.prepare(
                'UPDATE user_quotas SET paid_quota_remaining = paid_quota_remaining - 1 WHERE user_id = ?'
            ).bind(userId).run();
            console.log(`[AI Chat] 已扣除用户 ${userId} 的付费额度 1 次`);
        } else {
            // 没有付费额度，记录免费额度使用
            await env.DB.prepare(
                'INSERT INTO ai_usage_logs (user_id, model) VALUES (?, ?)'
            ).bind(userId, body.model).run();
        }
    } else {
        // 匿名用户，记录免费额度使用
        await env.DB.prepare(
            'INSERT INTO ai_usage_logs (anonymous_id, model) VALUES (?, ?)'
        ).bind(anonymousId, body.model).run();
    }
} catch (e) {
    console.error('Failed to log AI usage:', e);
}
```

**修改前**：

**说明**：

- 有付费额度：只扣除付费额度，不记录 `ai_usage_logs`
- 没有付费额度：记录 `ai_usage_logs`（使用免费额度）
- 匿名用户：始终记录 `ai_usage_logs`（使用免费额度）

## 技术细节

### 额度扣减策略
1. **付费用户（有付费额度）**：
   - 生成文章：扣除付费额度，不记录 `ai_usage_logs`
   - 发布文章：已在生成时扣除，不再重复扣除
   - 总共：付费额度-1

2. **付费用户（付费额度用完）**：
   - 生成文章：记录 `ai_usage_logs`（使用免费额度）
   - 发布文章：已在生成时记录，不再重复记录
   - 总共：免费额度-1

3. **免费用户/匿名用户**：
   - 生成文章：记录 `ai_usage_logs`（使用免费额度）
   - 发布文章：已在生成时记录，不再重复记录
   - 总共：免费额度-1

### ai_usage_logs 表的作用
- 记录免费额度的使用情况
- 不记录付费额度的使用（付费额度在 `user_quotas` 表中管理）
- 用于统计用户的免费额度消耗

### user_quotas 表的作用
- 记录用户的付费额度余额
- 每次使用付费额度时，直接更新 `paid_quota_remaining` 字段
- 不依赖 `ai_usage_logs` 表
