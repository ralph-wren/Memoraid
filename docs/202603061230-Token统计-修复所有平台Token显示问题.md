# Token统计 - 修复所有平台Token显示问题

## 问题描述

用户发现微信公众号发布文章后,管理后台不显示Token消耗数据。经检查发现头条和小红书也存在相同问题,只有知乎正常显示Token数据。

## 问题原因

1. **Background层面**:
   - `handlePublishToWeixin`、`handlePublishToToutiao`、`handlePublishToXiaohongshu` 函数签名缺少 `tokenUsage` 参数
   - 调用这些函数时没有传递 `tokenUsage` 数据
   - `pending_xxx_publish` 存储对象中没有保存 `tokenUsage`

2. **Content Script层面**:
   - `PublishData` 接口定义缺少 `tokenUsage` 字段
   - 没有读取 `payload.tokenUsage` 并保存到 sessionStorage
   - 上报时没有从 sessionStorage 读取并传递 token 数据

## 修复方案

### 1. Background (src/background/index.ts)

#### 1.1 修改函数签名,添加 tokenUsage 参数

```typescript
// 微信
async function handlePublishToWeixin(payload: { 
  title: string; 
  content: string; 
  sourceUrl?: string; 
  sourceImages?: string[]; 
  generatedId?: string; 
  tokenUsage?: { promptTokens?: number; completionTokens?: number; totalTokens?: number } 
}) {
  // ...
}

// 头条
async function handlePublishToToutiao(payload: { 
  title: string; 
  content: string; 
  sourceUrl?: string; 
  sourceImages?: string[]; 
  generatedId?: string; 
  tokenUsage?: { promptTokens?: number; completionTokens?: number; totalTokens?: number } 
}) {
  // ...
}

// 小红书
async function handlePublishToXiaohongshu(payload: { 
  title: string, 
  content: string, 
  sourceUrl?: string, 
  sourceImages?: string[], 
  generatedId?: string, 
  tokenUsage?: { promptTokens?: number; completionTokens?: number; totalTokens?: number } 
}) {
  // ...
}
```

#### 1.2 在 pending 数据中保存 tokenUsage

```typescript
// 微信
await chrome.storage.local.set({
  pending_weixin_publish: {
    // ... 其他字段
    tokenUsage: payload.tokenUsage // 传递 token 数据
  }
});

// 头条
await chrome.storage.local.set({
  pending_toutiao_publish: {
    // ... 其他字段
    tokenUsage: payload.tokenUsage // 传递 token 数据
  }
});

// 小红书
const publishData = {
  // ... 其他字段
  tokenUsage: payload.tokenUsage // 传递 token 数据
};
```

#### 1.3 调用时传递 tokenUsage

```typescript
// 在 startArticleGenerationAndPublish 中
if (platform === 'toutiao') {
  await handlePublishToToutiao({
    // ... 其他参数
    tokenUsage // 传递 token 数据
  });
} else if (platform === 'weixin') {
  await handlePublishToWeixin({
    // ... 其他参数
    tokenUsage // 传递 token 数据
  });
} else if (platform === 'xiaohongshu') {
  await handlePublishToXiaohongshu({
    // ... 其他参数
    tokenUsage // 传递 token 数据
  });
}
```

### 2. Content Script

#### 2.1 修改 PublishData 接口

```typescript
// src/content/weixin.ts
// src/content/toutiao.ts
// src/content/xiaohongshu.ts
interface PublishData {
  // ... 其他字段
  tokenUsage?: { promptTokens?: number; completionTokens?: number; totalTokens?: number }; // AI token 消耗数据
}
```

#### 2.2 读取并保存 token 数据到 sessionStorage

```typescript
// 保存 token 数据供发布上报使用
if (payload.tokenUsage) {
  sessionStorage.setItem('memoraid_token_usage', JSON.stringify(payload.tokenUsage));
} else {
  sessionStorage.removeItem('memoraid_token_usage');
}
```

#### 2.3 上报时读取并传递 token 数据

```typescript
const reportOnce = (/* ... */) => {
  // ... 其他代码
  
  // 读取 token 数据
  const tokenUsageStr = sessionStorage.getItem('memoraid_token_usage');
  let tokenUsage: { promptTokens?: number; completionTokens?: number; totalTokens?: number } | undefined;
  if (tokenUsageStr) {
    try {
      tokenUsage = JSON.parse(tokenUsageStr);
    } catch (e) {
      console.error('解析 token 数据失败:', e);
    }
  }
  
  // 清除 token 数据
  if (tokenUsageStr) {
    sessionStorage.removeItem('memoraid_token_usage');
  }

  reportArticlePublish({
    platform: 'xxx',
    title: finalTitle,
    url: publishedUrl,
    status: 'published',
    extra: { 
      trigger,
      // 记录 token 消耗数据
      promptTokens: tokenUsage?.promptTokens,
      completionTokens: tokenUsage?.completionTokens,
      totalTokens: tokenUsage?.totalTokens,
    },
    generatedId: sessionStorage.getItem('memoraid_generated_id') || undefined
  });
};
```

## 注意事项

1. Token数据通过 sessionStorage 传递,页面刷新后会丢失
2. 上报成功后会自动清除 sessionStorage 中的 token 数据
3. 如果上报失败,token 数据会保留在 sessionStorage 中,下次上报时会继续使用
