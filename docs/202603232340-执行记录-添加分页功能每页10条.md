# 执行记录添加分页功能

## 需求描述
用户要求：执行记录每页显示10条，支持翻页，按时间倒序排列。

## 实现方案

### 1. 添加分页变量
```javascript
// 执行记录分页变量
let currentTaskId = '';      // 当前查看的任务ID
let currentTaskName = '';    // 当前查看的任务名称
let logsPage = 1;           // 当前页码
let logsPageSize = 10;      // 每页显示10条
let logsTotalCount = 0;     // 总记录数
```

### 2. 重构viewTaskLogs函数
原来的 `viewTaskLogs` 函数直接加载并显示记录，现在改为：
- 保存任务信息到全局变量
- 重置页码为1
- 调用 `loadTaskLogs()` 加载数据

```javascript
async function viewTaskLogs(taskId, taskName) {
    currentTaskId = taskId;
    currentTaskName = taskName;
    logsPage = 1; // 重置到第一页
    await loadTaskLogs();
}
```

### 3. 新增loadTaskLogs函数
负责加载和显示执行记录，支持分页：
```javascript
async function loadTaskLogs() {
    // 计算offset
    const offset = (logsPage - 1) * logsPageSize;
    
    // 调用API，传递limit和offset参数
    const res = await fetch(
        API_BASE + '/api/task-execution-logs?task_id=' + 
        encodeURIComponent(currentTaskId) + 
        '&limit=' + logsPageSize + 
        '&offset=' + offset, 
        { headers }
    );
    
    // 保存总记录数
    logsTotalCount = data.total || 0;
    
    // 渲染表格和分页组件
    ...
}
```

### 4. 添加分页组件
在表格下方显示分页按钮：
```javascript
const totalPages = Math.ceil(logsTotalCount / logsPageSize);
if (totalPages > 1) {
    modalContent += '<div style="margin-top:16px;display:flex;align-items:center;justify-content:center;gap:12px">';
    modalContent += '<button class="pagination-btn" onclick="changeLogsPage(' + (logsPage - 1) + ')" ' + (logsPage === 1 ? 'disabled' : '') + '>上一页</button>';
    modalContent += '<span class="pagination-info">第 ' + logsPage + ' / ' + totalPages + ' 页（共 ' + logsTotalCount + ' 条）</span>';
    modalContent += '<button class="pagination-btn" onclick="changeLogsPage(' + (logsPage + 1) + ')" ' + (logsPage === totalPages ? 'disabled' : '') + '>下一页</button>';
    modalContent += '</div>';
}
```

### 5. 新增changeLogsPage函数
处理翻页操作：
```javascript
function changeLogsPage(page) {
    const totalPages = Math.ceil(logsTotalCount / logsPageSize);
    if (page < 1 || page > totalPages) return;
    logsPage = page;
    loadTaskLogs(); // 重新加载数据
}
```

## 数据流程

### 首次打开执行记录
```
用户点击"📋 记录"按钮
  ↓
viewTaskLogs(taskId, taskName)
  ↓
保存任务信息，重置页码为1
  ↓
loadTaskLogs()
  ↓
调用API: /api/task-execution-logs?task_id=xxx&limit=10&offset=0
  ↓
显示第1页数据和分页组件
```

### 翻页操作
```
用户点击"下一页"按钮
  ↓
changeLogsPage(2)
  ↓
更新 logsPage = 2
  ↓
loadTaskLogs()
  ↓
调用API: /api/task-execution-logs?task_id=xxx&limit=10&offset=10
  ↓
显示第2页数据和分页组件
```

## 后端API支持
后端API `/api/task-execution-logs` 已经支持分页参数：
- `task_id`: 任务ID（必需）
- `limit`: 每页记录数（默认20）
- `offset`: 偏移量（默认0）

返回数据：
```json
{
  "logs": [...],
  "total": 100,
  "limit": 10,
  "offset": 0
}
```

数据已按 `started_at DESC` 排序（时间倒序）。

## 用户体验优化
1. **分页信息清晰** - 显示"第 X / Y 页（共 Z 条）"
2. **按钮状态管理** - 第一页禁用"上一页"，最后一页禁用"下一页"
3. **保持弹窗打开** - 翻页时不关闭弹窗，直接更新内容
4. **每页10条** - 适中的数量，既不会太多导致滚动，也不会太少需要频繁翻页
