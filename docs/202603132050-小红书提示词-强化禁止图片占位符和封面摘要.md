# 小红书提示词 - 强化禁止图片占位符和封面摘要

## 问题描述

用户反馈生成的小红书文章存在以下问题：
1. 文章中出现图片占位符 `[图片: xxx]`，但小红书平台不需要这种格式
2. 文章结尾出现封面提示词 `[封面: xxx]`，这是公众号专用格式
3. 话题标签有时缺失或后面有其他内容

## 根本原因

虽然小红书专属提示词中已经禁止了这些格式，但通用提示词（第一部分）中仍然要求添加图片占位符和封面。AI在处理时可能会混淆两部分规则，导致：
- 通用规则要求添加图片占位符 → AI添加了 `[图片: xxx]`
- 通用规则要求公众号添加封面 → AI误以为小红书也需要
- 禁止规则不够明确 → AI没有严格遵守

## 解决方案

### 1. 修改通用提示词 - 明确小红书例外

**文件**: `src/utils/prompts.ts`

#### 1.1 图片占位符规则（第418行附近）
```typescript
- **图片占位符（重要！）**：
  - ⚠️ **小红书平台例外**：如果目标平台是小红书，**严禁使用任何图片占位符**！跳过本条规则，直接用纯文字写作
  - 其他平台在合适的地方插入 `[图片: 描述]`
  - 建议每500-800字配一张图
  - 描述格式根据目标平台不同：
    - **公众号**：需要15-50字的详细场景描述（用于AI生成配图）
    - **头条/知乎**：只需2-5字的简短关键词（用于搜索配图）
  - 如果不确定目标平台，默认使用简短关键词格式,尽量是简单名词概念
  - 示例：`[图片: 外卖骑手]`、`[图片: 办公室]`
```

#### 1.2 封面提示词规则（第450行附近）
```typescript
### 4. 封面图提示词（仅公众号需要！）
- **只有微信公众号**需要在文章最后生成封面图提示词
- ⚠️ **小红书、头条、知乎等平台严禁添加封面提示词**，直接结束文章即可
- 公众号格式：在文章**最后一行**，单独用 `[封面: 详细描述]` 格式
- 描述要**30-60个字**，包含：主体、场景、色彩、氛围、视觉冲击力
```

### 2. 强化小红书专属提示词

**文件**: `src/utils/prompts.ts`（第1030行附近）

#### 2.1 正文要求 - 多次强调禁止图片占位符
```typescript

- **分段分段再分段**！每一行或每两行一个段落
- **严禁使用任何 Emoji 表情包**！全文必须是纯文字内容，**每段后面严禁添加emoji表情**
- ❌❌❌ **严禁使用图片占位符**！小红书平台不需要 `[图片: xxx]` 这种格式，全文只用纯文字表达
- ❌❌❌ **严禁使用 `[图片: xxx]` 格式**！这是其他平台的规则，小红书不需要！
- **不允许其他方式充作标题来强行分段，比如【】里面添加内容用来总结，必须一口气说完**
- 中间不需要段落小标题，全文一气呵成，不需要加粗，不需要加下划线
- 用自然的语言表达情绪和重点，不要依赖表情符号
```

#### 2.2 格式示例 - 强调话题标签后不能有内容
```typescript
**注意（CRITICAL）**：
- 话题标签必须在文章最后一行
- 话题标签前面可以有一个简短的互动引导（如"评论区聊聊吧"），但必须另起一行
- ❌❌❌ **严禁在话题标签后面添加任何内容**（如封面、摘要、图片等）
- 话题标签是文章的结束，后面不能有任何文字
```

#### 2.3 平台特殊说明 - 集中列出所有禁止项
```typescript

⚠️⚠️⚠️ **小红书平台严禁使用以下格式（即使通用规则中要求也不能用）：**
- ❌ **严禁添加图片占位符**：不要使用 `[图片: xxx]` 格式（这是公众号/头条/知乎的规则，小红书不需要）
- ❌ **严禁添加封面提示词**：不要使用 `[封面: xxx]` 格式（这是公众号专用，小红书不需要）
- ❌ **严禁添加摘要**：不要使用 `[摘要: xxx]` 格式（这是公众号专用，小红书不需要）
- ❌ **话题标签后面严禁添加任何内容**：话题标签必须是文章的最后一行，后面不能有任何文字
- ✅ **小红书只需要**：标题 + 简介 + 正文 + 话题标签（按这个顺序，不要添加其他格式）
```

## 修改要点

### 多层防护策略

1. **通用规则层面**：在图片占位符和封面规则中明确标注小红书例外
2. **专属规则层面**：在小红书提示词中多次、多处强调禁止
3. **用户提示层面**：在发送给AI的消息中用醒目格式再次提醒
4. **集中说明**：新增"平台特殊说明"章节，集中列出所有禁止项
5. **平台名称修复**：修复了 `platformName` 变量缺少小红书映射的问题，确保提示词中显示"小红书"而不是"公众号"

### 强调方式

- 使用 `❌❌❌` 三个叉号引起注意
- 使用 `⚠️⚠️⚠️` 多个警告符号
- 使用 `CRITICAL` 标记关键规则
- 在括号中说明"这是其他平台的规则，小红书不需要"
- 明确说明"即使通用规则中要求也不能用"

### 正确格式

小红书文章的正确结构：
```
# 标题

[简介]简介内容（50-80字，纯文字）

正文第一段

正文第二段

...更多段落...

评论区聊聊吧

#话题1 #话题2 #话题3 #话题4 #话题5
```
