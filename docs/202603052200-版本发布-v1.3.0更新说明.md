# Memoraid v1.3.0 版本发布说明

## 发布时间
2026年3月5日

## 版本号
1.3.0

## 主要更新内容

### 1. 支持定时任务创建文章
- 用户可以在设置页面配置定时任务
- 支持按照设定的时间间隔自动从指定内容源抓取内容并生成文章
- 支持多个平台的定时发布(微信公众号、知乎、头条、小红书)
- 定时任务可以独立启用/禁用

### 2. 支持充值文章额度
- 新增用户额度系统,包含免费额度和付费额度
- 首页显示剩余额度信息(免费/付费分别显示)
- 额度不足时提供充值入口
- 充值后可继续使用AI生成文章功能
- 管理员可通过邮件审批充值订单

### 3. 新增用户反馈功能
- 首页右上角新增反馈按钮(💬图标)
- 支持三种反馈类型:使用体验、优化建议、问题反馈
- 支持匿名用户和登录用户提交反馈
- 管理员页面新增"用户反馈"模块
- 管理员可查看、筛选、回复和处理用户反馈

### 4. 完善文章数据统计功能
- 新增Token使用量统计,显示每篇文章的AI消耗
- 管理员页面新增用户排行榜功能
  - 文章数量排行榜
  - Token消耗排行榜
  - 充值金额排行榜
- 优化数据展示界面

### 5. 优化账号同步功能
- 修复知乎文章上报时的账户并发插入冲突问题
- 使用 `INSERT OR IGNORE` 避免UNIQUE约束冲突
- 提升多平台账号同步的稳定性
- 优化账号数据的存储和查询性能

## 技术改进

### 前端
- 优化反馈提交的用户体验,使用内联状态提示替代弹窗
- 简化设置页面,移除模型提供商选择(统一使用Memoraid)
- 改进版本通知横幅,使用跑马灯效果展示更新内容

### 后端
- 新增 `/api/feedback` 接口支持反馈提交
- 新增 `/api/admin/feedback` 接口支持反馈管理
- 新增 `/api/admin/leaderboards` 接口支持排行榜查询
- 优化额度检查逻辑,修复付费额度无法使用的问题
- 改进数据库操作,避免并发冲突

## 文件变更

## Chrome Web Store 提交说明

### 权限申请理由
本版本使用了 `alarms` 权限,用于实现定时任务功能。提交到Chrome Web Store时需要填写权限使用理由:

**理由文本** (可直接复制到表单中):
```
Memoraid使用alarms权限实现定时任务功能,具体用途包括:

1. 定时内容抓取 - 根据用户配置的时间间隔,自动从RSS订阅源和指定网站抓取最新内容

2. 自动文章生成 - 在设定时间使用AI处理抓取的内容,生成适合不同平台的文章

3. 多平台定时发布 - 支持定时将文章发布到微信公众号、知乎、头条、小红书等自媒体平台

4. 后台任务调度 - 确保即使用户关闭扩展弹窗,定时任务仍能按计划在后台执行

所有定时任务均需用户在设置页面主动配置后才会执行,用户可随时启用/禁用任务,完全掌控任务的执行。这是Memoraid核心的自动化内容创作功能,帮助自媒体创作者提高工作效率。
```

详细权限说明文档: `docs/CHROME_STORE_PERMISSIONS.md`

### 提交步骤
1. 登录 [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole)
2. 选择 Memoraid 扩展
3. 上传 `release/memoraid-release.zip`
4. 在权限申请理由处粘贴上述文本
5. 填写版本更新说明(可参考本文档"主要更新内容"部分)
6. 提交审核
