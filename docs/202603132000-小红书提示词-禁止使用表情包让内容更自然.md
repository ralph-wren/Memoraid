# 小红书提示词优化 - 禁止使用表情包让内容更自然

## 问题描述

用户反馈：生成的小红书文章使用了大量Emoji表情包，读者觉得像AI写的，不够自然。

## 问题分析

之前的小红书提示词要求：
- **必须大量使用 Emoji**
- 在关键点后面加 ✅，在吐槽处加 😅，在惊喜处加 ✨
- 简介可以带1-2个emoji

这导致生成的内容过于"AI化"，缺乏真实感。

## 解决方案

### 修改内容

**文件**：`src/utils/prompts.ts`

**主要修改**：

1. **正文要求**（第970-980行）：
   ```typescript
   #### 正文要求（CRITICAL - 严禁使用表情包）
   - **分段分段再分段**！每一行或每两行一个段落
   - **严禁使用任何 Emoji 表情包**！全文必须是纯文字内容
   - **不允许其他方式充作标题来强行分段，比如【】里面添加内容用来总结，必须一口气说完**
   - 中间不需要段落小标题，全文一气呵成，不需要加粗，不需要加下划线
   - 用自然的语言表达情绪和重点，不要依赖表情符号
   ```

2. **简介要求**（第960行）：
   ```typescript
   - 简介语气要轻松自然，**严禁使用emoji表情包**
   - 示例格式：
     - `[简介]最近发现一个超好用的工具，帮我节省了一半工作时间！分享给需要的姐妹们`
     - `[简介]这个方法我用了3个月，效果真的绝了！建议收藏慢慢看`
   ```

3. **语言风格优化**（第985-995行）：
   ```typescript
   #### 语言风格（更自然、更像人写的）
   - 语气要亲切自然，像朋友聊天一样
   - 多用"你"、"咱们"、"我觉得"等第一人称视角
   - 营造一种"我是真的觉得好才推荐给你"的私人分享感
   - 可以适当使用口语化表达，但要避免过度夸张
   - 重点内容通过语言强调，而不是表情符号
   - 示例：
     - ❌ 不好："这个真的太好用了！✨ 强烈推荐！💯"
     - ✅ 好："这个真的太好用了！我自己用了三个月，强烈推荐给你们"
   ```

4. **完整格式示例**（第1000行）：
   ```
   # 这是标题

   [简介]这是简介内容，50-80字，纯文字不带表情

   这是正文第一段，自然流畅的表达

   这是正文第二段，继续分享内容

   ...更多正文段落...

   #话题1 #话题2 #话题3 #话题4 #话题5
   ```

### 优化效果

**之前的风格**：
```
# 这个工具真的太好用了！

[简介]最近发现一个超好用的工具，帮我节省了一半工作时间！✨

这个工具真的太棒了！😊

我用了三个月，效果绝了！✅

强烈推荐给大家！💯
```

**优化后的风格**：
```
# 这个工具真的太好用了

[简介]最近发现一个超好用的工具，帮我节省了一半工作时间！分享给需要的姐妹们

这个工具真的太棒了！我自己用了三个月，每天都在用

效果真的很明显，工作效率提升了一半不止

强烈推荐给需要的朋友们，真的值得试试
```

## 核心改进点

1. **去除所有Emoji表情包**：让内容更自然，不像AI生成
2. **强调语言表达**：通过自然的语言来表达情绪和重点
3. **增强真实感**：多用第一人称视角，像朋友聊天
4. **避免过度夸张**：适度使用口语化表达，但不过分
