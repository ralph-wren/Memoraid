# 图片生成 - 完善正文配图提示词要求

## 问题描述
用户反馈微信公众号生成的图片与文章内容不相关，特别是人物图片缺少关键信息（种族、性别、年龄、场景、表情、动作、服装等），导致图片生成太随意。

之前已经修改了封面图的提示词要求，现在需要将相同的详细描述规则应用到正文配图。

## 修改内容

### 1. 通用提示词模板（ARTICLE_PROMPT_TEMPLATE）
修改了"图片占位符"部分，增加了公众号正文配图的详细要求：

**修改前**：
- 公众号：需要15-50字的详细场景描述
- 没有明确要求人物描述的具体内容

**修改后**：
- 公众号：需要40-80字的详细场景描述
- **如果涉及人物，必须详细描述**：种族、性别、年龄、场景、表情、动作、服装等
- 添加了3个详细的人物类示例：
  - 外卖骑手：25岁左右的亚洲男性，穿着黄色雨衣，表情专注...
  - 白领：28岁左右的亚洲女性，穿着职业装，面带微笑...
  - 年轻女孩：22岁左右的亚洲年轻女孩，穿着休闲装，脸上露出甜蜜的微笑...

### 2. 公众号专属提示词（WEIXIN_DEFAULT_PROMPT）
修改了"配图要求"部分，与通用模板保持一致：

**修改前**：
- 描述要详细具体（15-50字）
- 人物描述要求不够明确

**修改后**：
- 描述要详细具体（40-80字）
- **人物描述必须包含**：种族（亚洲人/白人/黑人等）、性别、年龄段、场景、表情、动作、服装
- 添加了3个详细的人物类示例

## 修改文件
- `src/utils/prompts.ts`
  - 第434-442行：通用提示词模板的图片占位符部分
  - 第782-820行：公众号专属提示词的配图要求部分

## 效果预期
1. 正文配图的提示词将包含更详细的人物描述
2. AI生成的图片将更准确地反映文章内容
3. 人物图片将包含完整的特征信息（种族、性别、年龄、场景、表情、动作、服装）
4. 图片与文章内容的相关性将显著提高

## 注意事项
1. 这个修改只影响微信公众号平台（有AI生成图片功能）
2. 头条和知乎平台仍然使用简短关键词（2-5字），因为它们只能搜索图片
3. 小红书平台不使用图片占位符，完全用纯文字
4. 字数要求从15-50字增加到40-80字，确保描述足够详细

## 测试建议
1. 生成一篇包含人物的微信公众号文章
2. 检查正文配图的提示词是否包含完整的人物描述
3. 验证生成的图片是否与文章内容高度相关
4. 确认人物特征（种族、性别、年龄等）是否准确
