# 定时任务 - 添加查看执行记录功能

## 功能描述
在定时任务列表中添加"查看记录"按钮，点击后弹窗显示该任务的历史执行记录，包括执行时间、状态、生成/发布数量、耗时等信息。

## 实现内容

### 1. 定时任务表格添加操作列
在任务列表表格中添加"操作"列，每行显示"📋 记录"按钮。

**表格结构**：
| 任务名称 | 状态 | 目标平台 | 执行周期 | 上次执行 | 操作 |
|---------|------|---------|---------|---------|------|
| 每日热点推送 | 运行中 | 公众号、小红书 | 每天 09:00 | 2026-03-23 22:30 ✅ | 📋 记录 |

### 2. 查看执行记录弹窗
点击"📋 记录"按钮后，弹出模态框显示该任务的执行历史：

**弹窗内容**：
- 标题：显示任务名称
- 表格：显示最近20条执行记录
  - 执行时间：精确到秒
  - 状态：✅ 成功 / ❌ 失败 / ⏳ 执行中
  - 生成：生成的文章数量
  - 发布：成功发布的文章数量
  - 耗时：执行时长（秒）
- 错误信息：如果执行失败，在下一行显示错误详情（红色背景）

### 3. API接口增强
修改 `GET /api/task-execution-logs` 接口，支持按 `task_id` 筛选：

**请求参数**：
- `task_id`（可选）：任务ID，用于筛选特定任务的执行记录
- `limit`（可选）：每页数量，默认20
- `offset`（可选）：偏移量，默认0

**示例**：
```
GET /api/task-execution-logs?task_id=task_123456&limit=20
```

## 技术细节

### 数据库查询
```sql
-- 按task_id筛选执行记录
SELECT id, task_id, task_name, status, started_at, completed_at, 
       duration, articles_generated, articles_published, error_message 
FROM task_execution_logs 
WHERE user_id = ? AND task_id = ? 
ORDER BY started_at DESC 
LIMIT 20
```

### 状态显示
- `success` → ✅ 成功（绿色）
- `failed` → ❌ 失败（红色）
- `running` → ⏳ 执行中（橙色）

### 时间格式化
使用 `formatTime()` 函数将时间戳转换为易读格式：
```
1711209015000 → 2026-03-23 22:30:15
```
