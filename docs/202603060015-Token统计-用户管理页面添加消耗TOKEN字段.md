# 用户管理页面添加消耗TOKEN字段

## 更新时间
2026年3月6日 00:15

## 需求描述
在管理员后台的用户管理页面,在"7日文章"列后面新增"消耗TOKEN"字段,统计每个用户累计消耗的token数量。

## 实现方案

### 1. 数据库查询增强

在用户列表查询SQL中添加token统计:

```sql
-- 累计消耗token数量（从ai_usage_logs表统计）
(SELECT COALESCE(SUM(total_tokens), 0) FROM ai_usage_logs WHERE user_id = u.id OR anonymous_id = u.id) as total_tokens
```

**说明**:
- 从 `ai_usage_logs` 表统计每个用户的总token消耗
- 使用 `COALESCE` 确保没有记录时返回0
- 支持匿名用户的token统计 (`anonymous_id`)

### 2. 表头添加新列

```html
<th class="sortable" id="sort-total_tokens" onclick="toggleSort('total_tokens')">消耗TOKEN</th>
```

**位置**: 在"7日文章"和"注册时间"之间

**特性**:
- 支持点击排序
- 可按token消耗量升序/降序排列

### 3. 数据显示优化

添加token数量格式化函数:

```javascript
// 格式化token数量（大于1000时显示为K）
const formatTokens = (tokens) => {
    if (!tokens || tokens === 0) return '0';
    if (tokens >= 1000000) return (tokens / 1000000).toFixed(1) + 'M';  // 百万级
    if (tokens >= 1000) return (tokens / 1000).toFixed(1) + 'K';        // 千级
    return tokens.toString();
};
```

**显示效果**:
- 0 tokens → "0"
- 1,234 tokens → "1.2K"
- 1,234,567 tokens → "1.2M"
- 鼠标悬停显示精确数值

### 4. 表格渲染更新

```javascript
<td>
    <span class="status-pill ${u.total_tokens > 0 ? 'info' : ''}" 
          title="${u.total_tokens || 0} tokens">
        ${formatTokens(u.total_tokens)}
    </span>
</td>
```

**样式**:
- 有token消耗时显示蓝色标签 (`info`)
- 无消耗时显示灰色
- title属性显示精确数值

### 5. 排序功能支持

```javascript
if (sort === 'total_tokens') sortField = 'total_tokens';
```

支持按token消耗量排序,方便找出:
- 消耗最多的用户
- 消耗最少的用户

### 6. 表格列数更新

```javascript
// 从8列更新为9列
document.getElementById('recentUsers').innerHTML = html || '<tr><td colspan="9" style="text-align:center">暂无数据</td></tr>';
```

## 功能特点

1. **实时统计**: 从数据库实时查询,数据准确
2. **友好显示**: 大数字自动格式化为K/M单位
3. **详细信息**: 鼠标悬停显示精确token数
4. **支持排序**: 可按token消耗量排序
5. **视觉区分**: 有消耗的用户显示蓝色标签

## 使用场景

1. **成本分析**: 查看哪些用户消耗token最多
2. **用户分类**: 区分活跃用户和普通用户
3. **资源优化**: 识别高消耗用户,优化资源分配
4. **数据统计**: 配合其他指标分析用户行为
