# 工单系统 - 修复JavaScript语法错误

## 问题描述
在工单系统的前端代码中出现多个JavaScript语法错误：
1. `Uncaught SyntaxError: Unexpected token 'var'` - 在管理员后台页面
2. `Uncaught SyntaxError: Invalid regular expression: missing /` - 在工单详情页面

## 问题原因
在TypeScript字符串模板中使用了CSS变量（如 `var(--text-muted)`）和模板字符串（反引号），导致JavaScript解析器将 `var` 当作关键字处理，引发语法错误。

## 解决方案
将所有在JavaScript字符串拼接、`innerHTML` 赋值和HTML事件属性中使用的CSS变量替换为具体的颜色值。

## 颜色映射
- `var(--text)` → `#0f172a` (深色文字)
- `var(--text-muted)` → `#9ca3af` (灰色文字)
- `var(--text-secondary)` → `#64748b` (次要文字)
- `var(--bg-subtle)` → `#f8fafc` (浅灰背景)
- `var(--bg-secondary)` → `#f8fafc` (次要背景)
- `var(--bg-muted)` → `#f1f5f9` (hover背景色)
- `var(--border)` → `#e2e8f0` (边框颜色)
- `var(--accent)` → `#10b981` (强调色/绿色)

## 技术要点
1. `<style>` 标签内可以使用CSS变量
2. JavaScript字符串拼接中不能使用CSS变量
3. `innerHTML` 赋值中不能使用CSS变量
4. HTML事件属性中不能使用CSS变量
5. 事件属性中的引号需要转义：`onmouseover="this.style.background=\'#f1f5f9\'"`
