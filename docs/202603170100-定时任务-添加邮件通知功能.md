# 定时任务添加邮件通知功能

## 功能描述

在定时任务设置中添加通知邮箱字段，当任务完成后自动发送邮件通知用户，包含任务执行状态、文章详情、发布结果等信息。

## 邮件内容设计

### 邮件主题
```
[Memoraid] 定时任务执行完成 - {任务名称}
```

### 邮件内容包含
1. **任务概览**
   - 任务名称
   - 执行时间
   - 任务状态（成功/失败）

2. **执行统计**
   - 成功发布数量
   - 失败发布数量
   - 总计文章数量

3. **文章详情**（每篇文章）
   - 状态（成功/失败）
   - 标题
   - 素材来源 URL
   - 发布平台列表
   - 发布时间
   - 失败原因（如果失败）

4. **任务日志**
   - 时间戳
   - 日志级别（info/success/error/warn）
   - 日志消息

## 实现步骤

### 1. 数据库迁移

创建 `backend/migrations/0010_add_notification_email.sql`：
- 添加 `notification_email` 字段到 `scheduled_tasks` 表
- 添加 `execution_times` 字段（支持多个执行时间点）
- 添加 `article_count` 字段

### 2. 后端 API

在 `backend/src/index.ts` 中添加：
- `POST /api/scheduled-tasks/send-notification` - 发送任务完成通知邮件
- 使用 Resend API 发送邮件（from: onboarding@resend.dev）
- 生成 HTML 和纯文本两种格式的邮件内容

### 3. 前端组件

修改 `src/components/ScheduleSettings.tsx`：
- 添加"通知邮箱"输入框
- 保存和更新任务时包含 `notificationEmail` 字段
- 在任务列表中显示通知邮箱（如果已设置）

### 4. 调度器集成

修改 `src/background/scheduler.ts`：
- 在任务执行完成后，收集执行结果数据
- 如果任务配置了通知邮箱，调用后端 API 发送邮件
- 包含所有文章的详细信息和任务日志

## 邮件模板样式

- 使用响应式设计，适配移动端和桌面端
- 清晰的视觉层次，使用卡片式布局
- 成功状态使用绿色，失败状态使用红色
- 包含 Memoraid 品牌标识
- 提供官网链接

## 数据流程

1. 用户在定时任务设置中填写通知邮箱
2. 任务执行完成后，scheduler 收集执行结果
3. Scheduler 调用后端 API `/api/scheduled-tasks/send-notification`
4. 后端生成邮件内容（HTML + 纯文本）
5. 使用 Resend API 发送邮件
6. 返回发送结果

## 注意事项

1. 邮箱地址需要验证格式
2. 邮件发送失败不应影响任务执行
3. 邮件内容需要转义 HTML 特殊字符
4. 时间格式统一使用中国时区（UTC+8）
5. 邮件大小控制在合理范围内（避免日志过长）

## 测试建议

1. 创建测试任务，设置通知邮箱
2. 手动触发任务执行
3. 检查邮件是否正确发送
4. 验证邮件内容的完整性和格式
5. 测试失败场景的邮件通知
