# 定时任务 - 添加邮件通知功能

## 功能概述

为定时任务添加邮件通知功能，任务完成后自动发送包含执行详情的邮件报告。

## 问题背景

用户希望在定时任务执行完成后能够收到邮件通知，了解任务执行情况，包括：
- 任务执行状态（成功/失败）
- 每篇文章的发布结果
- 详细的执行日志
- 统计数据（成功/失败数量）

## 使用方法

### 1. 配置邮箱

在定时任务编辑界面：
1. 展开要配置的任务
2. 找到"通知邮箱（可选）"输入框
3. 输入接收通知的邮箱地址
4. 点击保存按钮

### 2. 邮件内容

任务完成后会收到包含以下内容的邮件：

**任务概览**
- 任务名称
- 执行时间（中国时区）
- 任务状态（成功/失败）

**执行统计**
- 成功发布数量
- 失败发布数量
- 总计文章数量

**文章详情**
- 每篇文章的标题
- 素材来源链接
- 发布平台
- 发布状态
- 发布时间
- 失败原因（如果失败）

**任务日志**
- 完整的执行日志
- 包含时间戳和日志级别
- 方便排查问题

## 技术细节

### 邮件服务

使用 Resend API 发送邮件：
- 官网：https://resend.com
- 免费额度：每月 3000 封邮件
- 发件人：onboarding@resend.dev
- 发件名称：Memoraid

### 邮件格式

- HTML 格式：精美的邮件模板，包含样式和布局
- 纯文本格式：作为备用，确保所有邮件客户端都能正常显示

### 错误处理

- 邮件发送失败不会影响任务状态
- 失败信息会记录在任务日志中
- 用户可以在任务日志中查看邮件发送状态

## 注意事项

1. **邮箱验证**：后端会验证邮箱格式，必须包含 `@` 符号
2. **发送频率**：Resend 免费版每月 3000 封，注意不要超限
3. **邮件延迟**：邮件发送可能有几秒到几分钟的延迟
4. **垃圾邮件**：首次接收可能被标记为垃圾邮件，需要手动标记为非垃圾邮件
