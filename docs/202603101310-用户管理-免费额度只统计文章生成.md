# 用户管理：免费额度只统计文章生成次数

## 修改日期
2026-03-10 13:10

## 需求说明
用户要求免费额度只统计文章生成次数，不包括AI聊天次数。

## 修改内容

### 1. 后端SQL查询修改（backend/src/index.ts）

修改 `ai_usage` 字段的统计逻辑，只统计 `model = 'article-generation'` 的记录：

```sql
-- 修改前：统计所有AI使用记录
(SELECT COUNT(*) FROM ai_usage_logs WHERE user_id = u.id OR anonymous_id = u.id) as ai_usage

-- 修改后：只统计文章生成记录
(SELECT COUNT(*) FROM ai_usage_logs 
 WHERE (user_id = u.id OR anonymous_id = u.id) 
 AND model = 'article-generation') as ai_usage
```

**说明**：
- `ai_usage_logs` 表中的 `model` 字段用于区分使用类型
- `model = 'article-generation'` 表示文章生成
- 其他值（如 'deepseek-chat'）表示AI聊天
- 现在只统计文章生成的记录

### 2. 前端显示修改（backend/src/index.ts）

#### 2.1 表头提示修改
```html
<!-- 修改前 -->
<th title="包括AI聊天和文章生成的总使用次数">免费额度</th>

<!-- 修改后 -->
<th title="文章生成使用次数">免费额度</th>
```

#### 2.2 数据单元格提示修改
```javascript
// 修改前：显示AI聊天和文章生成的明细
<td title="AI聊天: ${chatUsage}次 | 文章生成: ${articleUsage}篇">

// 修改后：只显示总文章数
<td title="已生成 ${u.total_articles || 0} 篇文章">
```

### 3. 代码简化
- 移除了 `chatUsage` 和 `articleUsage` 的计算逻辑
- 简化了提示信息，只显示文章生成相关的信息

## 影响说明

### 额度统计规则变更
**修改前**：
- 免费额度 = AI聊天次数 + 文章生成次数
- 例如：1次聊天 + 1篇文章 = 2/5

**修改后**：
- 免费额度 = 文章生成次数
- 例如：1次聊天 + 1篇文章 = 1/5（只统计文章）

### 用户体验改进
1. **更清晰的额度显示**：用户一眼就能看出生成了多少篇文章
2. **简化的提示信息**：鼠标悬停显示"已生成 X 篇文章"
3. **符合用户预期**：免费额度主要用于文章生成，不包括聊天

## 数据库记录说明

### ai_usage_logs 表
该表记录所有AI使用情况，通过 `model` 字段区分：

| model 值 | 说明 | 是否计入免费额度 |
|---------|------|----------------|
| article-generation | 文章生成 | ✅ 是 |
| deepseek-chat | AI聊天 | ❌ 否 |
| 其他 | 其他AI功能 | ❌ 否 |

### 记录时机
1. **文章生成**：在 `/api/articles/batch` 接口中，生成新文章时记录
2. **AI聊天**：在 `/api/ai/chat/completions` 接口中，每次对话时记录
