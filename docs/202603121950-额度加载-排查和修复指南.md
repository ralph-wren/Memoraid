## 常见问题和解决方案

### 问题1: HTTP 401 - 认证失败

**症状:**
```
Failed to load quota: HTTP 401
或
{ "error": "Unauthorized" }
```

**原因:** 
- 插件没有token,也没有anonymousId
- token格式不正确

**解决方案:**
1. 检查是否有匿名ID:
```javascript
// 在popup控制台运行
chrome.storage.local.get(['anonymousId'], console.log)
```

2. 如果没有anonymousId,手动创建一个:
```javascript
// 在popup控制台运行
const anonymousId = 'anon_' + Date.now() + '_' + Math.random().toString(36).substr(2, 9);
chrome.storage.local.set({ anonymousId }, () => {
  console.log('已创建匿名ID:', anonymousId);
  // 刷新popup
  window.location.reload();
});
```

### 问题2: HTTP 500 - 服务器错误

**症状:**
```
Failed to load quota: HTTP 500
或
{ "error": "..." }
```

**原因:**
- 数据库查询失败
- 后端代码执行异常

**解决方案:**
1. 查看后端日志:
```bash
cd backend
npx wrangler tail --format pretty
```

2. 重新加载插件触发请求,观察日志输出

3. 如果看到数据库错误,检查表是否存在:
```bash
cd backend
npx wrangler d1 execute memoraid-db --remote --command "SELECT name FROM sqlite_master WHERE type='table' AND name IN ('user_quotas', 'ai_usage_logs', 'payment_orders')"
```

### 问题3: CORS错误

**症状:**
```
Access to fetch at '...' from origin '...' has been blocked by CORS policy
```

**原因:**
- 后端没有正确设置CORS头
- 请求的域名不正确

**解决方案:**
1. 检查后端URL配置:
```javascript
// 在popup控制台运行
chrome.storage.local.get(['settings'], (result) => {
  console.log('Backend URL:', result.settings?.sync?.backendUrl || 'https://memoraid.dpdns.org');
});
```

2. 确认后端CORS配置正确 (已在代码中配置)

### 问题4: 网络错误

**症状:**
```
Failed to fetch
或
Network request failed
```

**原因:**
- 网络连接问题
- 后端服务不可用
- DNS解析失败

**解决方案:**
1. 测试后端是否可访问:
```bash
curl https://memoraid-backend.iuyuger.workers.dev/api/user/quota
```

2. 检查网络连接

3. 尝试使用备用域名 (如果有)

### 问题5: 缓存问题

**症状:**
- 显示旧的额度数据
- 更新后不生效

**解决方案:**
清除缓存:
```javascript
// 在popup控制台运行
chrome.storage.local.remove(['quotaCache', 'quotaCacheTime'], () => {
  console.log('缓存已清除');
  window.location.reload();
});
```

## 完整的调试流程

1. **运行控制台脚本** (`test/debug-quota-console.js`)
   - 获取完整的错误信息

2. **根据错误类型采取对应措施:**
   - 401错误 -> 检查认证信息
   - 500错误 -> 查看后端日志
   - CORS错误 -> 检查域名配置
   - 网络错误 -> 测试后端可用性

3. **如果问题依然存在:**
   - 截图控制台完整输出
   - 截图Network标签的请求详情
   - 提供后端日志输出
   - 联系开发者进一步排查
