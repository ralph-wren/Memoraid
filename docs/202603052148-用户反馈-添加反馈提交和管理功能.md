# 用户反馈 - 添加反馈提交和管理功能

## 功能概述

在首页右上角添加用户反馈按钮，用户可以提交使用体验、优化建议和问题反馈。管理员可以在后台查看、回复和管理所有用户反馈。

### 2. 后端 - 反馈API接口

**文件**: `backend/src/index.ts`

#### 2.1 提交反馈接口

**路由**: `POST /api/feedback`

**功能**:
- 接收用户反馈提交
- 支持匿名用户和登录用户
- 验证反馈类型和内容

**请求体**:
```json
{
  "type": "experience|suggestion|bug",
  "content": "反馈内容"
}
```

**验证规则**:
- type必须是: experience, suggestion, bug之一
- content不能为空
- content长度不超过500字符

**响应**:
```json
{
  "success": true
}
```

#### 2.2 获取反馈列表接口（管理员）

**路由**: `GET /api/admin/feedback`

**权限**: 仅管理员

**查询参数**:
- `page`: 页码（默认1）
- `pageSize`: 每页数量（默认20）
- `type`: 反馈类型筛选（all, experience, suggestion, bug）
- `status`: 状态筛选（all, pending, resolved, ignored）

**响应**:
```json
{
  "list": [
    {
      "id": 1,
      "user_id": 123,
      "user_email": "user@example.com",
      "type": "suggestion",
      "content": "建议内容",
      "status": "pending",
      "admin_reply": null,
      "created_at": 1709654400,
      "updated_at": null
    }
  ],
  "total": 50,
  "page": 1,
  "pageSize": 20,
  "totalPages": 3
}
```

#### 2.3 更新反馈状态接口（管理员）

**路由**: `POST /api/admin/feedback/:id/status`

**权限**: 仅管理员

**请求体**:
```json
{
  "status": "resolved|ignored",
  "adminReply": "管理员回复内容（可选）"
}
```

**功能**:
- 更新反馈状态
- 添加管理员回复
- 记录更新时间

### 4. 数据库表结构

**表名**: `feedback`

```sql
CREATE TABLE IF NOT EXISTS feedback (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,  -- 用户ID，可以为NULL（匿名用户）
    user_email TEXT,  -- 用户邮箱，可以为NULL
    type TEXT NOT NULL,  -- 反馈类型: experience, suggestion, bug
    content TEXT NOT NULL,  -- 反馈内容
    status TEXT DEFAULT 'pending',  -- 状态: pending, resolved, ignored
    admin_reply TEXT,  -- 管理员回复
    created_at INTEGER NOT NULL,  -- 创建时间（Unix时间戳）
    updated_at INTEGER,  -- 更新时间（Unix时间戳）
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

**索引**:
- `idx_feedback_user_id`: 用户ID索引
- `idx_feedback_type`: 反馈类型索引
- `idx_feedback_status`: 状态索引
- `idx_feedback_created_at`: 创建时间索引（降序）

## 用户流程

### 用户提交反馈
1. 点击首页右上角的反馈按钮（💬图标）
2. 选择反馈类型（使用体验/优化建议/问题反馈）
3. 输入反馈内容（最多500字符）
4. 点击"提交反馈"按钮
5. 收到成功提示，弹窗自动关闭

### 管理员处理反馈
1. 登录管理员后台
2. 点击侧边栏"用户反馈"
3. 使用筛选器查看特定类型或状态的反馈
4. 查看反馈详情
5. 选择操作：
   - 点击"回复"按钮，输入回复内容并提交（自动标记为已解决）
   - 点击"标记已解决"直接标记为已解决
   - 点击"忽略"标记为已忽略

## 技术特点

1. **支持匿名用户**: 未登录用户也可以提交反馈
2. **实时状态更新**: 管理员操作后立即刷新列表
3. **分页加载**: 支持大量反馈数据的分页显示
4. **多维度筛选**: 按类型和状态筛选反馈
5. **响应式设计**: 反馈卡片hover效果，提升交互体验
6. **数据验证**: 前后端双重验证，确保数据质量
