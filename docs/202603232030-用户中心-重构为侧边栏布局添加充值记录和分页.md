# 用户中心页面重构 - 侧边栏布局、充值记录和分页功能

## 更新时间
2026-03-23 20:30

## 问题描述
用户中心页面需要优化布局和功能：
1. 将"内容数据中心"标题移到Logo旁边
2. 文章列表改为侧边栏筛选样式
3. 添加充值记录模块
4. 支持分页功能

## 解决方案

### 1. 页面布局重构

#### Logo区域优化
- 将"内容数据中心"和副标题移到Logo右侧
- 使用垂直布局显示标题和副标题
- 移动端自动隐藏副标题

```html
<div class="logo-text">
    <span class="logo-name">Memoraid</span>
    <span class="logo-subtitle">内容数据中心 · 专注文章与额度管理</span>
</div>
```

#### 侧边栏布局
- 左侧固定宽度侧边栏（240px）
- 包含平台筛选和排序方式
- 使用sticky定位，滚动时保持可见

```css
.main-layout {
    display: grid;
    grid-template-columns: 240px 1fr;
    gap: 24px;
}

.sidebar {
    position: sticky;
    top: 96px;
}
```

### 2. Tab切换功能

#### 实现两个Tab
- 文章列表：显示用户发布的所有文章
- 充值记录：显示用户的充值历史

```javascript

    currentTab = tab;
    // 更新Tab按钮状态
    // 切换内容显示
    // 按需加载数据

```

### 3. 排序功能

#### 支持两种排序方式
- 按发布时间排序（默认）
- 按Token消耗排序

```javascript
function changeSortBy(sortBy) {
    currentSortBy = sortBy;
    articlesPage = 1; // 重置到第一页
    loadArticles();

```

#### 文章列表分页

- 显示当前页码和总页数

```javascript

let articlesPageSize = 20;
let articlesTotalCount = 0;

function renderArticlesPagination() {
    const totalPages = Math.ceil(articlesTotalCount / articlesPageSize);
    // 渲染分页按钮

```

#### 充值记录分页
- 每页显示20条记录
- 独立的分页状态
- 相同的分页UI组件

### 5. 新增API接口

#### GET /api/payment/history
获取用户充值记录（支持分页）

**请求参数：**
- `limit`: 每页数量（默认20）
- `offset`: 偏移量（默认0）

**响应数据：**
```json
{
  "records": [
    {
      "id": "订单号",
      "amount": 10,
      "quota_amount": 50,
      "status": "paid",
      "created_at": 1234567890,
      "paid_at": 1234567890
    }
  ],
  "total": 100,
  "limit": 20,
  "offset": 0
}
```

### 数据加载流程
1. 页面初始化时检查登录状态
2. 加载平台列表和用户额度
3. 默认加载文章列表（第一页）

### API调用优化
- 使用现有的 `/api/user/articles` 接口（已支持分页）
- 新增 `/api/payment/history` 接口获取充值记录
- 前端实现Token排序（后端只支持时间排序）

1. **Token排序**：由于后端API只支持按时间排序，Token排序在前端实现
2. **分页总数**：文章列表从API返回的total字段获取准确总数
3. **充值记录**：如果API不存在会显示空状态，不会报错
4. **响应式**：移动端侧边栏改为静态定位，避免遮挡内容
