# 官网图片点击放大功能

## 功能描述
为运营效果展示的图片添加点击放大查看功能，提升用户体验。

## 实现方式

### 1. 图片样式修改
在图片标签上添加：
- `cursor:pointer` - 鼠标悬停时显示手型光标
- `onclick="openImageModal(this.src)"` - 点击时打开lightbox

### 2. Lightbox组件
创建全屏图片查看器：

```html
<div id="imageLightbox" style="display:none;position:fixed;top:0;left:0;right:0;bottom:0;background:rgba(0,0,0,0.9);z-index:9999;align-items:center;justify-content:center;padding:20px" onclick="closeImageModal()">
  <img id="lightboxImage" src="" style="max-width:90%;max-height:90%;border-radius:8px;box-shadow:0 8px 32px rgba(0,0,0,0.5)">
  <div style="position:absolute;top:20px;right:20px;color:#fff;font-size:32px;cursor:pointer;width:40px;height:40px;display:flex;align-items:center;justify-content:center;background:rgba(255,255,255,0.1);border-radius:50%;backdrop-filter:blur(10px)" onclick="closeImageModal()">×</div>
</div>
```

**样式特点：**
- 全屏黑色半透明背景（rgba(0,0,0,0.9)）
- 图片最大90%宽高，自适应屏幕
- 右上角关闭按钮，带毛玻璃效果
- 圆角和阴影效果

### 3. JavaScript功能

#### openImageModal(src)
打开图片查看器：
```javascript
function openImageModal(src) {
  const lightbox = document.getElementById('imageLightbox');
  const img = document.getElementById('lightboxImage');
  img.src = src;
  lightbox.style.display = 'flex';
  document.body.style.overflow = 'hidden'; // 禁止页面滚动
}
```

#### closeImageModal()
关闭图片查看器：
```javascript
function closeImageModal() {
  const lightbox = document.getElementById('imageLightbox');
  lightbox.style.display = 'none';
  document.body.style.overflow = ''; // 恢复页面滚动
}
```

#### ESC键关闭
```javascript
document.addEventListener('keydown', function(e) {
  if (e.key === 'Escape') {
    closeImageModal();
  }
});
```

## 交互方式

### 打开图片
1. 点击运营效果图片
2. 图片在全屏黑色背景上居中显示
3. 页面滚动被禁用

### 关闭图片
支持三种方式：
1. 点击图片外的黑色背景区域
2. 点击右上角的 × 关闭按钮
3. 按键盘 ESC 键

## 应用范围
- 首页运营效果展示（2张图片）
- 定价页面运营效果展示（2张图片）

## 用户体验优化

### 1. 视觉反馈
- 鼠标悬停时显示手型光标
- 提示用户图片可点击

### 2. 多种关闭方式
- 点击背景关闭（最常用）
- 点击关闭按钮（明确操作）
- ESC键关闭（键盘用户友好）

### 3. 页面滚动控制
- 打开lightbox时禁止页面滚动
- 关闭后恢复滚动
- 避免背景页面滚动干扰

### 4. 响应式设计
- 图片最大90%宽高
- 自适应不同屏幕尺寸
- 移动端和桌面端都能正常使用

## 技术细节

### 1. z-index层级
- lightbox: 9999
- 确保在所有内容之上

### 2. 图片加载
- 点击时动态设置图片src
- 复用同一个lightbox组件

### 3. 事件冒泡
- 关闭按钮的onclick阻止事件冒泡
- 避免点击按钮时触发背景的关闭事件

### 4. 样式隔离
- 使用内联样式
- 避免与页面其他样式冲突
