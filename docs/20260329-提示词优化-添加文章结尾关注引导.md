# 提示词优化 - 添加文章结尾关注引导

**日期**: 2026-03-29  
**功能**: 提示词优化  
**解决问题**: 在各平台文章末尾添加委婉、俏皮的关注引导，提升用户关注转化率

## 修改内容

为四个平台的默认提示词都添加了"文章结尾引导"规则，要求AI在生成文章时，在文章末尾添加符合平台调性的关注引导语。

### 1. 头条号（接地气风格）

**风格要求**：像邻居聊天，真诚不做作，符合头条用户习惯

**示例**：
- "说实话，这事儿还挺有意思的，关注我，后面还有更多料。"
- "觉得说得在理的话，点个关注呗，咱们继续聊。"
- "如果你也关心这些事儿，不妨关注一下，一起看热闹。"
- "喜欢这种接地气的分析，就给个关注，咱们慢慢聊。"

**位置**：放在正文最后

### 2. 知乎（理性专业风格）

**风格要求**：专业、克制、有价值感，符合知乎调性

**示例**：
- "如果这篇分析对你有启发，欢迎关注，我会持续输出深度内容。"
- "觉得有价值的话，可以关注一下，后续会有更多专业解读。"
- "如果你也关注这个领域，欢迎关注我，一起深入探讨。"
- "喜欢这种分析风格的话，不妨点个关注，我们一起成长。"

**位置**：放在正文最后

### 3. 微信公众号（温暖真诚风格）

**风格要求**：温暖、真诚、不生硬，像朋友间的邀请

**示例**：
- "如果这篇文章对你有帮助，不妨点个关注，我会继续分享更多有价值的内容～"
- "喜欢这篇文章的话，记得关注我哦，后续还有更多干货分享！"
- "觉得有用的话，给个关注呗，咱们一起成长～"
- "如果你也对这个话题感兴趣，欢迎关注我，一起探讨更多！"

**位置**：放在正文最后，摘要和封面之前

### 4. 小红书（可爱俏皮风格）

**风格要求**：年轻化、有亲和力，像闺蜜间的邀请，符合小红书调性

**示例**：
- "喜欢的话记得关注我呀，每天分享更多干货～"
- "觉得有用就点个关注吧，咱们一起变优秀！"
- "关注我不迷路，后续还有更多宝藏分享！"
- "如果对你有帮助，点个关注支持一下呗～"
- "喜欢这种分享的姐妹，记得关注我哦！"

**位置**：放在正文最后，话题标签之前，可以和"评论区聊聊吧"放在一起

## 设计思路

1. **差异化风格**：根据不同平台的用户特点，设计了不同风格的关注引导
   - 头条：接地气、像邻居聊天
   - 知乎：理性专业、有价值感
   - 公众号：温暖真诚、像朋友邀请
   - 小红书：可爱俏皮、像闺蜜分享

2. **简短有效**：所有引导语都控制在1-2句话，不会显得啰嗦

3. **自然融入**：引导语的风格与平台整体调性一致，不会显得突兀

4. **明确位置**：为每个平台指定了引导语的具体位置，确保格式正确

## 预期效果

- 提升用户关注转化率
- 增强与读者的互动感
- 符合各平台的内容调性
- 不会显得生硬或过度营销

## 测试建议

建议在实际使用中观察：
1. 不同平台的关注转化率变化
2. 用户对引导语的反馈
3. 是否需要根据数据调整引导语风格
