# 文章标题 - 修复匿名用户上报标题显示通用名称问题

## 问题描述

匿名用户上报的文章标题显示为"公众号"、"小红书文章"等通用名称,而不是实际生成的文章标题。

## 问题分析

### 根本原因

在各个平台的 content script 和 `publishReporter.ts` 中,当无法从 `sessionStorage` 获取标题时,使用了 `document.title` 作为后备值。但是:

1. **微信公众号页面**: `document.title` 就是 "公众号"
2. **小红书页面**: `document.title` 就是 "小红书"  
3. **头条页面**: `document.title` 可能是通用名称

### 问题场景

通过数据库查询发现,这些标题为"公众号"、"小红书文章"的记录都是:
- `status='published'` (已发布状态)
- `account_id` 为匿名ID (如 `anon_1773911230347_j6dsy6mwi`)

这说明问题发生在**手动发布流程**:

1. 匿名用户通过插件生成文章
2. 标题被保存到 `sessionStorage.memoraid_pending_title`
3. 用户**手动**点击发布按钮(而不是自动发布)
4. 发布成功后,URL变化触发监听器上报
5. 此时 `sessionStorage` 中的标题可能已被清除或丢失(页面刷新、标签页切换等)
6. 代码使用 `document.title` 作为后备,导致标题显示为平台名称

### 为什么登录用户没有这个问题?

登录用户通常使用**自动发布**功能:
1. Background script 生成文章后立即上报(status='generated')
2. 然后自动打开发布页面并填充内容
3. 自动点击发布按钮
4. 发布成功后再次上报更新状态(status='published')
5. 整个过程中标题一直保存在 `sessionStorage` 中

而匿名用户可能:
- 关闭了自动发布
- 生成文章后过了很久才手动发布
- 刷新了页面或切换了标签页
- 导致 `sessionStorage` 中的标题丢失

### 受影响的文件

1. `src/content/xiaohongshu.ts` - 两处使用了默认标题 `'小红书文章'`
2. `src/content/weixin.ts` - 使用了 `document.title` 作为后备
3. `src/content/toutiao.ts` - 使用了 `document.title` 作为后备
4. `src/utils/publishReporter.ts` - 使用了 `document.title` 作为后备

## 解决方案

### 核心问题修复

发现了一个更严重的问题:**当AI生成的markdown包含frontmatter时,标题提取逻辑会失败**。

#### 问题代码 (src/background/index.ts)

```typescript
// 检查是否有H1标题 - 只检查开头
const hasH1 = /^\s*#\s+/.test(summary);

if (!hasH1) {
  // 如果没有H1,添加网页原始标题作为H1
  if (!isGeneric && extraction.title) {
    summary = `# ${extraction.title}\n\n` + summary;  // ← 添加了错误的标题!
  }
}

// 后面提取H1标题
const h1TitleMatch = summary.match(/^#\s+(.+)$/m);
if (h1TitleMatch && h1TitleMatch[1]) {
  finalTitle = h1TitleMatch[1].trim();  // ← 提取到的是刚添加的错误标题
}
```

#### 问题场景

当AI生成的markdown是这样的:

```markdown
---
title: 北京 - 城市概览与信息检索分析
date: 2026-03-25
---
# 北京 - 城市概览与信息检索分析

内容...
```

1. `hasH1`检查失败(因为开头是`---`而不是`#`)
2. 代码添加了`# 北京 - Google 搜索`(网页原始标题)
3. 后面提取H1时,提取到的是这个错误的标题
4. 最终历史记录和面板显示的都是`北京 - Google 搜索`

#### 修复方案

修改`hasH1`检查,使其支持frontmatter:

```typescript
// 修改前
const hasH1 = /^\s*#\s+/.test(summary);  // 只检查开头

// 修改后
const hasH1 = /^#\s+/m.test(summary);  // 使用多行模式,匹配任意行开头的H1
```

这样即使markdown开头有frontmatter,也能正确识别后面的H1标题。

### 其他修复

同时修复了以下问题,避免使用`document.title`作为后备值:

### 1. 小红书 (xiaohongshu.ts)

修改两处代码,当无法获取标题时:
1. 尝试从页面标题输入框提取
2. 如果还是没有,使用包含时间戳的默认值

```typescript
// 修改前
const finalTitle = pendingTitle || '小红书文章';

// 修改后
let finalTitle = pendingTitle;
if (!finalTitle) {
    // 尝试从标题输入框获取
    const titleInput = document.querySelector('input[placeholder*="标题"]') as HTMLInputElement;
    if (titleInput && titleInput.value.trim()) {
        finalTitle = titleInput.value.trim();
    } else {
        // 使用更有意义的默认值(包含时间戳)
        finalTitle = `小红书笔记_${new Date().toLocaleString('zh-CN', { timeZone: 'Asia/Shanghai' })}`;
    }
}
```

### 2. 微信公众号 (weixin.ts)

不再使用 `document.title`,改用包含时间戳的默认值:

```typescript
// 修改前
const finalTitle = (titleText || pendingTitle || getCurrentTitle() || document.title || '未命名文章').trim();

// 修改后
const pendingTitle = sessionStorage.getItem('memoraid_pending_title');
const currentTitle = getCurrentTitle();
const finalTitle = (
    titleText || 
    pendingTitle || 
    currentTitle || 
    `公众号文章_${new Date().toLocaleString('zh-CN', { timeZone: 'Asia/Shanghai' })}`
).trim();
```

### 3. 头条 (toutiao.ts)

同样不再使用 `document.title`:

```typescript
// 修改前
const finalTitle = (pendingTitle || getCurrentTitle() || document.title || '未命名文章').trim();

// 修改后
const pendingTitle = sessionStorage.getItem('memoraid_pending_title');
const currentTitle = getCurrentTitle();
const finalTitle = (
    pendingTitle || 
    currentTitle || 
    `头条文章_${new Date().toLocaleString('zh-CN', { timeZone: 'Asia/Shanghai' })}`
).trim();
```

### 4. 通用发布报告器 (publishReporter.ts)

修改 `reportOnce` 方法:

```typescript
// 修改前
const title = this.getCurrentTitle();
reportArticlePublish({
  platform: this.options.platform,
  title: title || document.title || '未命名文章',
  // ...
});

// 修改后
const title = this.getCurrentTitle();
// 不再使用 document.title 作为后备,因为它通常是平台名称(如"公众号"、"知乎")
// 使用更有意义的默认值(包含平台名称和时间戳)
const finalTitle = title || `${this.options.platform}文章_${new Date().toLocaleString('zh-CN', { timeZone: 'Asia/Shanghai' })}`;

reportArticlePublish({
  platform: this.options.platform,
  title: finalTitle,
  // ...
});
```
