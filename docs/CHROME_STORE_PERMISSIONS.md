# Chrome Web Store 权限说明

## Alarms 权限使用说明

### 权限名称
`alarms`

### 使用理由
Memoraid 使用 `alarms` 权限来实现定时任务功能,允许用户设置自动化的内容抓取和文章生成任务。

### 具体用途

1. **定时内容抓取**: 根据用户配置的时间间隔(如每天、每周),自动从指定的内容源(RSS订阅、网站等)抓取最新内容

2. **自动文章生成**: 在设定的时间点,自动使用AI处理抓取的内容,生成适合不同平台的文章

3. **多平台定时发布**: 支持在指定时间自动将生成的文章发布到微信公众号、知乎、头条、小红书等自媒体平台

4. **后台任务调度**: 即使用户关闭了扩展弹窗,定时任务仍能在后台按计划执行,确保内容创作的连续性

### 用户控制
- 用户可以在设置页面完全控制定时任务的启用/禁用
- 用户可以自定义任务执行的时间间隔
- 用户可以随时查看和修改定时任务配置
- 所有定时任务都需要用户主动配置后才会执行

### 隐私保护
- 定时任务仅在用户明确配置后才会运行
- 不会在用户不知情的情况下执行任何操作
- 所有任务执行记录都保存在本地,用户可随时查看

## 其他权限说明

### Storage 权限
用于保存用户的设置、文章历史记录、平台Cookie等本地数据

### ActiveTab 权限
用于读取当前标签页的网页内容,进行内容提取和处理

### Notifications 权限
用于在任务完成或出现错误时向用户发送通知提醒

### Cookies 权限
用于管理各个自媒体平台的登录状态,实现一键发布功能

### Identity 权限
用于用户账号的OAuth认证和云端数据同步

### Host Permissions (<all_urls>)
用于支持在任意网页上进行内容提取,以及与各个自媒体平台的API进行通信
