# 微博热搜抓取功能（第一阶段）

## 功能概述
在定时任务中添加微博热搜作为新闻源，自动抓取热搜列表，选择话题生成文章并发布到各平台。

## 实现进度

### ✅ 已完成
1. **微博热搜 Content Script** (`src/content/weibo-hotsearch.ts`)
   - 在微博热搜页面注入脚本
   - 抓取热搜列表（标题、链接、热度）
   - 响应 Background 的抓取请求

2. **Manifest 配置**
   - 添加微博热搜页面的 content_scripts 配置
   - 匹配规则：`*://weibo.com/hot/*`, `*://s.weibo.com/*`

### ⏳ 待实现
1. **Background 调度逻辑**
   - 检测微博热搜任务
   - 打开热搜页面并抓取列表
   - 随机选择热搜话题
   - 跳转到话题详情页

2. **话题内容提取**
   - 在话题详情页提取微博内容
   - 提取文本、图片、评论等
   - 发送给 AI 生成文章

3. **定时任务 UI**
   - 添加"微博热搜"新闻源选项
   - 配置热搜类型（文娱、科技、社会等）
   - 配置选择策略（随机、热度最高等）

## 技术实现

### 热搜抓取逻辑

```typescript
// 1. 查找热搜列表容器
const containerSelectors = [
    '.HotList_list_2LFQY',
    '[class*="HotList"]',
    '[class*="hotlist"]'
];

// 2. 提取热搜项
const itemSelectors = [
    'a[href*="/hot/"]',
    'a[href*="weibo.com"]'
];

// 3. 解析热搜数据
interface HotSearchItem {
    rank: number;      // 排名
    title: string;     // 标题
    link: string;      // 链接

}
```

## 数据流程（完整版）

```
定时任务触发
    ↓
Background 打开微博热搜页面
    ↓
Content Script 抓取热搜列表
    ↓
发送热搜列表给 Background
    ↓
Background 选择一个话题
    ↓
打开话题详情页
    ↓
Content Script 提取话题内容
    ↓
发送内容给 Background
    ↓
AI 生成文章
    ↓
发布到各平台
```
