# 小红书模板 - 跳过第一个模板随机选择

## 问题描述

发布小红书文章时，随机选择模板功能会包括第一个模板，但用户希望跳过第一个模板，只从第 2 个开始随机选择。

## 原因分析

原代码使用 `Math.floor(Math.random() * cards.length)` 来随机选择模板索引，这会生成 0 到 `cards.length - 1` 的随机数，包括索引 0（第一个模板）。

## 解决方案

修改随机选择逻辑，跳过第一个模板：

```typescript
// 随机选择一个（跳过第一个模板）
// 如果只有1个模板，则选择它；否则从第2个开始随机选择
const randomIndex = cards.length === 1 ? 0 : Math.floor(Math.random() * (cards.length - 1)) + 1;
```

### 逻辑说明

1. **只有 1 个模板**：`randomIndex = 0`，选择唯一的模板
2. **有多个模板**：
   - `Math.random() * (cards.length - 1)` 生成 0 到 `cards.length - 2` 的随机数
   - `+ 1` 后得到 1 到 `cards.length - 1` 的索引
   - 跳过索引 0（第一个模板）

### 示例

假设有 5 个模板（索引 0-4）：
- 原逻辑：随机选择 0、1、2、3、4
- 新逻辑：随机选择 1、2、3、4（跳过 0）
