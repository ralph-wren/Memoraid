# 定时任务 - 支持多个执行时间点

## 功能说明

定时任务现在支持设置多个执行时间点，例如：
- 每天 09:00、12:00、18:00 执行
- 每周一、周三 09:00、15:00 执行

## 实现方案

采用了"时间段选择器"方案：
```
执行时间：
[时] [09] : [分] [00]  [+ 添加]

已添加：
• 09:00 [删除]
• 12:00 [删除]
• 18:00 [删除]
```

### 2. 前端界面实现（`src/components/ScheduleSettings.tsx`）

#### 添加时间点
```typescript
const addExecutionTime = (taskId: string) => {
  setTasks(tasks.map(task => {
    if (task.id === taskId) {
      const times = task.executionTimes || [{ hour: task.hour, minute: task.minute }];
      const newTime = { hour: tempHour, minute: tempMinute };
      
      // 检查是否已存在
      const exists = times.some(t => t.hour === newTime.hour && t.minute === newTime.minute);
      if (exists) {
        return task;
      }
      
      // 添加并排序
      const newTimes = [...times, newTime].sort((a, b) => {
        if (a.hour !== b.hour) return a.hour - b.hour;
        return a.minute - b.minute;
      });
      
      return { ...task, executionTimes: newTimes };
    }
    return task;
  }));
};
```

#### 删除时间点
```typescript
const removeExecutionTime = (taskId: string, index: number) => {
  setTasks(tasks.map(task => {
    if (task.id === taskId) {
      const times = task.executionTimes || [{ hour: task.hour, minute: task.minute }];
      
      // 至少保留一个时间点
      if (times.length <= 1) {
        return task;
      }
      
      const newTimes = times.filter((_, i) => i !== index);
      return { ...task, executionTimes: newTimes };
    }
    return task;
  }));
};
```

#### 判断是否应该执行任务
```typescript
function shouldRunTask(task: ScheduledTask, now: Date): boolean {
  const currentHour = now.getHours();
  const currentMinute = now.getMinutes();
  
  // 优先使用 executionTimes，否则使用 hour/minute（向后兼容）
  const times = task.executionTimes || [{ hour: task.hour, minute: task.minute }];
  
  // 遍历所有执行时间点，只要有一个匹配就触发
  const timeMatches = times.some(time => 
    time.hour === currentHour && time.minute === currentMinute
  );
  
  if (!timeMatches) {
    return false;
  }
  
  // ... 其他判断逻辑（每天/每周/间隔模式）
}
```

### 5. 任务描述显示修改

#### 格式化任务描述
```typescript
const formatScheduleDesc = (task: ScheduledTask): string => {
  const times = task.executionTimes || [{ hour: task.hour, minute: task.minute }];
  const timesStr = times.map(t => 
    `${t.hour.toString().padStart(2, '0')}:${t.minute.toString().padStart(2, '0')}`
  ).join('、');
  
  if (task.scheduleType === 'daily') {
    return `每天 ${timesStr}`;
  } else if (task.scheduleType === 'weekly') {
    const days = task.weekDays?.map(d => `周${['日','一','二','三','四','五','六'][d]}`).join('、');
    return `每${days} ${timesStr}`;
  } else {
    return `每 ${task.intervalMinutes} 分钟`;
  }
};
```

## 向后兼容

为了保证旧数据的兼容性：
1. 保留了 `hour` 和 `minute` 字段
2. 如果 `executionTimes` 不存在，自动使用 `hour/minute` 构建单个时间点
3. 新任务默认包含一个执行时间 `[{ hour: 9, minute: 0 }]`

## 注意事项

1. 至少需要保留一个执行时间点，不能全部删除
2. 添加时间点时会自动去重和排序
3. 时间点按照"小时:分钟"升序排列
4. 间隔模式下不支持多时间点（因为是按间隔执行）
5. 所有时间都是中国时区（UTC+8）
