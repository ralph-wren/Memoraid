 # 小红书提示词优化 - 禁止过度口语化标题

## 问题描述
当前小红书提示词会生成过度口语化和情绪化的标题,例如:
- ❌ "家人们，今天刷到一个话题，直接给我笑不活"
- ❌ "家人们，我真的崩了！😭"
- ❌ "家人们，谁懂啊！今天的热搜第一也太好笑了"

这些标题的问题:
1. 过度使用"家人们"等网络用语
2. 纯情绪化表达,缺乏实质内容
3. 使用"今天刷到"、"这个话题"等模糊指代
4. 没有说明具体事件主体和内容

## 解决方案

### 修改文件
`src/utils/prompts.ts` 第890-905行左右

### 需要修改的内容

#### 1. 修改"默认人设"部分
```typescript
// 修改前:
- **说话习惯**：多用感叹号，经常用"家人们"、"建议收藏"、"亲测有效"、"真的绝了"
- **记忆钩子**：结尾引导收藏，比如"这波不收藏真的亏大了，快存起来！"

// 修改后:
- **说话习惯**：语气亲切自然，适度使用感叹号表达情绪
- **记忆钩子**：结尾引导收藏，比如"记得收藏起来慢慢看！"
```

#### 2. 添加标题规则
在"### 写作风格要求"的"**标题**"部分,添加以下规则:

```typescript
- **标题**：
  - 第一行用# 标记为文章标题
  - ✅ 标题必须具体明确，说明事件主体和核心内容
  - ✅ 标题要有信息量，让读者一眼知道文章讲什么
  - ❌ 严禁使用"家人们"、"谁懂啊"、"真的崩了"等过度口语化表达
  - ❌ 严禁使用"今天刷到"、"这个话题"等模糊指代
  - ❌ 严禁纯情绪化表达，必须包含实质内容
  - 示例：
    - ❌ 不好："家人们，今天刷到一个话题，直接给我笑不活"
    - ✅ 好："周杰伦巴黎时装周后罕见更新ins，配乐和文案都太有东西了！"
    - ❌ 不好："家人们，我真的崩了！😭"
    - ✅ 好："于晓光因秋瓷炫刷卡买包睡不着觉？别被标题骗了，真相甜到齁！"
  - 中间不需要段落小标题，全文一气呵成，不需要加粗，不需要加下划线，不需要加emoji
```

#### 3. 更新版本号
将版本号从 `1.2.2` 更新为 `1.3.0`:

```typescript
export const PROMPT_VERSIONS = {
  TOUTIAO: '1.2.2',
  ZHIHU: '1.2.2',
  WEIXIN: '1.2.2',
  XIAOHONGSHU: '1.3.0' // 优化标题规则，禁止过度口语化和情绪化表达，要求标题具体明确
};
```

## 预期效果

修改后生成的标题应该:
1. 具体明确,说明事件主体
2. 有信息量,让人知道讲什么
3. 不使用过度口语化表达
4. 不纯情绪化,包含实质内容

## 手动修改步骤

1. 打开 `src/utils/prompts.ts`
2. 找到第890行左右的"### 默认人设（小红书平台专属）"
3. 按照上述内容进行修改
4. 运行 `npm run build` 确认无错误
5. 测试生成文章,检查标题质量

## 注意事项

- 修改后需要重新生成文章才能看到效果
- 已生成的文章不会受影响
- 建议清除浏览器缓存后测试
