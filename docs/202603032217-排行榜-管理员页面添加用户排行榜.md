# 排行榜功能 - 管理员页面添加用户排行榜

## 更新时间
2026-03-03 22:17

## 功能描述
在管理员后台页面添加排行榜模块,展示三个榜单:
1. 📝 文章数量榜 - 统计每个用户生成的文章总数
2. ⚡ Token 消耗榜 - 统计每个用户消耗的总 Token 数
3. 💎 充值金额榜 - 统计每个用户的累计充值金额

## 技术实现

### 1. 后端 API
**路径**: `/api/admin/leaderboards`
**方法**: GET
**参数**: 
- `limit`: 返回排行榜前N名,默认10

**返回数据结构**:
```json
{
  "articles": [
    {
      "email": "user@example.com",
      "provider": "email",
      "article_count": 50,
      "last_publish_time": "2026-03-03T10:00:00Z"
    }
  ],
  "tokens": [
    {
      "email": "user@example.com",
      "provider": "email",
      "article_count": 50,
      "total_tokens": 150000
    }
  ],
  "recharge": [
    {
      "email": "user@example.com",
      "provider": "email",
      "total_amount": 500.00,
      "order_count": 5,
      "last_recharge_time": "2026-03-03T10:00:00Z"
    }
  ]
}
```

### 2. 数据库查询

#### 文章数量排行榜
```sql
SELECT 
  u.email,
  u.provider,
  COUNT(a.id) as article_count,
  MAX(a.publish_time) as last_publish_time
FROM users u
LEFT JOIN accounts acc ON acc.user_id = u.id
LEFT JOIN articles a ON a.account_id = acc.id
GROUP BY u.id
HAVING article_count > 0
ORDER BY article_count DESC
LIMIT ?
```

#### Token 消耗排行榜
```sql
SELECT 
  u.email,
  u.provider,
  COUNT(a.id) as article_count,
  SUM(
    CAST(
      json_extract(a.extra_info, '$.totalTokens') AS INTEGER
    )
  ) as total_tokens
FROM users u
LEFT JOIN accounts acc ON acc.user_id = u.id
LEFT JOIN articles a ON a.account_id = acc.id
WHERE json_extract(a.extra_info, '$.totalTokens') IS NOT NULL
GROUP BY u.id
HAVING total_tokens > 0
ORDER BY total_tokens DESC
LIMIT ?
```

#### 充值金额排行榜
```sql
SELECT 
  u.email,
  u.provider,
  SUM(po.amount) as total_amount,
  COUNT(po.id) as order_count,
  MAX(po.paid_at) as last_recharge_time
FROM users u
LEFT JOIN payment_orders po ON po.user_id = u.id
WHERE po.status = 'paid'
GROUP BY u.id
HAVING total_amount > 0
ORDER BY total_amount DESC
LIMIT ?
```

### 3. 前端实现

#### 侧边栏导航
在"文章管理"和"订单审核"之间添加了"🏆 排行榜"导航项

#### HTML 结构
使用网格布局展示三个排行榜卡片:
```html
<div style="display:grid;grid-template-columns:repeat(auto-fit,minmax(350px,1fr));gap:24px">
  <!-- 三个排行榜卡片 -->
</div>
```

#### JavaScript 函数

**fetchLeaderboards()**: 
- 从后端 API 获取排行榜数据
- 处理加载失败的情况

**renderLeaderboards(data)**:
- 渲染三个排行榜的数据
- 前三名显示特殊徽章: 🥇🥈🥉
- 其他名次显示数字排名
- 显示用户邮箱、统计数据、时间信息

**switchTab()**:
- 添加排行榜标签页切换逻辑
- 首次加载时自动获取数据

#### CSS 样式
```css
.leaderboard-item:hover {
    transform: translateX(4px);
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
}
```

## 界面展示

每个排行榜项包含:
- 排名徽章 (🥇🥈🥉 或数字)
- 用户邮箱 (可悬停查看完整邮箱)
- 辅助信息 (最近发布时间/文章数/最近充值时间)
- 主要指标 (文章数/Token数/充值金额)
- 单位说明 (篇文章/Tokens/笔订单)

## 注意事项
1. Token 消耗榜只统计 `extra_info` 中包含 `totalTokens` 字段的文章
2. 充值金额榜只统计状态为 `paid` 的订单
3. 排行榜数据在首次访问时加载,后续切换标签页不会重新加载
4. 所有金额显示保留两位小数
5. Token 数量使用千分位分隔符格式化显示
