# 邮件一键审批功能实现

## 功能描述

管理员收到充值通知邮件后，可以直接点击邮件中的"批准"或"拒绝"按钮完成审批，无需登录管理后台。

## 实现方案

### 1. Token机制

为每个订单生成唯一的审批token，包含：
- 订单ID
- 操作类型（approve/reject）
- 过期时间（24小时）

```typescript
async function generateApprovalToken(orderId: string, action: 'approve' | 'reject'): Promise<string> {
  const payload = {
    orderId,
    action,
    exp: Date.now() + 24 * 60 * 60 * 1000 // 24小时过期
  };
  const data = JSON.stringify(payload);
  return btoa(data); // Base64编码
}
```

### 2. 邮件中的审批按钮

在充值通知邮件中添加两个醒目的按钮：

```html
<a href="${backendUrl}/api/payment/approve?token=${approveToken}">
  ✓ 批准充值
</a>
<a href="${backendUrl}/api/payment/approve?token=${rejectToken}">
  ✗ 拒绝充值
</a>
```

按钮样式：
- 批准按钮：绿色渐变背景
- 拒绝按钮：红色渐变背景
- 带阴影效果，醒目易点击

### 3. 审批API端点

```
GET /api/payment/approve?token=xxx
```

处理流程：
1. 验证token有效性和是否过期
2. 检查订单是否存在
3. 检查订单状态（避免重复审批）
4. 执行审批操作：
   - 批准：更新订单状态 + 增加用户额度
   - 拒绝：只更新订单状态
5. 返回精美的结果页面

### 4. 结果页面

审批成功后显示精美的结果页面，包含：
- 大图标（✓ 或 ✗）
- 操作结果标题
- 订单详情（订单号、金额、额度、时间）
- 返回管理后台的链接

## 安全措施

1. **Token过期机制**
   - 审批链接24小时后自动失效
   - 防止长期有效的链接被滥用

2. **重复审批检查**
   - 检查订单状态，已处理的订单无法再次审批
   - 显示友好提示信息

3. **订单验证**
   - 验证订单是否存在
   - 验证token格式是否正确

## 使用流程

### 管理员视角

1. 收到充值通知邮件
2. 查看订单详情（用户、金额、额度）
3. 点击"批准充值"或"拒绝充值"按钮
4. 浏览器打开结果页面，显示审批结果
5. （可选）点击"前往管理后台"查看更多详情

### 用户视角

1. 提交充值申请
2. 等待管理员审批
3. 审批通过后，额度自动增加
4. 可以继续使用服务

## 邮件内容优化

### 充值通知邮件包含

1. **醒目的标题**
   - 💰 待审核充值: XX元

2. **订单详情表格**
   - 用户邮箱
   - 订单号
   - 充值金额（红色大字）
   - 获得额度（绿色）
   - 提交时间

3. **快速审批区域**
   - 说明文字："点击下方按钮即可完成审批，无需登录后台"
   - 批准按钮（绿色）
   - 拒绝按钮（红色）
   - 有效期提示："审批链接24小时内有效"

4. **备用链接**
   - "或前往管理后台查看详情"按钮

5. **警告提示**
   - "请在审核前确认用户已完成付款，避免误操作"

## 优点

1. **快速便捷**
   - 无需登录，一键审批
   - 移动端友好，随时随地处理

2. **减少步骤**
   - 传统流程：收邮件 → 登录后台 → 找订单 → 审批
   - 新流程：收邮件 → 点击按钮

3. **提高效率**
   - 审批速度更快
   - 用户等待时间更短

4. **用户体验好**
   - 精美的结果页面
   - 清晰的操作反馈

## 注意事项

1. **Token安全**
   - Token通过邮件传输，存在泄露风险
   - 建议对大额订单仍使用后台审核

2. **邮件客户端兼容性**
   - 按钮样式在不同邮件客户端可能显示不同
   - 提供纯文本链接作为备用

3. **网络环境**
   - 需要能访问后端API
   - 移动网络可能较慢

## 技术细节

```typescript
const approveToken = await generateApprovalToken(orderId, 'approve');

```

### Token验证
```typescript
function verifyApprovalToken(token: string) {
  try {
    const data = atob(token);
    const payload = JSON.parse(data);
    if (payload.exp < Date.now()) return null; // 已过期
    return payload;
  } catch (e) {
    return null; // 无效token
  }
}
```
