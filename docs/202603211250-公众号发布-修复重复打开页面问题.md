# 公众号发布 - 修复直接打开编辑器URL导致服务器错误

## 问题描述

点击公众号发布按钮后，会跳转到一个显示"服务器出错"的空白页面，无法正常进入编辑器。

## 原因分析

问题出在 background 直接打开编辑器 URL 时，URL 中的 `token` 参数为空：

```
https://mp.weixin.qq.com/cgi-bin/appmsg?t=media/appmsg_edit_v2&action=edit&isNew=1&type=10&createType=0&token=&lang=zh_CN
```

微信公众号的编辑器需要有效的 token 才能访问，直接打开没有 token 的 URL 会导致服务器返回错误。

正确的流程应该是：
1. 打开公众号首页
2. 点击"文章"按钮
3. 微信会自动生成带有有效 token 的编辑器 URL 并跳转

## 解决方案

修改 background 逻辑，不再直接打开编辑器 URL，而是打开首页，让 content script 点击"文章"按钮：

### 修改 background/index.ts

```typescript
// 打开或激活微信公众号页面
// 注意：不要直接打开编辑器 URL（因为 token 参数需要从首页获取）
// 正确做法：打开首页，让 content script 点击"文章"按钮进入编辑器
const homeUrl = 'https://mp.weixin.qq.com/';

// 优先查找编辑器页面
const editorTabs = await chrome.tabs.query({ url: '*://mp.weixin.qq.com/*appmsg_edit*' });
// 其次查找首页
const homeTabs = await chrome.tabs.query({ url: 'https://mp.weixin.qq.com/' });
// 最后查找所有微信页面
const allTabs = await chrome.tabs.query({ url: '*://mp.weixin.qq.com/*' });

let tab: chrome.tabs.Tab;

if (editorTabs.length > 0) {
  // 找到编辑器页面，复用它
  tab = editorTabs[0];
  await chrome.tabs.update(tab.id!, { active: true });
  // 重新加载页面以触发 content script
  await chrome.tabs.reload(tab.id!);
} else if (homeTabs.length > 0) {
  // 如果已有首页，激活它，让 content script 点击"文章"按钮
  tab = homeTabs[0];
  await chrome.tabs.update(tab.id!, { active: true });
  // 刷新页面以触发 content script
  await chrome.tabs.reload(tab.id!);
} else if (allTabs.length > 0) {
  // 如果有其他微信页面，导航到首页
  tab = allTabs[0];
  await chrome.tabs.update(tab.id!, { active: true, url: homeUrl });
} else {
  // 否则创建新标签页，打开首页
  tab = await chrome.tabs.create({
    url: homeUrl,
    active: true
  });
}
```

### 修改 content/weixin.ts

恢复简单的首页检测逻辑：

```typescript
// 登录成功后清除标记
sessionStorage.removeItem('memoraid_cookie_cleared');

// 如果在首页，点击"文章"按钮进入编辑器
if (pageState === 'home') {
  logger.log('📍 当前在首页，正在进入文章编辑页面...', 'info');
  
  if (await clickArticleButton()) {
    // 等待页面跳转
    await new Promise(r => setTimeout(r, 3000));
    
    // 重新检测状态
    pageState = await waitForPageReady(10000);
    logger.log(`跳转后页面状态: ${pageState}`, 'info');
  } else {
    logger.log('❌ 无法进入编辑页面，请手动点击"文章"按钮', 'error');
    return;
  }
}
```

## 逻辑说明

修改后的流程：

1. **background 打开首页**：
   - 优先查找已有的编辑器页面，如果有就复用
   - 其次查找首页，如果有就激活并刷新
   - 如果有其他微信页面，导航到首页
   - 如果没有任何微信页面，创建新标签页打开首页

2. **content script 点击"文章"按钮**：
   - 检测到在首页时，点击"文章"按钮
   - 微信会自动生成带有有效 token 的编辑器 URL
   - 跳转到编辑器页面

3. **优势**：
   - token 由微信自动生成，保证有效性
   - 不会出现"服务器出错"的问题
   - 流程更符合微信公众号的正常使用方式

## 预期效果

修复后，发布公众号文章时：
- 会先打开公众号首页
- content script 自动点击"文章"按钮
- 进入带有有效 token 的编辑器页面
- 不会出现"服务器出错"的问题
- 不会重复打开多个编辑器页面

- `src/background/index.ts` - 后台脚本（打开公众号页面逻辑）
- `src/content/weixin.ts` - 公众号内容脚本（页面导航和填充逻辑）
