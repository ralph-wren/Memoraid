# 提示词优化 - 增强文章原创性识别

## 问题描述
头条平台频繁提示"笔记未通过原创声明认证"，原因包括：
1. 存在与他人相似或重复的素材内容
2. 存在其他平台或用户信息
3. 存在直接引用或简单改编他人作品的内容
4. 存在模仿化/单一化创作内容
5. 存在其他原创性存疑的内容

## 解决方案

### 1. 新增"深度改写与原创性增强"规则
在通用提示词中新增 `4.4 深度改写与原创性增强` 章节，包含以下核心要求：

#### 内容重组与深度改写
- **严禁直接复述原文**：不要只是换个说法，要重新组织逻辑
- **必须重新构建叙事结构**：
  - 改变信息呈现的顺序
  - 合并或拆分原文的段落，形成新的逻辑链条
  - 用自己的话重新串联所有信息点
- **增加个人分析和解读**：
  - 每个关键信息点后面，必须加上自己的分析、评论或延伸思考
  - 不要只说"是什么"，要说"为什么"和"意味着什么"
  - 比例建议：原文信息占40%，个人分析占60%

#### 增加独特视角和深度
- **提供新的观察角度**：
  - 从不同利益相关方的角度分析
  - 联系到更大的社会背景或行业趋势
  - 提出原文没有讨论的潜在影响或隐藏问题
- **加入对比和类比**：
  - 对比类似事件的不同处理方式
  - 用生活化的比喻解释复杂问题
  - 引用相关的历史案例或行业经验

#### 语言表达的个性化
- **形成独特的表达风格**：
  - 用自己的语言习惯和表达方式
  - 加入个人化的情绪和态度
  - 使用生动的描述和具体的场景化表达
- **避免套路化表达**：
  - 不要用"众所周知"、"不言而喻"等空话
  - 不要用"引发热议"、"网友纷纷表示"等新闻腔
  - 不要用"值得深思"、"令人深省"等结尾套话

#### 去除平台痕迹
- **严禁保留任何平台特征**：
  - 不要保留原文的标题格式
  - 不要保留原文的段落结构和分段方式
  - 不要保留原文的语气和表达习惯
  - 不要保留原文的emoji使用方式
- **彻底改写表达方式**：
  - 长句改短句，短句改长句
  - 陈述句改反问句，反问句改陈述句
  - 正面表达改侧面烘托，侧面烘托改正面表达

#### 内容扩充与丰富
- **补充背景信息**：
  - 如果原文缺少背景，要补充（但不要编造具体数据）
  - 解释专业术语和行业知识
  - 提供相关的常识性信息
- **增加实用价值**：
  - 给出建议或启示
  - 提供可操作的思路
  - 总结可借鉴的经验教训

#### 原创性自检清单
在生成文章后，AI会自我检查：
- [ ] 文章的叙事结构与原文完全不同
- [ ] 每个段落都有自己的分析和观点
- [ ] 没有大段直接复述原文内容
- [ ] 语言表达方式与原文明显不同
- [ ] 提供了原文没有的新视角或深度分析
- [ ] 完全看不出内容来自哪个平台
- [ ] 文章读起来像是原创思考

### 2. 优化效果预期
通过以上优化，生成的文章将具备：
- **更高的原创度**：不再是简单改写，而是深度重组和再创作
- **更强的个性化**：有明确的个人观点和独特视角
- **更好的可读性**：逻辑更清晰，表达更生动
- **更低的平台痕迹**：完全看不出内容来源

### 3. 使用建议
- 生成文章后，建议先在头条平台测试原创性
- 如果仍然提示原创性问题，可以尝试：
  - 增加更多个人分析和观点
  - 进一步改变叙事结构
  - 补充更多背景信息和延伸思考
- 对于特别敏感的话题，建议手动再次润色

## 注意事项
1. 这些规则主要针对头条平台，但也适用于其他平台
