# 小红书简介 - 修复简介缺失问题

## 问题描述

用户反馈生成的小红书文章开头的简介又没了，文章直接从标题跳到正文，缺少了 `[简介]` 部分。

## 根本原因分析

检查小红书提示词后发现存在以下冲突：

### 1. Emoji 规则冲突

**冲突位置**：`src/utils/prompts.ts` 第960行附近

```typescript
### 默认人设（小红书平台专属）
- **视觉风格**：段落之间空行，每段文字前面或后面必定带有 Emoji  // ❌ 冲突
```

vs

```typescript
#### 正文要求（CRITICAL - 严禁使用表情包和图片占位符）
- **严禁使用任何 Emoji 表情包**！  // ✅ 正确规则
```

**问题**：默认人设要求"必定带有 Emoji"，但正文要求"严禁使用 Emoji"，AI 收到矛盾指令。

### 2. 简介强调不足

虽然提示词中有简介要求，但没有足够强调：
- 没有明确说明"简介是必须的，不要跳过"
- 没有说明"简介和正文是两个独立部分"
- 通用提示词中的"开头"要求可能让 AI 误以为直接写正文开头即可

## 解决方案

### 1. 移除 Emoji 冲突规则

**文件**：`src/utils/prompts.ts` 第960行附近

```typescript
### 默认人设（小红书平台专属）
- **笔名**：小木（M木）
- **身份**：一个热爱分享的技术博主/生活极客，擅长把复杂的事讲得简单且有质感
- **视觉风格**：段落之间空行，每段文字简短易读  // ✅ 修改：移除 Emoji 要求
- **说话习惯**：语气亲切自然，适度使用感叹号表达情绪
- **记忆钩子**：结尾引导收藏，比如"记得收藏起来慢慢看！"
```

### 2. 强化简介必须包含的要求

**文件**：`src/utils/prompts.ts` 第987行附近

```typescript
#### 笔记简介（CRITICAL）
- ⚠️⚠️⚠️ **简介是必须的**！不要跳过简介直接写正文！  // ✅ 新增强调
- 简介必须紧跟在标题后面，在正文之前
- 简介**必须**使用以下格式标记：`[简介]简介内容`
- 简介长度：50-80字
- 简介要概括文章核心内容，吸引读者点击
- 简介要包含关键信息点，但不能剧透全部内容
- 简介语气要轻松自然，**严禁使用emoji表情包**
- ⚠️ **简介和正文是两个独立部分**：简介用 `[简介]` 标记，正文不需要标记  // ✅ 新增说明
- 示例格式：
  - `[简介]最近发现一个超好用的工具，帮我节省了一半工作时间！分享给需要的姐妹们`
  - `[简介]这个方法我用了3个月，效果真的绝了！建议收藏慢慢看`
  - `[简介]踩了无数坑总结出来的经验，看完能少走很多弯路`
```

### 3. 在正文要求中再次强调

**文件**：`src/utils/prompts.ts` 第1000行附近

```typescript
#### 正文要求（CRITICAL - 严禁使用表情包和图片占位符）
- ⚠️ **正文必须在简介之后**！不要跳过简介直接写正文！  // ✅ 新增强调
- **分段分段再分段**！每一行或每两行一个段落
- **严禁使用任何 Emoji 表情包**！全文必须是纯文字内容，**每段后面严禁添加emoji表情**
- ❌❌❌ **严禁使用图片占位符**！小红书平台不需要 `[图片: xxx]` 这种格式，全文只用纯文字表达
- ❌❌❌ **严禁使用 `[图片: xxx]` 格式**！这是其他平台的规则，小红书不需要！
- **不允许其他方式充作标题来强行分段，比如【】里面添加内容用来总结，必须一口气说完**
- 中间不需要段落小标题，全文一气呵成，不需要加粗，不需要加下划线
- 用自然的语言表达情绪和重点，不要依赖表情符号
- 正文开头：直接抛出最有意思的点，前3句话必须让人想继续读  // ✅ 新增：说明"正文开头"是指正文的第一段
```

### 4. 添加格式检查清单

**文件**：`src/utils/prompts.ts` 第1023行附近

```typescript
#### 完整格式示例（CRITICAL - 必须严格遵守）
⚠️⚠️⚠️ **以下是小红书笔记的完整格式，必须严格按照这个顺序生成，不要遗漏任何部分：**

```
# 这是标题

[简介]这是简介内容，50-80字，纯文字不带表情

这是正文第一段，自然流畅的表达

这是正文第二段，继续分享内容

...更多正文段落...

评论区聊聊吧

#话题1 #话题2 #话题3 #话题4 #话题5
```

**格式检查清单（生成前必须确认）**：  // ✅ 新增检查清单
1. ✅ 第一行是标题（用 # 标记）
2. ✅ 第二部分是简介（用 [简介] 标记）← **不要遗漏这一部分！**
3. ✅ 第三部分是正文（多个段落，纯文字）
4. ✅ 最后是话题标签（用 # 标记）
5. ❌ 没有图片占位符
6. ❌ 没有封面提示词
7. ❌ 没有摘要
8. ❌ 话题标签后面没有任何内容
```

## 修改要点

### 多层强调策略

1. **移除冲突**：删除默认人设中"必定带有 Emoji"的要求
2. **简介章节**：用 ⚠️⚠️⚠️ 强调"简介是必须的，不要跳过"
3. **正文章节**：再次强调"正文必须在简介之后"
4. **格式示例**：添加完整的格式检查清单，明确标注"不要遗漏这一部分"
5. **区分概念**：明确说明"简介和正文是两个独立部分"

### 为什么会缺失简介

1. **规则冲突**：Emoji 要求冲突让 AI 困惑，可能跳过某些部分
2. **强调不足**：没有明确说明简介是"必须的"，AI 可能认为是可选的
3. **概念混淆**：通用提示词中的"开头"要求，AI 可能误以为是正文开头，跳过简介
4. **格式不清**：没有明确的检查清单，AI 生成时可能遗漏

1. 简介和正文是两个独立部分，不要混淆
2. 简介用 `[简介]` 标记，正文不需要标记
3. 通用提示词中的"开头"指的是正文开头，不是文章开头
4. 必须严格按照：标题 → 简介 → 正文 → 话题标签 的顺序生成
5. 如果 AI 仍然跳过简介，需要在 content script 中添加验证和提示逻辑
