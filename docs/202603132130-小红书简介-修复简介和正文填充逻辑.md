# 小红书简介功能 - 修复简介标记和正文提示显示问题

## 问题描述

用户反馈截图显示两个问题：
1. **`[简介]` 标记文字显示在正文中**，没有被移除
2. **`正文:` 这个提示文字也出现了**，不应该显示给用户

## 问题分析

### 问题1：`[简介]` 标记未移除
原因：正则表达式 `/\[简介\].+?(?:\n|$)/` 只匹配一行，如果有多个 `[简介]` 标记或者标记后有换行，会导致移除不完整。

### 问题2：`正文:` 提示出现
原因：AI在生成文章时，自己添加了 `正文:` 这样的中间提示标记，但代码中没有移除这个标记。

## 修改内容

### 1. 增强简介标记移除逻辑 (src/background/index.ts)

**修改前**：
```typescript
// 只移除一次
cleanedContent = cleanedContent.replace(/\[简介\].+?(?:\n|$)/, '').trim();
```

**修改后**：
```typescript
// 使用全局匹配，移除所有[简介]标记（包括换行）
cleanedContent = cleanedContent.replace(/\[简介\][^\n]*\n*/g, '').trim();
```

### 2. 添加"正文:"标记移除逻辑 (src/background/index.ts)

```typescript
// 移除可能存在的"正文:"标记（AI有时会自己添加这种中间提示）
cleanedContent = cleanedContent.replace(/^正文[:：]\s*\n*/gm, '').trim();
```

说明：
- 使用 `^` 匹配行首
- 同时匹配中文冒号 `:` 和英文冒号 `：`
- 使用 `gm` 标志进行全局多行匹配
- 移除冒号后的空格和换行

### 3. 更新提示词禁止生成中间标记 (src/utils/prompts.ts)

在"正文要求"部分添加：
```markdown
- ❌❌❌ **严禁添加"正文:"、"内容:"等中间提示标记**！简介后直接开始写正文内容，不需要任何标记！
```

并添加正确/错误示例对比：

**正确示例**：
```
# 标题

[简介]这是简介内容

家人们，今天刷到一个特别有意思的现象。
```

**错误示例**：
```
# 标题

[简介]这是简介内容

正文:  ← 错误！不要添加这种标记！

家人们，今天刷到一个特别有意思的现象。
```

## 工作流程

1. **AI生成文章**：标题 + `[简介]简介内容` + `正文:` + 正文 + 话题
2. **background.ts 清理**：
   - 移除标题（H1）
   - 提取简介到 `intro` 字段
   - 移除所有 `[简介]` 标记（全局匹配）
   - 移除 `正文:` 标记（全局多行匹配）
   - 移除话题标签
3. **xiaohongshu.ts 填充**：
   - 编辑页：标题 + 纯正文
   - 发布设置页：简介 + 话题
