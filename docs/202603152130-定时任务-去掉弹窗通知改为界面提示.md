## 用户体验改进

### 之前的问题：
1. 弹窗通知会打断用户操作，体验不好
2. 删除任务时的确认对话框多余，增加操作步骤
3. 添加重复时间点或删除最后一个时间点时的提示打断操作
4. 添加时间点时自动保存，导致用户添加的时间点被删除（因为保存时会覆盖）
5. 底部和顶部都有保存按钮，界面冗余

### 现在的改进：
1. 状态提示直接显示在任务卡片上，不打断用户操作
2. 删除任务直接删除，操作更流畅
3. 添加/删除时间点静默处理，不弹窗提示
4. 所有修改都需要手动保存，避免意外覆盖
5. 统一使用顶部保存按钮，界面更简洁
6. 有未保存修改时，保存按钮显示为橙色，提醒用户保存

## 注意事项

1. 状态提示只在 1 分钟内显示，避免过时信息干扰
2. 正在执行中的状态会一直显示，直到任务完成
3. 所有修改都需要点击保存按钮才会生效
4. 保存按钮颜色：橙色=有未保存修改，灰色=无修改
5. 删除任务不再有确认提示，请谨慎操作（可以通过复制按钮备份任务）
6. 添加重复时间点会静默忽略，不会弹窗提示
7. 删除最后一个时间点会静默拒绝，至少保留一个时间点

## 测试建议

1. 创建新任务，添加多个执行时间点，不保存，刷新页面验证是否丢失
2. 添加时间点后点击保存，刷新页面验证是否保存成功
3. 手动执行任务，观察状态提示是否正确显示
4. 等待定时任务自动执行，观察状态提示是否正确更新
5. 验证不再有弹窗通知打断操作
