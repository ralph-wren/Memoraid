# 用户页平台筛选只显示实际有内容的平台

## 本次调整

- `/user` 页的平台筛选改为只展示当前用户实际有文章的平台
- 服务端接口 `/api/platforms` 在已登录场景下按用户文章数据返回平台列表
- 统一过滤掉 `test` 平台，避免测试数据进入正式页面
- 前端增加兜底过滤：即使接口返回异常数据，也不会把 `test` 渲染出来
- 如果当前选中的平台已经不存在，筛选会自动回退到“全部”

## 校验结果

- `./node_modules/.bin/tsc --noEmit`：通过
- `npm run build`：失败，仍然是本机 Node 18 环境下 `undici` 缺少全局 `File`，不是本次改动引起
