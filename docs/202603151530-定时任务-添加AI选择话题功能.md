# 定时任务 - 添加 AI 选择话题功能

## 需求描述

1. 定时任务默认使用今日热榜，去掉新闻源类型选择按钮
2. 在热榜 Node ID 输入框上方添加获取说明和网站链接
3. 添加"单次生成文章数量"选项（1-5篇）
4. 添加"自定义提示词"输入框，用户可以输入选题要求
5. 修改执行逻辑：AI 从热榜列表中根据用户要求选择指定数量的话题，然后生成文章

## 实现细节

### AI 选择话题函数（`selectArticlesWithAI`）

位置：`src/background/scheduler.ts`

功能：
1. 从热榜列表中提取前 50 条话题（避免 token 过多）
2. 构建 AI 提示词，包含：
   - 系统提示：说明任务和返回格式要求（JSON 对象，包含序号和理由）
   - 用户提示：热榜列表 + 选题数量 + 自定义要求
3. 调用 AI API（使用与主流程相同的认证逻辑）
4. 解析 AI 返回的选择结果（JSON 格式，包含 index 和 reason）
5. 在日志中打印每个话题的选择理由
6. 根据序号提取对应的文章
7. 如果 AI 调用失败，降级为随机选择模式

**重要更新（2026-03-15）**：
- ✅ 所有情况（包括只选 1 篇）都使用 AI 选择，不再随机
- ✅ AI 返回格式改为 JSON 对象，包含选择理由
- ✅ 在日志中打印每个话题的选择理由

关键代码：
```typescript
// AI 提示词示例（新格式）
```

### 执行流程

1. 用户配置定时任务：
   - 选择今日热榜 Node ID
   - 设置生成文章数量（1-5 篇）
   - 可选：添加自定义提示词

2. 定时触发执行：
   - 打开今日热榜页面，抓取热榜列表
   - 如果 `articleCount > 1` 或有自定义提示词，调用 AI 选择话题
   - 否则随机选择 1 个话题
   - 循环处理每个选中的话题：
     * 打开文章页面
     * 抓取内容
     * AI 生成文章
     * 发布到各平台
   - 更新任务状态，发送通知
