# 文章列表 - 修复平台筛选初始加载问题

## 问题描述
页面刷新时，文章列表的平台筛选按钮区域不显示，需要等待一会（API返回后）才显示，用户体验不好。

## 问题原因
1. `platformFilterBar` 元素默认设置为 `display:none`
2. 只有在 `switchTab('articles')` 时才会显示
3. 页面初始化时默认就是文章列表Tab，但没有显式调用显示逻辑
4. 导致平台筛选区域在 `renderPlatformFilters` 被调用前一直隐藏

## 解决方案
在 `init` 函数中，认证成功后立即显示平台筛选区域（此时显示"加载中..."占位符）。

### 修改内容

**文件**: `backend/src/index.ts`

```javascript
// 初始化：先检查登录，再加载数据
async function init() {
    const isAuth = await checkAuth();
    if (isAuth) {
        // 默认显示文章列表Tab，立即显示平台筛选区域（显示加载状态）
        document.getElementById('platformFilterBar').style.display = 'block';
        loadData();
    }
}
```

## 加载流程

### 修复前
1. 页面加载 → `init()` → `checkAuth()` → `loadData()`
2. `platformFilterBar` 保持 `display:none`
3. API返回 → `renderPlatformFilters()` → 平台按钮显示
4. **问题**：用户看到空白区域，体验不好

### 修复后
1. 页面加载 → `init()` → `checkAuth()` 
2. **立即显示** `platformFilterBar`（显示"加载中..."）
3. `loadData()` → API请求
4. API返回 → `renderPlatformFilters()` → 替换为实际按钮
5. **优势**：用户立即看到加载状态，体验流畅

    if (tab === 'articles') {
