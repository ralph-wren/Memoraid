# 定时任务 - 添加执行中取消任务功能

## 修改时间
2026-03-28 01:20

## 问题描述
用户希望在定时任务执行过程中，能够点击按钮取消正在执行的任务，而不是只能等待任务完成。

## 需求
1. 执行中的任务显示取消按钮（X图标，红色）
2. 未执行的任务显示执行按钮（Zap图标，蓝色）
3. 点击取消按钮可以中断正在执行的任务
4. 取消后任务状态标记为失败，并记录取消原因

## 实现方案

### 1. 后端实现（src/background/scheduler.ts）

#### 1.1 添加任务取消控制
```typescript
// 存储正在执行的任务ID和对应的取消标志
const runningTasks = new Map<string, { cancelled: boolean }>();
```

#### 1.2 修改executeTask函数
- 任务开始时注册到runningTasks
- 在循环处理文章时检查取消标志
- 任务结束时从runningTasks中移除

```typescript
async function executeTask(task: ScheduledTask) {
  // 注册任务到运行列表，初始化取消标志为false
  runningTasks.set(task.id, { cancelled: false });
  
  try {
    // ... 任务执行逻辑
    
    for (let i = 0; i < selectedArticles.length; i++) {
      // 检查任务是否被取消
      const taskControl = runningTasks.get(task.id);
      if (taskControl?.cancelled) {
        await taskLog(task.id, 'warn', `⚠️ 任务已被取消，停止处理剩余文章`);
        throw new Error('任务已被用户取消');
      }
      
      // ... 处理文章
    }
  } finally {
    // 清理任务运行记录
    runningTasks.delete(task.id);
  }
}
```

#### 1.3 添加stopTaskById函数
```typescript
export async function stopTaskById(taskId: string) {
  // 检查任务是否正在执行
  const taskControl = runningTasks.get(taskId);
  if (!taskControl) {
    console.log(`[Scheduler] 任务 ${taskId} 未在执行中，无需取消`);
    return;
  }
  
  // 设置取消标志
  taskControl.cancelled = true;
  
  // 记录取消日志
  await taskLog(taskId, 'warn', `⚠️ 用户手动取消任务`);
  
  // 更新任务状态为失败（取消也算失败）
  await updateTaskStatus(taskId, 'failed', '用户手动取消');
}
```

```typescript
const stopTaskNow = async (taskId: string) => {
  if (runningTaskId !== taskId) return;
  
  try {
    // 发送取消任务消息到后台
    await chrome.runtime.sendMessage({
      type: 'SCHEDULE_STOP_NOW',
      payload: { taskId }
    });
    
    // 立即清除运行状态
    setRunningTaskId(null);
    
    // 刷新任务状态
    await loadTasksFromBackend(true);
  } catch (e) {
    console.error('发送取消任务消息失败:', e);
  }
};
```

## 技术细节

### 取消机制
1. 使用Map存储正在执行的任务和取消标志
2. 在任务执行的关键位置（文章循环）检查取消标志
3. 检测到取消标志后抛出异常，进入错误处理流程
4. 错误处理流程会关闭所有打开的标签页并更新任务状态

### 状态同步
1. 前端通过chrome.runtime.sendMessage发送取消请求
2. 后端接收消息后设置取消标志
3. 执行中的任务检测到标志后停止执行
4. 前端立即清除runningTaskId状态
5. 刷新任务列表获取最新状态

### 用户体验
1. 执行中显示红色X图标，明确表示可以取消
2. 未执行显示蓝色闪电图标，表示可以立即执行
3. 取消后任务状态标记为失败，并记录"用户手动取消"
4. 日志中记录取消操作，方便追踪

2. 在任务执行过程中点击取消按钮
3. 确认任务停止执行，不再处理剩余文章
4. 确认任务状态更新为失败
5. 确认日志中记录了取消操作
6. 确认所有打开的标签页都被关闭

## 注意事项
1. 取消操作是异步的，可能需要几秒钟才能完全停止
2. 如果任务正在等待某个操作（如页面加载），需要等待该操作完成后才能检测到取消标志
3. 取消后的任务状态为"失败"，与执行失败的任务状态相同
4. 取消操作会记录在任务日志中，可以通过查看日志确认取消时间点
