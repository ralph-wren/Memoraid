# 修复仪表盘数据趋势不加载问题

## 问题描述
管理员页面在先访问其他页面（如用户管理、文章管理等），再点击仪表盘时，数据趋势图表不会加载，需要刷新页面才能显示。

## 问题原因
在 `backend/src/index.ts` 的 `switchTab()` 函数中，当切换到仪表盘（dashboard）标签页时，没有调用 `loadDashboardCharts()` 函数来加载数据趋势图表。

虽然在 `init()` 函数中首次加载时会调用 `loadDashboardCharts()`，但是当用户从其他标签页切换回仪表盘时，图表不会重新加载。

## 解决方案
在 `switchTab()` 函数中添加判断，当切换到仪表盘时自动调用 `loadDashboardCharts()` 加载图表数据。

### 修改代码
**文件：** `backend/src/index.ts`

**修改位置：** `switchTab()` 函数

```typescript
// Tab Switching
function switchTab(tabId) {
    document.querySelectorAll('.nav-item').forEach(el => el.classList.remove('active'));
    const navEl = document.getElementById('nav-' + tabId);
    if (navEl) navEl.classList.add('active');
    
    document.querySelectorAll('.tab-content').forEach(el => el.style.display = 'none');
    const tabEl = document.getElementById('tab-' + tabId);
    if (tabEl) tabEl.style.display = 'block';
    
    // 修复：切换到仪表盘时加载数据趋势图表
    if (tabId === 'dashboard') {
        loadDashboardCharts();
    }
    
    if (tabId === 'orders' && !window.ordersLoaded) {
        fetchOrders(true);
        window.ordersLoaded = true;
    }
    
    // ... 其他标签页的加载逻辑
}
```

## 技术细节
- **loadDashboardCharts()** 函数负责加载两个趋势图表：
  - 每日活跃用户图表（dashActiveChart）
  - 每日生成文章图表（dashArticlesChart）
- 图表支持切换时间范围：近7天、近30天、近90天
- 使用 Canvas 绘制折线图，包含渐变填充和数据点标记

## 测试步骤
1. 登录管理员页面
2. 点击"用户管理"或其他标签页
3. 再点击"仪表盘"标签页
4. 确认数据趋势图表正常显示，无需刷新页面
