# 定时任务执行记录写入功能

## 问题描述
用户反馈：小红书定时任务执行了，但在用户中心点击"记录"按钮时没有数据显示。

## 问题原因
调度器（`src/background/scheduler.ts`）在执行任务时只更新了任务状态（`updateTaskStatus`），但没有写入执行记录到 `task_execution_logs` 表。

虽然数据库表和前端查询接口都已经存在，但调度器没有调用API创建和更新执行记录。

## 解决方案

### 1. 后端API新增接口

在 `backend/src/index.ts` 中添加两个新的API接口：

#### 8.5.1 POST /api/task-execution-logs
创建任务执行记录（供调度器在任务开始时调用）

**请求参数：**
```json
{
  "task_id": "任务ID",
  "task_name": "任务名称",
  "status": "running",
  "started_at": 1234567890000
}
```

**返回：**
```json
{
  "success": true,
  "id": 123
}
```

#### 8.5.2 PATCH /api/task-execution-logs/:id
更新任务执行记录（供调度器在任务结束时调用）

**请求参数：**
```json
{
  "status": "success",
  "completed_at": 1234567890000,
  "duration": 120000,
  "articles_generated": 2,
  "articles_published": 2,
  "error_message": "错误信息（可选）"
}
```

### 2. 调度器修改

在 `src/background/scheduler.ts` 的 `executeTask` 函数中：

#### 任务开始时
1. 记录开始时间戳 `startedAt`
2. 调用 `createExecutionLog()` 创建执行记录，获取记录ID
3. 记录日志：`📝 已创建执行记录 ID: xxx`

#### 任务成功完成时
1. 计算完成时间和执行时长
2. 调用 `updateExecutionLog()` 更新记录：
   - status: 'success'
   - completed_at: 完成时间戳
   - duration: 执行时长（毫秒）
   - articles_generated: 生成的文章数量
   - articles_published: 成功发布的文章数量

#### 任务失败时
1. 计算完成时间和执行时长
2. 调用 `updateExecutionLog()` 更新记录：
   - status: 'failed'
   - completed_at: 完成时间戳
   - duration: 执行时长（毫秒）
   - error_message: 错误信息

### 3. 新增辅助函数

#### createExecutionLog()
```typescript
async function createExecutionLog(
  taskId: string, 
  taskName: string, 
  startedAt: number
): Promise<number>
```
- 调用后端 `POST /api/task-execution-logs` 创建记录
- 返回新创建的记录ID

#### updateExecutionLog()
```typescript
async function updateExecutionLog(
  logId: number,
  updates: {
    status?: 'running' | 'success' | 'failed';
    completed_at?: number;
    duration?: number;
    articles_generated?: number;
    articles_published?: number;
    error_message?: string;
  }
): Promise<void>
```
- 调用后端 `PATCH /api/task-execution-logs/:id` 更新记录

## 数据流程

```
任务开始
  ↓
创建执行记录（status: running）
  ↓
执行任务逻辑
  ↓
任务成功 ────→ 更新记录（status: success, 统计数据）
  ↓
任务失败 ────→ 更新记录（status: failed, 错误信息）
```

## 测试验证

1. 等待定时任务自动执行，或手动触发任务
2. 打开用户中心页面：https://memoraid.dpdns.org/user#tasks
3. 点击任务列表中的"📋 记录"按钮
4. 应该能看到执行记录，包含：
   - 执行时间
   - 状态（成功/失败/执行中）
   - 生成数量
   - 发布数量
   - 耗时
   - 错误信息（如果失败）

## 注意事项

1. 所有时间都使用中国时区（东八区）
2. 执行记录只能查看自己的记录（通过user_id过滤）
3. 如果创建或更新执行记录失败，不会影响任务执行，只会记录警告日志
4. 执行记录ID存储在 `executionLogId` 变量中，用于后续更新
