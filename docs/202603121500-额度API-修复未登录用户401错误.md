# 额度API：修复未登录用户401错误

## 修改日期
2026-03-12 15:00

## 问题描述
未登录用户打开插件时，额度信息显示"加载失败"，浏览器控制台报错：
- `Failed to load resource: the server responded with a status of 401 ()`
- `Failed to load quota: HTTP 401`

## 问题原因
1. 后端 `/api/user/quota` 接口只检查 `Authorization` 头（Bearer token）
2. `getUserIdFromRequest` 函数不支持匿名用户的 `X-Anonymous-ID` 头
3. 未登录用户发送的是 `X-Anonymous-ID`，不是 `Authorization`
4. 后端返回401未授权错误，导致前端无法获取额度信息

## 解决方案
修改后端 `/api/user/quota` 接口，支持通过 `X-Anonymous-ID` 头识别匿名用户。

## 修改内容

### 后端修改（backend/src/index.ts）

#### 修改 quota API 的用户识别逻辑
```typescript
// 7.6 GET /api/user/quota - 获取用户额度
if (url.pathname === '/api/user/quota' && request.method === 'GET') {
  try {
    // 优先从 Authorization 获取用户ID，如果没有则从 X-Anonymous-ID 获取
    let userId = getUserIdFromRequest(request);
    if (!userId) {
      // 尝试从匿名ID获取
      const anonymousId = request.headers.get('X-Anonymous-ID');
      if (anonymousId) {
        userId = anonymousId;
      }
    }
    
    if (!userId) {
      return new Response(JSON.stringify({ error: 'Unauthorized' }), { 
        status: 401, 
        headers: { ...corsHeaders, 'Content-Type': 'application/json' } 
      });
    }

    // 获取用户信息
    const user = await env.DB.prepare('SELECT provider FROM users WHERE id = ?').bind(userId).first();
    const isAnonymous = user?.provider === 'anonymous' || !user;
    const freeLimit = isAnonymous ? 5 : 20;
    
    // 获取已使用的免费次数（只统计文章生成）
    const usageCount = await env.DB.prepare(
      'SELECT COUNT(*) as count FROM ai_usage_logs WHERE user_id = ? AND model = ?'
    ).bind(userId, 'article-generation').first('count') as number || 0;
    
    // ... 其余代码保持不变
  }
}
```

**修改说明**：
1. 先尝试从 `Authorization` 头获取用户ID（已登录用户）
2. 如果没有，再尝试从 `X-Anonymous-ID` 头获取（未登录用户）
3. 两者都没有才返回401错误
4. 判断是否匿名用户时，增加 `|| !user` 条件，处理用户不存在的情况
5. 统计使用次数时，只统计 `model = 'article-generation'` 的记录（与之前的优化保持一致）

## 技术细节

### 用户识别优先级
1. **已登录用户**：`Authorization: Bearer mock_jwt_xxx`
2. **未登录用户**：`X-Anonymous-ID: xxx`
3. **无认证信息**：返回401错误

### 匿名用户判断
- `user?.provider === 'anonymous'`：数据库中存在且provider为anonymous
- `!user`：数据库中不存在该用户（首次使用）
- 两种情况都视为匿名用户，免费额度为5次

### 额度统计
- 只统计 `model = 'article-generation'` 的使用记录
- 不统计AI聊天的使用次数
- 与之前的"免费额度只统计文章生成"功能保持一致

## 前端改进

### 加载状态提示
```typescript
剩余额度: {
  quota === undefined ? '加载中...' : 
  quota === null ? '加载失败' :
  quota.total_remaining !== undefined ? `${quota.total_remaining} 次` : '0 次'
}
```

**说明**：
- `undefined`：正在加载，显示"加载中..."
- `null`：加载失败，显示"加载失败"
- 有数据：正常显示额度
