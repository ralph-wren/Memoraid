# 小红书提示词优化 - 禁止图片占位符和封面摘要

## 问题描述

用户反馈：生成的小红书文章中出现了以下问题：
1. 文章中有图片占位符 `[图片: xxx]`
2. 文章结尾有封面提示 `[封面: xxx]`
3. 话题标签有时会丢失

## 问题分析

### 图片占位符问题

通用提示词中虽然说了"小红书：不需要图片占位符"，但：
- 说明不够强调，只是简单一句话
- 小红书专属提示词中没有明确禁止

### 封面和摘要问题

小红书不需要封面和摘要（这是公众号的功能），但提示词中没有明确禁止，导致AI可能会生成。

### 话题标签问题

提示词中要求话题标签在结尾，但没有强调"必须在最后一行"，导致AI可能在话题后面添加其他内容。

## 解决方案

### 1. 加强图片占位符禁止规则

**通用提示词**（第418行）：
```typescript
- **小红书**：❌ **严禁使用图片占位符**！小红书平台不需要 `[图片: xxx]` 格式
```

**小红书专属提示词**（第1003行）：
```typescript
- **严禁使用图片占位符**！小红书平台不需要 `[图片: xxx]` 这种格式，全文只用纯文字表达
```

### 2. 明确禁止封面和摘要

**小红书专属提示词**（新增）：
```typescript
### 小红书平台特殊说明（CRITICAL）
⚠️ **小红书平台不需要以下内容，严禁添加：**
- ❌ **严禁添加封面提示词**：不要使用 `[封面: xxx]` 格式
- ❌ **严禁添加摘要**：不要使用 `[摘要: xxx]` 格式
- ✅ **只需要**：标题 + 简介 + 正文 + 话题标签
```

### 3. 强调话题标签位置

**小红书专属提示词**（第1035行）：
```typescript
### 导出话题（CRITICAL - 必须包含）
- 小红书笔记结尾**必须**包含至少5个相关话题，格式为 `#标签名`。
- 话题之间用空格分隔。
- 话题必须在文章最后一行，前面不要有其他内容。
```

**完整格式示例**：
```
# 这是标题

[简介]这是简介内容，50-80字，纯文字不带表情

这是正文第一段，自然流畅的表达

这是正文第二段，继续分享内容

...更多正文段落...

评论区聊聊吧

#话题1 #话题2 #话题3 #话题4 #话题5
```

**注意**：
- 话题标签必须在文章最后一行
- 话题标签前面可以有一个简短的互动引导（如"评论区聊聊吧"）
- 严禁在话题标签后面添加任何内容（如封面、摘要等）
