# 支付增加管理员充值通知邮件

## 本次调整

- 新增 `loadEmailConfig` 统一读取发件人、发件名称和管理员通知邮箱配置
- 新增 `sendAdminRechargeNotificationEmail`，用户支付成功并自动到账后，额外给管理员通知邮箱发送一封到账提醒邮件
- 保留用户侧支付成功邮件，两条邮件链路并行发送，互不影响
- 后台“邮件配置”改为支持配置 `管理员通知邮箱`，用于接收用户充值成功提醒
- 测试邮件优先发送到管理员通知邮箱；未配置时回落到发件人邮箱

## 当前行为

- 用户充值成功后：用户本人会收到支付成功邮件
- 如果配置了管理员通知邮箱：管理员也会同时收到一封“用户充值成功通知”邮件
- 这封管理员邮件仅用于通知，不包含任何审核入口或审批操作
