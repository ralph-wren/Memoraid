# 添加各平台每日文章数量折线图

## 功能描述
在管理员页面的平台内容分布区域下方，新增了一个多折线图表，展示各个平台（微信公众号、今日头条、知乎、小红书等）每日文章数量的趋势变化。

## 实现内容

### 1. 后端API实现
**新增API端点：** `GET /api/admin/platform-trends`

**功能：** 获取各平台每日文章数量数据，支持时间范围参数（7天/30天/90天）

**查询逻辑：**
```sql
SELECT 
  p.name as platform_name,
  p.display_name,
  ((a.publish_time + 28800) / 86400) as day_key,
  COUNT(*) as cnt
FROM articles a
JOIN platforms p ON a.platform_id = p.id
WHERE a.publish_time >= ? AND p.name != 'test'
GROUP BY p.id, day_key
ORDER BY p.id, day_key
```

**特点：**
- 自动排除test平台的数据
- 按UTC+8时区统计每日数据
- 返回各平台的名称、显示名称和每日数值数组

**返回格式：**
```json
{
  "labels": ["3/1", "3/2", "3/3", ...],
  "platforms": [
    {
      "name": "weixin",
      "displayName": "微信公众号",
      "values": [5, 8, 3, ...]
    },
    {
      "name": "toutiao",
      "displayName": "今日头条",
      "values": [2, 4, 6, ...]
    }
  ]
}
```

### 2. 前端HTML结构
在平台内容分布卡片下方添加新的图表区域：

```html
<!-- 平台文章数量趋势图 -->
<div class="card" style="padding:20px;margin-top:16px">

    <div id="platformLegend"></div>

```

### 3. 前端JavaScript实现

#### 平台颜色映射
为每个平台分配专属颜色，与品牌色保持一致：
```javascript
const platformColors = {
    'weixin': '#07C160',      // 微信绿
    'toutiao': '#ED4040',     // 头条红
    'zhihu': '#0084FF',       // 知乎蓝
    'xiaohongshu': '#FF2442', // 小红书红
    'default': '#6b7280'      // 默认灰色
};
```

#### 核心函数

**1. switchPlatformChartRange(days)** - 切换时间范围
- 更新按钮激活状态
- 调用loadPlatformTrendsChart()重新加载数据

**2. loadPlatformTrendsChart()** - 加载数据
- 请求API获取各平台趋势数据
- 调用drawPlatformTrendsChart()绘制图表

**3. drawPlatformTrendsChart(labels, platforms)** - 绘制多折线图
- 使用Canvas绘制多条折线，每个平台一条
- 自动计算所有平台的最大值作为Y轴范围
- 为每条折线使用对应平台的品牌色
- 绘制数据点（带白色边框，更清晰）
- 自适应X轴日期标签间隔

**4. updatePlatformLegend(platforms)** - 更新图例
- 显示每个平台的颜色标识、名称和总文章数
- 格式：`🟢 微信公众号 (125篇)`

### 4. 图表特性
- ✅ 多条折线同时显示，每个平台一条
- ✅ 使用平台品牌色，易于区分
- ✅ 支持切换时间范围（7天/30天/90天）
- ✅ 自动排除test平台数据
- ✅ 数据点带白色边框，更清晰可见
- ✅ 图例显示各平台总文章数
- ✅ 自适应Y轴最大值
- ✅ 自适应X轴标签间隔

### 5. 加载时机
- 首次进入管理员页面时自动加载（init函数）
- 切换到仪表盘标签页时自动加载（switchTab函数）
- 切换时间范围时重新加载

## 技术细节

### Canvas绘图优化
- 使用devicePixelRatio适配高清屏
- 折线宽度2.5px，清晰可见
- 数据点半径3px，带1.5px白色边框
- Y轴网格线使用浅灰色，不干扰主要内容

### 性能优化
- 只绘制有数据的点（值>0）
- X轴标签自适应间隔，避免重叠
- 使用并行请求，不阻塞其他数据加载
