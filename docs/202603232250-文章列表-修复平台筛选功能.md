# 文章列表 - 修复平台筛选功能

## 问题描述
用户反馈点击平台筛选按钮后，文章列表没有变化，平台筛选功能不生效。

## 问题原因
前端和后端的参数不匹配：
- **前端**：传递 `platforms` 参数（复数），值为逗号分隔的多个平台代码，如 `platforms=weixin,xiaohongshu`
- **后端**：只支持 `platform` 参数（单数），只能筛选单个平台

## 解决方案
修改后端 `GET /api/user/articles` 接口，支持多平台筛选。

### 修改内容

#### 1. 添加 platforms 参数支持
```typescript
const platform = url.searchParams.get('platform') || ''; // 单个平台（兼容旧版）
const platforms = url.searchParams.get('platforms') || ''; // 多个平台（逗号分隔）
```

#### 2. 构建 SQL IN 查询
```typescript
// 支持多平台筛选（优先使用platforms参数）
if (platforms) {
  const platformList = platforms.split(',').filter(p => p.trim());
  if (platformList.length > 0) {
    const placeholders = platformList.map(() => '?').join(',');
    query += ` AND p.name IN (${placeholders})`;
    params.push(...platformList);
  }
} else if (platform) {
  // 兼容旧版单平台筛选
  query += ` AND p.name = ?`;
  params.push(platform);
}
```

#### 3. 同步修改 COUNT 查询
在获取总数的查询中也添加相同的筛选逻辑，确保分页正确。

### API 使用示例

**单平台筛选（兼容旧版）**：
```
GET /api/user/articles?platform=weixin&limit=20&offset=0
```

**多平台筛选（新功能）**：
```
GET /api/user/articles?platforms=weixin,xiaohongshu&limit=20&offset=0
```

**全部平台（不传参数）**：
```
GET /api/user/articles?limit=20&offset=0
```

## 技术细节

### SQL IN 查询构建
```sql
-- 单平台
WHERE p.name = ?

-- 多平台
WHERE p.name IN (?, ?, ?)
```

### 参数绑定
```typescript
// 示例：platforms=weixin,xiaohongshu
const platformList = ['weixin', 'xiaohongshu'];
const placeholders = '?,?'; // 动态生成
params.push(...platformList); // 展开数组
```

### 前端调用
```javascript
// 构建查询参数
let query = '?limit=' + articlesPageSize + '&offset=' + offset;

// 添加平台筛选（支持多选）
if (currentPlatform.length > 0) {
    query += '&platforms=' + currentPlatform.join(',');
}

// 发起请求
const res = await fetch(API_BASE + '/api/user/articles' + query, { headers });
```

## 用户体验

### 筛选交互
1. 点击"全部平台"：清空筛选，显示所有文章
2. 点击单个平台：只显示该平台的文章
3. 点击多个平台：显示选中平台的文章（OR关系）
4. 再次点击已选中的平台：取消选中

### 按钮状态
- 选中状态：蓝色背景（`active` 类）
- 未选中状态：白色背景
- 全部平台：当没有选中任何平台时高亮
