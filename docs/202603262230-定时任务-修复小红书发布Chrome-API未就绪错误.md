# 定时任务 - 修复小红书发布 Chrome API 未就绪错误

## 问题描述

定时任务执行时，发布到小红书失败，错误信息：
```
Cannot read properties of undefined (reading 'create')
```

从日志可以看到：
```
[22:32:38] [ERROR  ] ❌ 发布到 xiaohongshu 失败: Cannot read properties of undefined (reading 'create')
[22:32:53] [ERROR  ] ❌ 发布到 xiaohongshu 失败: Cannot read properties of undefined (reading 'create')
```

## 问题原因

在定时任务执行过程中，当调用 `handlePublishToXiaohongshu` 等发布函数时，可能会遇到以下情况：

1. **Chrome API 未完全初始化**：在某些情况下（特别是定时任务刚启动时），`chrome.tabs` 对象可能尚未完全初始化
2. **Service Worker 生命周期问题**：Chrome Extension 的 Service Worker 可能在空闲时被挂起，重新唤醒时 API 可能需要时间初始化
3. **并发调用问题**：多个定时任务同时执行时，可能导致 Chrome API 访问冲突

错误发生在以下代码位置：
- `chrome.tabs.create()` - 创建新标签页
- `chrome.tabs.query()` - 查询已有标签页
- `chrome.tabs.update()` - 更新标签页

## 解决方案

### 1. 添加 Chrome API 可用性检查

在所有调用 `chrome.tabs.create()` 之前，添加防御性检查：

```typescript
// 【修复】检查 chrome.tabs 是否可用（防止定时任务中 chrome API 未初始化）
if (!chrome || !chrome.tabs) {
  console.error('[Background] chrome.tabs is not available');
  throw new Error('Chrome API 未就绪，请稍后重试');
}
```

### 2. 修改的文件

**src/background/index.ts**

修改了以下四个发布函数：

1. **handlePublishToToutiao** (第 1615 行附近)
   - 在 `chrome.tabs.create()` 调用前添加检查

2. **handlePublishToZhihu** (第 1745 行附近)
   - 在 `chrome.tabs.create()` 调用前添加检查

3. **handlePublishToWeixin** (第 1884 行附近)
   - 在 `chrome.tabs.create()` 调用前添加检查

4. **handlePublishToXiaohongshu** (第 2115 行附近)
   - 在 `chrome.tabs.create()` 和 `chrome.tabs.query()` 调用前添加检查

### 3. 代码示例

修改前：
```typescript
const tab = await chrome.tabs.create({
  url: publishUrl,
  active: true
});
```

修改后：
```typescript
// 【修复】检查 chrome.tabs 是否可用（防止定时任务中 chrome API 未初始化）
if (!chrome || !chrome.tabs) {
  console.error('[Background] chrome.tabs is not available');
  throw new Error('Chrome API 未就绪，请稍后重试');
}

const tab = await chrome.tabs.create({
  url: publishUrl,
  active: true
});
```

## 预期效果

1. **更好的错误提示**：当 Chrome API 未就绪时，会抛出明确的错误信息，而不是 `undefined` 错误
2. **提高稳定性**：防止在 API 未初始化时执行操作，避免崩溃
3. **便于调试**：通过日志可以快速定位是 API 未就绪的问题

## 后续优化建议

1. **添加重试机制**：当检测到 Chrome API 未就绪时，可以等待一段时间后重试
2. **Service Worker 保活**：考虑使用心跳机制保持 Service Worker 活跃
3. **延迟执行**：定时任务可以在检测到 API 就绪后再执行发布操作

## 测试建议

1. 创建一个定时任务，设置为立即执行
2. 观察日志，确认不再出现 `Cannot read properties of undefined` 错误
3. 如果出现 "Chrome API 未就绪" 错误，说明修复生效，可以考虑添加重试逻辑
