# 用户反馈 - 集成插件反馈到管理员后台

## 功能描述

将插件面板的用户反馈功能集成到管理员后台的"用户反馈"页面，实现统一管理。

## 实现内容

### 1. 前端页面改造

在管理员后台的"用户反馈"Tab中添加两个子Tab：

- **工单系统**：显示用户通过用户中心提交的工单
- **插件反馈**：显示用户通过浏览器插件提交的反馈

### 2. 插件反馈列表功能

- 支持按类型筛选：使用体验、功能建议、问题反馈
- 支持按状态筛选：待处理、已解决、已忽略
- 显示反馈内容、用户邮箱、提交时间
- 显示管理员回复（如果有）

### 3. 管理员操作

- **标记已解决**：将反馈状态改为"已解决"
- **忽略**：将反馈状态改为"已忽略"
- **回复**：给用户回复并自动标记为"已解决"

### 4. API权限修复

修复了两个管理员反馈API的权限验证，使用 `verifyAdminToken` 函数：

- `GET /api/admin/feedback` - 获取反馈列表
- `POST /api/admin/feedback/:id/status` - 更新反馈状态

// 更新反馈状态
async function updateFeedbackStatus(feedbackId, newStatus) {
    const token = localStorage.getItem('memoraid_admin_token');
    const res = await fetch('/api/admin/feedback/' + feedbackId + '/status', {
        method: 'POST',
        headers: {
            'Authorization': 'Bearer ' + token,
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({ status: newStatus })
    });
    
    loadPluginFeedback(); // 刷新列表
}

// 回复反馈
async function replyToFeedback(feedbackId) {
    const reply = prompt('请输入回复内容：');
    if (!reply || !reply.trim()) return;
    
    const token = localStorage.getItem('memoraid_admin_token');
    const res = await fetch('/api/admin/feedback/' + feedbackId + '/status', {
        method: 'POST',
        headers: {
            'Authorization': 'Bearer ' + token,
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({ 
            status: 'resolved',
            admin_reply: reply.trim()
        })
    });
    
    loadPluginFeedback(); // 刷新列表
}

## 数据库表结构

使用现有的 `feedback` 表：

```sql
CREATE TABLE feedback (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT,
    user_email TEXT,
    type TEXT NOT NULL,  -- experience, suggestion, bug
    content TEXT NOT NULL,
    status TEXT DEFAULT 'pending',  -- pending, resolved, ignored
    admin_reply TEXT,
    created_at INTEGER NOT NULL,
    updated_at INTEGER
);
```

## 使用说明

1. 登录管理员后台
2. 点击"用户反馈"Tab
3. 默认显示"工单系统"，点击"插件反馈"切换到插件反馈列表
4. 使用筛选器按类型和状态过滤反馈
5. 对反馈进行操作：
   - 点击"标记已解决"将状态改为已解决
   - 点击"忽略"将状态改为已忽略
   - 点击"回复"输入回复内容并自动标记为已解决
