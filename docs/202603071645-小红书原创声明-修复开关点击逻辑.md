# 小红书原创声明修复 - 添加开关点击逻辑

## 问题描述
用户反馈：小红书发布流程中，原创声明功能无法正常工作，日志显示：
```
⚠️ 未找到"我已阅读并同意"勾选项（弹窗结构变化），跳过
```

## 根本原因
通过 Playwright 录制用户的实际操作，发现了问题：

**缺少第一步：点击原创声明开关**

Playwright 录制的正确流程：
```javascript
// 1. 点击开关（打开原创声明入口）
await page.locator('.d-switch-simulator').first().click();

// 2. 点击勾选框（同意条款）
await page.locator('.d-checkbox-indicator').click();

// 3. 点击"声明原创"按钮
await page.getByRole('button', { name: '声明原创' }).click();
```

而我们的代码直接从"点击去声明"开始，跳过了第一步，导致：
1. 原创声明功能没有被打开
2. "去声明"按钮可能不可见或不可点击
3. 即使点击成功，弹窗也可能不会出现

## 解决方案

### 1. 添加开关点击逻辑

在 `setOriginalityDeclaration` 函数的开始部分，添加点击开关的逻辑：

```typescript
// 0) 先点击原创声明开关（如果存在）
// 根据 Playwright 录制：await page.locator('.d-switch-simulator').first().click();
// 修复：需要先打开原创声明开关，才能看到"去声明"按钮
logger.log('查找原创声明开关...', 'info');
const switchEl = document.querySelector('.d-switch-simulator') as HTMLElement | null;
if (switchEl && isElementVisible(switchEl)) {
    logger.log('点击原创声明开关', 'action');
    await clickReliable(switchEl);
    await sleep(800); // 等待开关动画和"去声明"按钮出现
}

// 1) 点击「去声明」入口
// ...
```

### 2. 完整的原创声明流程

修复后的完整流程：

1. **点击开关**：`.d-switch-simulator` - 打开原创声明功能
2. **等待动画**：800ms - 等待开关动画和"去声明"按钮出现
3. **点击"去声明"**：查找并点击"去声明"按钮
4. **等待弹窗**：等待原创声明弹窗出现
5. **勾选同意**：点击"我已阅读并同意"勾选框
6. **等待按钮启用**：等待"声明原创"按钮从 disabled 变为可点击
7. **点击确认**：点击"声明原创"按钮
8. **等待关闭**：等待弹窗关闭，确认成功

## 技术细节

### 为什么需要点击开关？

小红书的原创声明功能是一个**可选功能**，默认是关闭的：
- 关闭状态：只显示"原创声明"标题和一个开关
- 打开状态：显示"原创声明"标题、开关（已打开）、"去声明"按钮

如果不点击开关，"去声明"按钮可能：
- 不存在（DOM 中没有）
- 不可见（display: none）
- 不可点击（disabled 或被遮罩）

### 选择器说明

```typescript
// 开关选择器
'.d-switch-simulator'  // 小红书的开关组件类名

// 勾选框选择器（已在配置中）
'.d-checkbox-indicator'  // 勾选框指示器
```

### 等待时间

```typescript
await sleep(800);  // 等待开关动画和"去声明"按钮出现
```

为什么是 800ms？
- 开关有动画效果（约 300ms）
- "去声明"按钮需要渲染（约 200ms）
- 留出缓冲时间（约 300ms）
