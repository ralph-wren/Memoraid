# 定时任务日志 - 添加复制按钮和优化自动滚动

## 修改时间
2026-03-15 16:00

## 问题描述
1. 用户需要复制日志内容，但没有复制按钮
2. 任务结束后日志仍在自动滚动，影响查看历史日志

## 解决方案

### 1. 添加复制按钮
- 在删除按钮旁边添加复制按钮（使用 Copy 图标）
- 点击后将所有日志复制到剪贴板
- 日志格式：`[时间] [级别] 消息内容`
- 复制成功后按钮变绿色，2秒后恢复
- 无日志时按钮禁用（灰色）

### 2. 优化自动滚动逻辑
- 只在任务状态为 `running` 时自动滚动
- 任务结束（`success` 或 `failed`）后停止自动滚动
- 底部状态栏显示：
  * 任务执行中：`📍 自动滚动` 或 `⏸️ 已暂停滚动（滑到底部恢复）`
  * 任务已结束：`⏹️ 任务已结束`

## 技术细节

### 复制功能实现
```typescript
// 复制所有日志到剪贴板
const copyLogs = async () => {
  if (logs.length === 0) {
    return;
  }
  
  // 格式化日志内容
  const logText = logs.map(entry => {
    const time = formatTime(entry.time);
    const level = entry.level.toUpperCase().padEnd(7); // 对齐
    return `[${time}] [${level}] ${entry.message}`;
  }).join('\n');
  
  try {
    await navigator.clipboard.writeText(logText);
    setCopySuccess(true);
    // 2秒后隐藏提示
    setTimeout(() => setCopySuccess(false), 2000);
  } catch (e) {
    console.error('复制日志失败:', e);
  }
};
```

### 自动滚动优化
```typescript
// 自动滚动到底部（只在任务执行中时自动滚动）
useEffect(() => {
  // 只有任务状态为 'running' 时才自动滚动
  const shouldAutoScroll = task.lastRunStatus === 'running' && autoScroll;
  if (shouldAutoScroll && logEndRef.current) {
    logEndRef.current.scrollIntoView({ behavior: 'smooth' });
  }
}, [logs, autoScroll, task.lastRunStatus]);
```

## 用户体验改进
1. 方便用户复制日志内容进行分享或保存
2. 任务结束后可以自由查看历史日志，不会被自动滚动打断
3. 复制按钮有视觉反馈（成功时变绿色）
4. 底部状态栏清晰显示当前滚动状态

## 测试建议
1. 启动一个定时任务，观察日志是否自动滚动
2. 任务执行完成后，确认日志停止自动滚动
3. 点击复制按钮，粘贴到文本编辑器，确认格式正确
4. 无日志时，确认复制按钮为禁用状态
