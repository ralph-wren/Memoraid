# 定时任务支持今日热榜新闻源

## 功能概述

扩展定时任务系统，支持今日热榜（tophub.today）作为新闻源，用户可以订阅任意热榜并自动生成发布内容。

## 改动说明

### 1. 数据结构扩展 (src/utils/storage.ts)

- 新增 `NewsSourceType` 类型：`'newsnow' | 'tophub'`
- `ScheduledTask` 接口新增字段：
  - `newsSourceType`: 新闻源类型（NewsNow API 或今日热榜）
  - `tophubNodeId`: 今日热榜的 node_id（如 `3QeLwJEd7k`）
  - `categories`: 改为可选，仅 NewsNow 使用

### 2. 调度器逻辑改造 (src/background/scheduler.ts)

#### 核心改动

- 将原有的 `executeTask` 函数拆分为两个独立的获取函数：
  - `fetchFromNewsNow()`: 处理 NewsNow API 获取（原有逻辑）
  - `fetchFromTophub()`: 处理今日热榜页面抓取（新增）

### 今日热榜抓取流程

1. 根据 `tophubNodeId` 构建完整 URL：`https://tophub.today/n/{nodeId}`
2. 创建隐藏标签页打开热榜页面
3. 等待页面加载完成（15秒超时）
4. 注入脚本抓取 DOM 数据：
   ```javascript
   // 选择器：table tbody tr td:nth-child(2) a（表格第二列的链接）
   const items = document.querySelectorAll('table tbody tr td:nth-child(2) a');
   ```
5. 提取标题和链接，返回文章列表
6. 关闭热榜标签页

### 3. UI 界面优化 (src/components/ScheduleSettings.tsx)

#### 新增功能

- 新闻源类型选择按钮（NewsNow API / 今日热榜）
- 根据选择的类型动态显示不同配置项：
  - **NewsNow 模式**：显示 URL 输入和内容偏好选择
  - **今日热榜模式**：显示 node_id 输入框

#### UI 提示

- 提供常用热榜 node_id 示例：
  - 知乎热榜：`3QeLwJEd7k`
  - 微博热搜：`KqndgxeLl9`
  - 百度热搜：`Jb0vmloB1G`
- 说明如何从 URL 中提取 node_id

## 使用方法

### 创建今日热榜定时任务

1. 打开插件设置 → 定时任务
2. 点击"新建任务"
3. 选择"今日热榜"作为新闻源类型
4. 填写 node_id（从今日热榜页面 URL 获取）
   - 例如：`tophub.today/n/3QeLwJEd7k` 中的 `3QeLwJEd7k`
5. 选择发布平台
6. 设置执行时间
7. 保存并启用任务

### 获取今日热榜 node_id

1. 访问 [今日热榜](https://tophub.today/)
2. 选择想要订阅的榜单（如知乎热榜、微博热搜等）
3. 从浏览器地址栏复制 URL 中的 node_id
   - 格式：`https://tophub.today/n/{这里就是node_id}`

## 技术细节

### 页面抓取实现

使用 Chrome Extension 的 `chrome.scripting.executeScript` API 注入脚本：

```typescript
const results = await chrome.scripting.executeScript({
  target: { tabId: tab.id },
  func: () => {
    // 今日热榜的 DOM 结构：表格第二列的链接
    const items = document.querySelectorAll('table tbody tr td:nth-child(2) a');
    const articles: Array<{ title: string; url: string }> = [];
    
    items.forEach((item) => {
      const link = item as HTMLAnchorElement;
      const title = link.textContent?.trim() || '';
      const url = link.href || '';
      
      // 过滤掉无效的链接（标题太短或没有URL）
      if (title && url && title.length > 3) {
        articles.push({ title, url });
      }
    });
    
    return articles;
  },
});
```

### 错误处理

- 页面加载超时（15秒）
- DOM 结构变化导致抓取失败
- 自动关闭标签页，避免资源泄漏

## 兼容性

- 保持与现有 NewsNow 任务的完全兼容
- 旧任务会自动添加 `newsSourceType: 'newsnow'` 字段
- 不影响现有功能
