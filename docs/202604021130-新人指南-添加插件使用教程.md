# 新人指南 - 添加插件使用教程

## 功能描述

为 Memoraid 插件添加了一个新人指南文档，作为插件面板的第一篇默认文档，帮助新用户快速上手。

## 实现方案

### 1. 创建新人指南文档

创建了 `docs/新人指南-Memoraid使用教程.md` 文档，包含以下内容：

- **什么是 Memoraid**：插件简介和核心功能
- **快速开始**：安装步骤和首次使用指南
- **基础使用**：四个主要场景的使用教程
  - 将新闻转成头条文章
  - 将技术文章转成知乎专栏
  - 将内容发布到公众号
  - 生成小红书笔记
- **进阶功能**：
  - 配置平台 Cookie
  - 自定义文章风格
  - 自定义平台提示词
  - 定时任务配置
  - 数据统计查看
  - 账号同步
- **常见问题**：8 个常见问题的解答
- **使用技巧**：4 个实用技巧
- **获取帮助**：联系方式和反馈渠道

### 2. 自动添加到历史记录

修改了 `src/background/index.ts` 中的 `chrome.runtime.onInstalled` 事件处理函数：

- 检测首次安装（`details.reason === 'install'`）
- 自动读取新人指南文档内容
- 添加到历史记录列表，ID 为 `welcome-guide`
- 标题为 `📖 新人指南 - Memoraid 使用教程`

### 3. 文档打包配置

- 将新人指南文档复制到 `public/docs/` 目录
- Vite 构建时会自动将 public 目录的内容复制到 dist 目录
- 确保文档可以通过 `chrome.runtime.getURL()` 访问

## 使用说明

### 用户体验

1. **首次安装**：
   - 用户安装插件后，打开扩展面板
   - 在"历史记录"区域会看到一篇 `📖 新人指南 - Memoraid 使用教程`
   - 点击即可查看完整的使用教程

2. **文档内容**：
   - 文档使用 Markdown 格式编写
   - 包含详细的使用步骤和截图占位符
   - 提供常见问题解答和使用技巧

3. **截图需求**：
   文档中标注了需要截图的位置（共 10+ 处），包括：
   - Chrome 应用商店安装页面
   - 扩展主界面
   - 各平台发布页面
   - 设置页面
   - 数据统计页面
   - 等等

### 开发者说明

如果需要更新新人指南文档：

1. 修改 `docs/新人指南-Memoraid使用教程.md`
2. 将修改后的文档复制到 `public/docs/` 目录：
   ```bash
   cp "docs/新人指南-Memoraid使用教程.md" "public/docs/"
   ```
3. 重新构建：
   ```bash
   npm run build
   ```
