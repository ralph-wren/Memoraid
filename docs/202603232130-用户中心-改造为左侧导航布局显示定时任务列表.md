# 用户中心 - 改造为左侧导航布局，定时任务显示当前配置的任务列表

## 修改时间
2026-03-23 21:30

## 问题描述
用户要求将用户中心页面的侧边栏布局改为与admin页面一致的左侧导航菜单样式，并且定时任务Tab改为显示当前配置的任务列表，而不是执行记录。

## 解决方案

### 1. 布局改造
- 将原来的右侧侧边栏筛选改为顶部筛选工具栏
- 左侧改为固定宽度（260px）的导航菜单
- 右侧为主内容区，包含筛选工具栏和数据表格
- 采用flex布局，与admin页面保持一致

### 2. CSS样式更新
- 更新 `.layout` 为 `display: flex`
- 更新 `.sidebar` 样式，固定宽度260px，包含header和nav
- 更新 `.main-content` 样式，flex: 1，带圆角和背景色
- 添加 `.filter-toolbar` 样式，用于顶部筛选区域
- 更新响应式样式，移动端改为垂直布局

### 3. HTML结构调整
- 移除原来的 `.main-layout` 和 `.content-area` 结构
- 改为 `.layout > .sidebar + .main-content` 结构
- 侧边栏包含logo和导航项（文章列表、定时任务、充值记录）
- 主内容区包含筛选工具栏和tab内容
- 筛选工具栏仅在文章列表Tab显示

### 4. JavaScript功能更新

#### 4.1 Tab切换逻辑
- 更新 `switchTab()` 函数，使用 `nav-{tab}` ID来更新导航项状态
- 根据当前Tab显示/隐藏筛选工具栏
- tasks Tab调用 `loadScheduledTasks()` 而不是 `loadTaskExecutionLogs()`

#### 4.2 定时任务功能
- 新增 `renderScheduledTasks(tasks)` 函数，渲染任务列表表格
- 显示字段：任务名称、状态（启用/禁用）、目标平台、执行周期（cron表达式）、下次执行时间
- 移除定时任务的分页功能（任务列表通常不多，不需要分页）
- 移除 `renderTasksPagination()` 和 `changeTasksPage()` 函数
- 移除 `tasksPage` 和 `tasksPageSize` 变量

#### 4.3 刷新功能
- 新增 `loadCurrentTabData()` 函数，根据当前Tab刷新对应数据
- 顶部刷新按钮调用此函数

#### 4.4 筛选功能
- 更新 `renderPlatformFilters()` 函数，渲染为 `.filter-tag` 样式
- 更新 `changeSortBy()` 函数，更新筛选工具栏中的按钮状态

### 5. API接口
使用已有的 `GET /api/scheduled-tasks/list` 接口获取用户的定时任务列表。

## 技术细节

### 定时任务表格字段
```javascript
{
  name: '任务名称',
  enabled: true/false,  // 状态
  platforms: ['xiaohongshu', 'weixin'],  // 目标平台数组
  cron_expression: '0 9 * * *',  // Cron表达式
  next_run_time: '2026-03-24T09:00:00Z'  // 下次执行时间
}
```

### 布局结构
```
.container
  └── .layout (flex)
      ├── .sidebar (260px)
      │   ├── .sidebar-header (logo)
      │   └── .sidebar-nav (导航项)
      └── .main-content (flex: 1)
          └── .content-body
              ├── .filter-toolbar (仅文章列表显示)
              └── .tab-content (文章/任务/充值)
```
