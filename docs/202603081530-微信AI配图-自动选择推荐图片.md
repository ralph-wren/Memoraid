# 微信公众号AI配图 - 自动选择推荐图片功能优化

## 日期
2026-03-08 15:30

## 问题描述

微信公众号AI配图时，输入提示词后会显示推荐图片（"已在图片库中找到以下图片"区域），但原有逻辑会等待AI生成新图片（30-60秒），实际可以直接使用推荐图片（2-3秒），大大提升效率。

### 推荐图片特征
- 位于AI配图弹窗下方
- 标题："已在图片库中找到以下图片"
- 图片容器：parent类为`image-wrapper`
- 图片尺寸：132x132像素

### 历史图片特征
- 位于AI配图弹窗上方
- 图片容器：parent类为`ai-image-item-wrp`
- 图片尺寸：220x220像素

## 遇到的问题

1. **重复插入问题**：使用`simulateClick()`会触发完整的鼠标事件序列（mousedown、mouseup、click），导致点击事件被触发两次，造成图片重复插入
2. **推荐图片加载时间不足**：等待时间只有1秒，某些提示词的推荐图片还没加载完成就进入AI生成流程
3. **使用历史图片**：当没找到推荐图片时，会使用历史的AI生成图片，导致多个占位符插入相同的图片
4. **封面选择失败**：封面选择流程中使用`simulateClick()`导致图片未能正确选中

## 解决方案

### 1. 修复重复插入问题

**文件**：`src/content/weixin.ts`

**修改位置1**：`clickWeixinImageAdaptive`函数
```typescript
// 修改前：使用simulateClick()
simulateClick(img);
simulateClick(clickable);

// 修改后：使用原生click()避免触发额外的事件
img.click();
clickable.click();
```

**修改位置2**：`insertAIImage`函数中点击推荐图片
```typescript
// 修改前：使用simulateClick()
simulateClick(imageContainer);
simulateClick(btn);

// 修改后：使用原生click()避免重复触发
(imageContainer as HTMLElement).click();
(btn as HTMLElement).click();
```

### 2. 增加推荐图片等待时间

**修改位置1**：`generateAIImage`函数
```typescript
// 修改前：等待1秒
await new Promise(r => setTimeout(r, 1000));

// 修改后：等待2.5秒，确保推荐图片加载完成
await new Promise(r => setTimeout(r, 2500));
```

**修改位置2**：`insertAIImage`函数
```typescript
// 新增：在查找推荐图片区域之前，增加1.5秒的等待时间
await new Promise(r => setTimeout(r, 1500));
```

总等待时间：2.5秒（generateAIImage）+ 1.5秒（insertAIImage）= 4秒

### 3. 修复封面选择问题

**文件**：`src/content/weixin.ts`

**修改位置**：`setCoverFromContent`函数中的所有点击操作
```typescript
// 修改前：使用simulateClick()或复杂的事件序列
simulateClick(coverArea);
simulateClick(selectFromContentLink);
simulateClick(target);
simulateClick(btn);

// 修改后：统一使用原生click()
coverArea.click();
selectFromContentLink.click();
target.click();
btn.click();
```

涉及的点击操作：
1. 点击封面区域触发菜单
2. 点击"从正文选择"链接
3. 点击图片容器选择图片
4. 点击"下一步"按钮
5. 点击裁剪区域
6. 点击"确认"按钮

## 实现逻辑

### 流程图

```
输入提示词
    ↓
等待2.5秒
    ↓
检查是否有推荐图片？
    ├─ 是 → 跳过AI生成 → 等待1.5秒 → 查找推荐图片 → 点击第一张 → 插入
    └─ 否 → 点击"创作"按钮 → 等待AI生成 → 插入AI生成的图片
```

### 关键代码

**1. 检查推荐图片（generateAIImage函数）**
```typescript
// 等待推荐图片加载
await new Promise(r => setTimeout(r, 2500));

// 查找"已在图片库中找到以下图片"区域
let hasRecommendImages = false;
const allTexts = document.querySelectorAll('*');
for (const el of allTexts) {
  const text = (el as HTMLElement).textContent;
  if (text && text.includes('已在图片库中找到以下图片')) {
    logger.log('✅ 发现推荐图片区域，无需等待AI生成', 'success');
    hasRecommendImages = true;
    break;
  }
}

// 如果有推荐图片，直接返回成功，不点击"创作"按钮
if (hasRecommendImages) {
  logger.log('跳过AI生成，将直接使用推荐图片', 'info');
  return true;
}
```

**2. 插入推荐图片（insertAIImage函数）**
```typescript
// 增加等待时间，确保推荐图片加载完成
await new Promise(r => setTimeout(r, 1500));

// 查找推荐图片区域
const recommendImages = Array.from(recommendSection.querySelectorAll('img')).filter(img => {
  const rect = img.getBoundingClientRect();
  const parent = img.parentElement;
  // 推荐图片的特征：parent 为 'image-wrapper'，尺寸约 132x132
  return rect.width > 50 && rect.height > 50 && parent?.className?.includes('image-wrapper');
});

if (recommendImages.length > 0) {
  const firstRecommendImage = recommendImages[0];
  const imageContainer = firstRecommendImage.closest('div[class*="item"], li, .image-item, [class*="image"]');
  
  // 使用原生click()避免重复触发
  (imageContainer as HTMLElement).click();
  await new Promise(r => setTimeout(r, 800));
  
  // 点击"插入"按钮
  (btn as HTMLElement).click();
}
```

## 注意事项

1. 如果某个提示词没有推荐图片，会自动回退到AI生成流程
2. 推荐图片是微信根据提示词从图片库中匹配的，质量可能不如AI生成的图片精准
3. 如果需要更精准的图片，可以手动触发AI生成

## 修复总结

本次修复的核心思路是：**将所有使用`simulateClick()`的地方改为原生`click()`方法**，避免触发额外的鼠标事件序列，从而解决重复插入和选择失败的问题。

涉及的函数：
1. `clickWeixinImageAdaptive()` - 自适应按钮点击
2. `insertAIImage()` - 推荐图片和确定按钮点击
3. `setCoverFromContent()` - 封面选择流程中的所有点击操作
