# 微信公众号AI配图 - 自动选择推荐图片

**日期**: 2026-03-08 15:30  
**功能**: 微信AI配图自动选择  
**问题**: 输入提示词后自动选择推荐图片，无需等待AI生成

## 问题描述

在微信公众号编辑器中插入AI配图时，用户输入提示词后，微信会显示两类图片：
1. **历史生成的图片**（上方）：之前AI生成的图片，尺寸220x220，parent类为`ai-image-item-wrp`
2. **推荐的图片**（下方）：微信图片库中的推荐图片，尺寸132x132，parent类为`image-wrapper`

原有逻辑会等待AI生成新图片（约30-60秒），但实际上可以直接使用推荐的图片，节省时间。

## 解决方案

### 1. 在 generateAIImage 函数中添加推荐图片检测

在输入提示词后，点击"创作"按钮之前，先检查是否有推荐图片：

```typescript
// 关键优化：在点击"创作"按钮之前，先检查是否有推荐图片
logger.log('检查是否有推荐图片...', 'info');

// 等待一下让推荐图片加载
await new Promise(r => setTimeout(r, 1000));

// 查找"已在图片库中找到以下图片"区域
let hasRecommendImages = false;
const allTexts = document.querySelectorAll('*');
for (const el of allTexts) {
  const text = (el as HTMLElement).textContent;
  if (text && text.includes('已在图片库中找到以下图片')) {
    logger.log('✅ 发现推荐图片区域，无需等待AI生成', 'success');
    hasRecommendImages = true;
    break;
  }
}

// 如果有推荐图片，直接返回成功，不点击"创作"按钮
if (hasRecommendImages) {
  logger.log('跳过AI生成，将直接使用推荐图片', 'info');
  return true;
}

// 如果没有推荐图片，继续原有逻辑：点击"创作"按钮等待AI生成
logger.log('未发现推荐图片，开始AI生成流程', 'info');
```

### 2. 在 insertAIImage 函数中优先选择推荐图片

```typescript
// 新增：优先查找推荐图片区域（"已在图片库中找到以下图片"）
if (activeDialog) {
  logger.log('查找推荐图片区域...', 'info');
  
  // 查找"已在图片库中找到以下图片"区域
  let recommendSection: Element | null = null;
  const allTexts = activeDialog.querySelectorAll('*');
  for (const el of allTexts) {
    const text = (el as HTMLElement).textContent;
    if (text && text.includes('已在图片库中找到以下图片')) {
      recommendSection = el.parentElement || el.nextElementSibling;
      break;
    }
  }
  
  // 如果找到推荐区域，查找其中的图片
  if (recommendSection) {
    const recommendImages = Array.from(recommendSection.querySelectorAll('img')).filter(img => {
      const rect = img.getBoundingClientRect();
      const parent = img.parentElement;
      // 推荐图片的特征：parent 为 'image-wrapper'，尺寸约 132x132
      return rect.width > 50 && rect.height > 50 && parent?.className?.includes('image-wrapper');
    });
    
    if (recommendImages.length > 0) {
      // 选择第一张推荐图片并插入
      // ...
    }
  }
}
```

### 2. 图片识别特征

**推荐图片的特征**：
- 位于"已在图片库中找到以下图片"区域下方
- 父容器类名包含 `image-wrapper`
- 尺寸约为 132x132 像素
- 无需等待生成，立即可用

**历史图片的特征**：
- 位于弹窗上方
- 父容器类名为 `ai-image-item-wrp`
- 尺寸约为 220x220 像素
- 是之前AI生成的图片

### 3. 执行流程

1. 打开AI配图弹窗
2. 输入提示词
3. **等待1秒让推荐图片加载**
4. **检查是否有"已在图片库中找到以下图片"区域**
5. 如果有推荐图片：
   - 跳过点击"创作"按钮
   - 直接在 `insertAIImage` 中选择推荐图片
   - 点击图片容器
   - 点击确定按钮
   - 完成插入（约2-3秒）
6. 如果没有推荐图片：
   - 点击"创作"按钮
   - 等待AI生成图片（约30-60秒）
   - 选择生成的图片并插入

## 优势

1. **大幅提速**：从等待30-60秒减少到2秒内完成
2. **节省资源**：无需调用AI生成接口
3. **用户体验**：推荐图片通常质量较高，符合提示词要求
4. **向下兼容**：如果没有推荐图片，仍会使用原有的AI生成逻辑
