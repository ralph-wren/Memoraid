# 额度显示同时扣除免费和付费的问题分析

## 问题描述

用户反馈：生成一篇文章时，插件上显示同时扣除了1次免费额度和1次付费额度，但数据库显示只扣除了免费额度。

## 当前额度扣除逻辑

### 1. AI聊天接口（`/api/ai/chat`）

```typescript
// backend/src/index.ts 第3662-3670行
if (trackingType === 'user') {
    if (!hasPaidQuota) {
        // 没有付费额度，记录免费额度使用
        await env.DB.prepare(
            'INSERT INTO ai_usage_logs (user_id, model) VALUES (?, ?)'
        ).bind(userId, body.model).run();
    } else {
        // 有付费额度，不记录（将在文章报告时扣除）
        console.log(`[AI Chat] 用户 ${userId} 使用付费额度，不在此处扣除`);
    }
}
```

### 2. 文章上报接口（`/api/articles/report`）

```typescript
// backend/src/index.ts 第3940-3970行
// 优先扣除付费额度，再扣除免费额度
if (paidQuota > 0) {
    const deductFromPaid = Math.min(paidQuota, newArticlesCount);
    await env.DB.prepare(
        'UPDATE user_quotas SET paid_quota_remaining = paid_quota_remaining - ? WHERE user_id = ?'
    ).bind(deductFromPaid, userId).run();
    
    const remainingToDeduct = newArticlesCount - deductFromPaid;
    if (remainingToDeduct > 0) {
        // 记录免费额度使用
        for (let i = 0; i < remainingToDeduct; i++) {
            await env.DB.prepare(
                'INSERT INTO ai_usage_logs (user_id, model) VALUES (?, ?)'
            ).bind(userId, 'article-generation').run();
        }
    }
} else {
    // 全部从免费额度扣除
    for (let i = 0; i < newArticlesCount; i++) {
        await env.DB.prepare(
            'INSERT INTO ai_usage_logs (user_id, model) VALUES (?, ?)'
        ).bind(userId, 'article-generation').run();
    }
}
```

## 问题分析

### 场景1：用户有付费额度

假设用户有：
- 免费额度：20次（已使用0次，剩余20次）
- 付费额度：10次

**生成1篇文章的流程：**

1. **AI聊天生成内容**：
   - 检查：`hasPaidQuota = true`（有付费额度）
   - 操作：不记录使用（不插入 `ai_usage_logs`）
   - 日志：`[AI Chat] 用户 xxx 使用付费额度，不在此处扣除`

2. **文章上报**：
   - 检查：`paidQuota = 10 > 0`
   - 操作：扣除1次付费额度（`paid_quota_remaining: 10 → 9`）
   - 操作：不记录免费额度使用（`remainingToDeduct = 0`）
   - 日志：`[Article Report] 已扣除付费额度: 1 次`

3. **查询额度**：
   - `usageCount = 0`（`ai_usage_logs` 中没有记录）
   - `freeRemaining = 20 - 0 = 20`（免费额度没变）
   - `paidQuota = 9`（付费额度减少1）

**预期结果：** 只扣除付费额度，免费额度不变

### 场景2：用户没有付费额度

假设用户有：
- 免费额度：20次（已使用0次，剩余20次）
- 付费额度：0次

**生成1篇文章的流程：**

1. **AI聊天生成内容**：
   - 检查：`hasPaidQuota = false`（没有付费额度）
   - 操作：记录免费额度使用（插入 `ai_usage_logs`）
   - 日志：`[AI Chat] 已记录用户 xxx 的免费额度使用`

2. **文章上报**：
   - 检查：`paidQuota = 0`
   - 操作：记录免费额度使用（插入 `ai_usage_logs`）
   - 日志：`[Article Report] 已扣除免费额度: 1 次`

3. **查询额度**：
   - `usageCount = 2`（`ai_usage_logs` 中有2条记录）
   - `freeRemaining = 20 - 2 = 18`（免费额度减少2）

**问题：** 同一篇文章，AI聊天和文章上报都记录了免费额度使用，导致扣除了2次！

## 根本原因

**AI聊天和文章上报都会记录免费额度使用，导致重复扣除！**

- 如果用户**有付费额度**：AI聊天不记录，文章上报扣除付费额度 ✅ 正确
- 如果用户**没有付费额度**：AI聊天记录1次，文章上报又记录1次 ❌ 错误

## 解决方案

### 已采用方案：AI聊天不记录使用（2026-03-27 23:50）

修改AI聊天接口，登录用户的AI聊天不记录额度使用，额度扣除统一在文章报告时处理：

```typescript
// backend/src/index.ts 第3655-3670行
// 【修复2026-03-27】AI聊天不记录额度使用
// 额度扣除统一在 /api/articles/report 端点处理，避免重复扣除
if (trackingType === 'user') {
    // 登录用户：AI聊天不记录使用，额度将在文章报告时统一扣除
    console.log(`[AI Chat] 用户 ${userId} AI聊天成功，额度将在文章报告时扣除`);
} else {
    // 匿名用户：记录免费额度使用（匿名用户没有文章上报功能）
    await env.DB.prepare(
        'INSERT INTO ai_usage_logs (anonymous_id, model) VALUES (?, ?)'
    ).bind(anonymousId, body.model).run();
}
```

### 修复效果

1. ✅ 避免AI聊天和文章上报重复扣除免费额度
2. ✅ 保持付费额度优先扣除的逻辑
3. ✅ 匿名用户的额度记录不受影响
