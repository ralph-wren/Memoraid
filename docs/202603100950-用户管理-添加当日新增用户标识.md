# 用户管理：添加当日新增用户标识

## 修改日期
2026-03-10 09:50

## 功能描述
在后台管理页面的用户管理模块中，为当日新增的用户添加"新"标识，方便管理员快速识别新注册用户。

## 修改内容

### 1. 后端API修改（backend/src/index.ts）

#### 1.1 添加当日新增用户判断逻辑
在 `/api/admin/users` 接口的SQL查询中：

```typescript
// 计算今天0点的时间戳（用于判断是否为当日新增用户）
const todayStart = Math.floor(new Date().setHours(0, 0, 0, 0) / 1000);

// 在SQL查询中添加字段
-- 是否为当日新增用户（注册时间 >= 今天0点）
CASE WHEN u.created_at >= ${todayStart} THEN 1 ELSE 0 END as is_new_today
```

**说明**：
- 使用 `new Date().setHours(0, 0, 0, 0)` 获取今天0点的时间戳
- 通过 CASE WHEN 判断用户的 `created_at` 是否大于等于今天0点
- 返回 1 表示是当日新增，0 表示不是

### 2. 前端渲染修改（backend/src/index.ts）

#### 2.1 在用户列表渲染函数中添加"新"标识
在 `renderUsers` 函数中：

```javascript
// 判断是否为当日新增用户
const isNewToday = u.is_new_today === 1;
const newBadge = isNewToday ? '<span style="background:#10b981;color:#fff;font-size:0.65rem;padding:1px 5px;border-radius:4px;margin-left:6px;vertical-align:middle">新</span>' : '';

// 在用户邮箱后面显示标识
<div class="user-email" style="color:var(--accent-secondary)">\${u.email}\${paidBadge}\${newBadge}</div>
```

**说明**：
- 使用绿色背景（#10b981）的徽章显示"新"字
- 样式与"付费"标识保持一致
- 标识显示在用户邮箱后面，付费标识之后

## 视觉效果
- 当日新增用户会在邮箱后面显示绿色的"新"标识
- 如果用户既是付费用户又是当日新增，会同时显示"付费"和"新"两个标识
- 标识样式：绿色背景、白色文字、圆角边框

## 技术细节
1. **时间计算**：使用服务器当前时间的0点作为判断基准
2. **数据库查询**：在SQL中直接计算，避免在应用层处理
3. **前端渲染**：使用条件判断动态生成HTML标签

## 测试建议
1. 创建一个新用户，检查是否显示"新"标识
2. 查看昨天或更早注册的用户，确认不显示"新"标识
3. 检查付费用户同时也是新用户时，两个标识是否都正常显示
4. 跨天后检查标识是否正确更新

## 注意事项
- 标识基于服务器时间判断，不同时区可能有差异
- 每次刷新页面都会重新计算，确保标识准确
- 标识仅在用户管理页面显示，不影响其他功能

### 部署问题
初次部署时遇到 wrangler 无法找到入口点的错误：
```
Missing entry-point to Worker script or to assets directory
```

### 问题原因
- 项目中同时存在 `wrangler.toml` 和 `wrangler.jsonc` 两个配置文件
- wrangler 优先读取 `wrangler.jsonc`，但该文件缺少必要的配置项（name、main等）

### 解决方案
将 `wrangler.toml` 中的配置合并到 `wrangler.jsonc` 中：
- 添加 `name`: "memoraid-backend"
- 添加 `main`: "src/index.ts"
- 添加 `compatibility_date` 和 `compatibility_flags`
- 添加 `d1_databases` 和 `r2_buckets` 配置
- 移除不支持的 `traces` 配置项
