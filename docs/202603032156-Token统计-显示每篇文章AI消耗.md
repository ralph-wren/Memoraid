# Token 统计功能实现

**日期**: 2026-03-03 21:56  
**版本**: v1.2.0  
**功能**: 统计并显示每篇文章的 AI Token 消耗

## 问题描述

用户希望能够统计每篇文章生成时消耗的 Token 数量，以便：
1. 了解每篇文章的成本
2. 在用户后台和管理员后台查看 Token 消耗明细
3. 在插件结果页面实时显示 Token 消耗

## 解决方案

### 1. 前端插件改动

**文件**: `src/background/index.ts`

- 在 4 个流式 AI 调用中添加 `stream_options: { include_usage: true }` 参数
- 从最后一个 chunk 中提取 `usage` 字段（包含 `prompt_tokens`、`completion_tokens`、`total_tokens`）
- 通过 `reportArticlePublish` 的 `extra` 字段将 token 数据传递给后端
- 添加 console.log 调试日志便于排查问题

涉及的函数：
- `startRefinement` - 文档精炼
- `startSummarization` - 内容摘要
- `startArticleGeneration` - 文章生成
- `startArticleGenerationAndPublish` - 生成并发布

**文件**: `src/components/Home.tsx`

- 添加 `tokenUsage` 状态
- 在结果页面显示 Token 消耗（输入/输出/总计）
- 新任务开始时清除上次的 tokenUsage

**文件**: `src/utils/types.ts`

- 新增 `TokenUsage` 接口定义
- 在 `ActiveTask` 接口中添加 `tokenUsage` 字段

### 2. 后端 API 改动

**文件**: `backend/src/index.ts`

**API 查询改动**:
- `/api/admin/articles` - 查询时包含 `extra_info` 字段，返回前解析 JSON 提取 token 数据
- `/api/user/articles` - 同上

**页面渲染改动**:
- admin 页面 `renderArticles` 函数 - 新增 Token 列，鼠标悬停显示输入/输出明细
- user 页面 `renderArticles` 函数 - 新增 Token 列，用 indigo 色徽章显示
- 表头新增 "Token" 列

### 3. 数据存储

Token 数据存储在 `articles.extra_info` 字段的 JSON 中：

```json
{
  "sourceUrl": "https://example.com",
  "type": "article_generation",
  "promptTokens": 1234,
  "completionTokens": 5678,
  "totalTokens": 6912
}
```

### 验证步骤

1. **在浏览器中打开插件**，生成一篇新文章
2. **打开浏览器控制台**（F12），查看日志：
   ```
   [startSummarization] 提取到 tokenUsage: {promptTokens: xxx, completionTokens: xxx, totalTokens: xxx}
   ```
3. **访问后台页面**：
   - https://memoraid.dpdns.org/user （用户后台）
   - https://memoraid.dpdns.org/admin （管理员后台）
4. **查看文章列表**，应该能看到 Token 列显示数值

## 注意事项

1. **历史文章**：之前生成的文章没有 token 数据，Token 列会显示 `-`
2. **新文章**：从 v1.2.0 开始生成的文章都会记录 token 消耗
3. **调试日志**：生产环境可以考虑移除 console.log，或改为仅在 debugMode 下输出
