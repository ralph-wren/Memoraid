# 定时任务 - 修复匿名用户认证问题

## 问题描述

用户在保存定时任务时遇到 `{"error":"Unauthorized"}` 错误。

## 问题原因

后端定时任务 API 使用 `getUserIdFromRequest()` 函数进行认证，该函数只检查 `Authorization` header 中的 JWT token，不支持匿名用户的 `X-Anonymous-ID` header。

## 解决方案

修改后端 API 的认证逻辑，支持匿名用户：

### 修改的 API 接口

1. `GET /api/scheduled-tasks` - 获取任务列表
2. `POST /api/scheduled-tasks` - 创建任务
3. `PUT /api/scheduled-tasks/:id` - 更新任务
4. `DELETE /api/scheduled-tasks/:id` - 删除任务

### 认证逻辑

```typescript
// 支持匿名用户：优先使用 Authorization，否则使用 X-Anonymous-ID
let userId = getUserIdFromRequest(request);
if (!userId) {
  const anonymousId = request.headers.get('X-Anonymous-ID');
  if (anonymousId) {
    userId = anonymousId;
  }
}

if (!userId) {
  return new Response(JSON.stringify({ error: 'Unauthorized' }), { 
    status: 401, headers: { ...corsHeaders, 'Content-Type': 'application/json' } 
  });
}
```

### 认证优先级

1. 优先使用 `Authorization` header（已登录用户）
2. 如果没有，使用 `X-Anonymous-ID` header（匿名用户）
3. 如果都没有，返回 401 Unauthorized
