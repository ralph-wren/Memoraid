# 文章列表 - 优化排序和筛选功能

## 修改时间
2026-03-23 22:00

## 需求描述
1. 移除账号字段（用户只有一个账号）
2. Token和发布时间列添加排序功能
3. 默认按发布时间倒序排列
4. 时间格式精确到秒
5. 平台筛选支持多选

## 实现方案

### 1. 移除账号列
- 从表格中删除账号列
- 表头从"标题、平台、账号、Token、发布时间"改为"标题、平台、Token、发布时间"

### 2. 添加排序功能
- 新增 `currentSortOrder` 变量，取值为 'desc'（降序）或 'asc'（升序）
- 默认按发布时间降序排列（最新的在前）
- 点击表头的Token或发布时间列可切换排序
- 点击同一列时切换升序/降序
- 点击不同列时默认降序
- 表头显示排序箭头：↓（降序）、↑（升序）

### 3. 时间格式优化
- 将相对时间（"3小时前"）改为精确时间
- 格式：YYYY-MM-DD HH:mm:ss
- 示例：2026-03-23 22:00:35

### 4. 平台多选筛选
- `currentPlatform` 从字符串改为数组
- 点击"全部平台"清空筛选
- 点击具体平台时切换选中状态（支持多选）
- 选中的平台按钮显示active样式
- API请求参数从 `&platform=xxx` 改为 `&platforms=xxx,yyy,zzz`

## 技术细节

### 排序逻辑
```javascript
// 点击排序列时的逻辑
if (currentSortBy === sortBy) {
    // 同一列，切换升降序
    currentSortOrder = currentSortOrder === 'desc' ? 'asc' : 'desc';
} else {
    // 不同列，默认降序
    currentSortBy = sortBy;
    currentSortOrder = 'desc';
}

// 前端排序
if (currentSortBy === 'token') {
    articles.sort((a, b) => {
        const diff = (b.totalTokens || 0) - (a.totalTokens || 0);
        return currentSortOrder === 'desc' ? diff : -diff;
    });
} else {
    articles.sort((a, b) => {
        const diff = (b.publish_time || 0) - (a.publish_time || 0);
        return currentSortOrder === 'desc' ? diff : -diff;
    });
}
```

### 多选筛选逻辑
```javascript
function filterPlatform(platform) {
    if (platform === 'all') {
        currentPlatform = []; // 清空筛选
    } else {
        const index = currentPlatform.indexOf(platform);
        if (index > -1) {
            currentPlatform.splice(index, 1); // 取消选中
        } else {
            currentPlatform.push(platform); // 添加选中
        }
    }
}
```

### 时间格式化
```javascript
function formatTime(ts) {
    if (!ts) return '-';
    const d = new Date(ts * 1000);
    const year = d.getFullYear();
    const month = String(d.getMonth() + 1).padStart(2, '0');
    const day = String(d.getDate()).padStart(2, '0');
    const hour = String(d.getHours()).padStart(2, '0');
    const minute = String(d.getMinutes()).padStart(2, '0');
    const second = String(d.getSeconds()).padStart(2, '0');
    return year + '-' + month + '-' + day + ' ' + hour + ':' + minute + ':' + second;
}
```
