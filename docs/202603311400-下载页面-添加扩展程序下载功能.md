## 实现内容

- 将 `release/memoraid-release.zip` 上传到 Cloudflare R2 存储
- 存储路径：`memoraid/memoraid-release.zip`
- 文件大小：1.1MB

### 2. 后端 API
添加了下载 API 端点：
- 路径：`/api/download/extension`
- 方法：GET
- 功能：从 R2 读取 zip 文件并返回给用户下载
- 响应头：
  - Content-Type: application/zip
  - Content-Disposition: attachment; filename="memoraid-release.zip"
  - Cache-Control: public, max-age=3600

## 技术实现

### 前端下载逻辑
```javascript
async function downloadExtension() {
  // 调用下载 API
  const response = await fetch('/api/download/extension');
  
  // 创建 Blob 并触发下载
  const blob = await response.blob();
  const url = window.URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = 'memoraid-release.zip';
  a.click();
  
  // 清理资源
  window.URL.revokeObjectURL(url);
}
```

### 后端下载 API
```typescript
if (request.method === 'GET' && url.pathname === '/api/download/extension') {
  const object = await env.R2.get('memoraid/memoraid-release.zip');
  if (!object) {
    return new Response('文件不存在', { status: 404 });
  }
  
  const headers = new Headers();
  headers.set('Content-Type', 'application/zip');
  headers.set('Content-Disposition', 'attachment; filename="memoraid-release.zip"');
  headers.set('Cache-Control', 'public, max-age=3600');
  
  return new Response(object.body, { headers });
}
```

## 使用说明

### 更新离线安装包
当有新版本发布时，执行以下命令更新 R2 中的文件：

```bash
cd backend
bash -lc "CI=1 npx wrangler r2 object put pothos-images/memoraid/memoraid-release.zip --file ../release/memoraid-release.zip --content-type application/zip"
```

### 更新版本号
修改下载页面中的版本号显示：
```html
<div>✓ 版本：<span id="versionNumber">1.3.0</span></div>
```

## 注意事项
1. 每次发布新版本时，需要手动上传新的 zip 文件到 R2
2. 建议同时更新页面中显示的版本号
3. R2 文件设置了 1 小时缓存，更新后可能需要等待缓存过期
4. 离线安装包不会自动更新，用户需要手动下载新版本
