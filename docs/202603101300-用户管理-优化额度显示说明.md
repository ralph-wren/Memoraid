# 用户管理：优化额度显示说明

## 修改日期
2026-03-10 13:00

## 问题描述
用户反馈在后台管理页面看到某用户只生成了1篇文章，但免费额度显示为 `2/5`，不清楚为什么会消耗2次额度。

## 问题原因
系统中的**免费额度**会在两种情况下消耗：
1. **AI聊天功能** - 用户在插件中使用AI聊天时，每次对话消耗1次
2. **文章生成功能** - 生成新文章时消耗1次（如果没有付费额度）

所以 `2/5` 表示：
- 可能使用了1次AI聊天
- 生成了1篇文章
- 总共消耗2次免费额度

## 解决方案

### 1. 后端SQL查询优化（backend/src/index.ts）

在用户列表查询中添加 `total_articles` 字段：

```sql
-- 总文章数（用于计算AI聊天次数）
(SELECT COUNT(*) FROM articles a_all 
 JOIN accounts ac_all ON a_all.account_id = ac_all.id 
 WHERE ac_all.user_id = u.id) as total_articles
```

**说明**：
- 统计用户的总文章数
- 用于计算 AI聊天次数 = 总使用次数 - 总文章数

### 2. 前端显示优化（backend/src/index.ts）

#### 2.1 表头添加提示
在"免费额度"列添加 title 提示：
```html
<th title="包括AI聊天和文章生成的总使用次数">免费额度</th>
```

#### 2.2 数据单元格添加详细提示
在渲染用户列表时，为免费额度单元格添加详细的使用明细：

```javascript
// 计算AI聊天次数（总使用次数 - 总文章数）
const chatUsage = Math.max(0, (u.ai_usage || 0) - (u.total_articles || 0));
const articleUsage = u.total_articles || 0;

// 在单元格上添加 title 提示
<td title="AI聊天: ${chatUsage}次 | 文章生成: ${articleUsage}篇">
  <span class="status-pill">${u.ai_usage || 0}/${limit}</span>
</td>
```

**说明**：
- 鼠标悬停在免费额度上时，会显示详细的使用明细
- 格式：`AI聊天: X次 | 文章生成: Y篇`
- 让管理员清楚了解用户的具体使用情况

### 3. 其他列也添加了提示
- **3日文章**：`最近3天生成的文章数量`
- **7日文章**：`最近7天生成的文章数量`
- **消耗TOKEN**：`累计消耗的AI Token数量`

## 技术说明

### 额度消耗规则
1. **免费额度**：
   - 匿名用户：5次
   - 注册用户：20次
   - 包括AI聊天和文章生成

2. **付费额度**：
   - 充值获得
   - 优先使用付费额度
   - 付费额度用完后才使用免费额度

3. **计算公式**：
   - AI聊天次数 = 总使用次数 - 总文章数
   - 总使用次数 = ai_usage_logs 表的记录数
   - 总文章数 = articles 表的记录数
