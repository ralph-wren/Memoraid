# 小红书话题自动添加功能优化

## 问题描述
文章最后有5个话题标签，需要在正文描述里自动填入话题。输入话题后会弹出菜单让选择话题，默认选择第一个。

## 测试验证
通过测试脚本验证了话题输入和选择的工作流程：

1. **编辑器选择器**: `.tiptap.ProseMirror[contenteditable="true"]`
2. **话题菜单选择器**: `#creator-editor-topic-container`
3. **菜单项选择器**: `[class*="item"]`
4. **测试结果**: 找到 2 个菜单项，点击第一个成功

## 解决方案

### 优化后的实现逻辑

1. **直接在正文编辑器中输入话题**
   - 不再尝试点击"活动话题"或工具栏按钮
   - 直接在编辑器末尾输入话题关键词
   - 第一个话题前添加两个换行，后续话题添加一个换行

2. **查找话题下拉菜单**
   - 优先使用 ID 选择器 `#creator-editor-topic-container`
   - 兜底查找其他可能的菜单容器
   - 最多尝试 10 次，每次间隔 200ms

3. **选择第一个菜单项**
   - 使用 `[class*="item"]` 等选择器查找菜单项
   - 过滤出可见且包含 `#` 的菜单项
   - 点击第一个菜单项完成选择

### 关键代码改动

```typescript
// 添加话题功能 - 在正文编辑器中直接输入话题并选择建议
const addTopics = async (topics: string[]): Promise<boolean> => {
    // 1. 查找正文编辑器
    const editor = findElement(SELECTORS.editor);
    
    for (let i = 0; i < topics.length; i++) {
        // 2. 聚焦编辑器并移动光标到末尾
        simulateClick(editor);
        editor.focus();
        
        // 移动光标到末尾
        const selection = window.getSelection();
        const range = document.createRange();
        range.selectNodeContents(editor);
        range.collapse(false);
        selection.removeAllRanges();
        selection.addRange(range);
        
        // 3. 输入话题（在新行输入）
        const textToInsert = i === 0 ? `\n\n${keyword}` : `\n${keyword}`;
        document.execCommand('insertText', false, textToInsert);
        
        // 4. 查找话题下拉菜单
        const menuById = document.querySelector('#creator-editor-topic-container');
        
        // 5. 查找菜单项并点击第一个
        const elements = Array.from(menu.querySelectorAll('[class*="item"]'));
        const visibleItems = elements.filter(el => 
            isElementVisible(el) && 
            el.textContent?.includes('#') &&
            el !== menu
        );
        
        // 6. 点击第一个菜单项
        simulateClick(visibleItems[0]);
    }
};
```

## 技术细节

### 光标定位
使用 `Range.collapse(false)` 将光标移动到编辑器末尾，确保话题添加在正文最后。

### 菜单项过滤
- 必须可见 (`isElementVisible`)
- 必须包含 `#` 字符
- 排除菜单容器本身

### 等待时机
- 输入话题后等待 800ms，让菜单有足够时间出现
- 点击菜单项后等待 500ms，让选择生效
