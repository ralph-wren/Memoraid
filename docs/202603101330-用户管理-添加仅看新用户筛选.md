# 用户管理：添加仅看新用户筛选

## 修改日期
2026-03-10 13:30

## 功能描述
在用户管理页面添加"仅看新用户"筛选按钮，方便管理员快速查看当日注册的新用户。

## 修改内容

### 1. 前端HTML修改（backend/src/index.ts）

在工具栏中添加"仅看新用户"按钮：

```html
<button id="paidFilterBtn" class="btn-sm btn-outline" onclick="togglePaidFilter()" style="font-size:0.8rem">💰 仅看付费用户</button>
<button id="newFilterBtn" class="btn-sm btn-outline" onclick="toggleNewFilter()" style="font-size:0.8rem">🆕 仅看新用户</button>
```

### 2. 前端JavaScript修改（backend/src/index.ts）

#### 2.1 添加全局变量
```javascript
let userNewOnly = false; // 是否仅看新用户（当日注册）
```

#### 2.2 添加切换函数
```javascript
// 切换新用户筛选（当日注册）
function toggleNewFilter() {
    userNewOnly = !userNewOnly;
    const btn = document.getElementById('newFilterBtn');
    if (userNewOnly) {
        btn.style.background = 'var(--accent)';
        btn.style.color = '#fff';
        btn.textContent = '🆕 仅看新用户 ✓';
    } else {
        btn.style.background = '';
        btn.style.color = '';
        btn.textContent = '🆕 仅看新用户';
    }
    fetchUsers(true);
}
```

#### 2.3 修改API调用
在 `fetchUsers` 函数中添加 `new_only` 参数：
```javascript
const params = new URLSearchParams({
    limit: usersLimit.toString(),
    offset: usersOffset.toString(),
    sort: userSort,
    order: userSortOrder,
    paid_only: userPaidOnly ? '1' : '0',
    new_only: userNewOnly ? '1' : '0', // 新增
    keyword: userSearchKeyword
});
```

### 3. 后端API修改（backend/src/index.ts）

#### 3.1 获取筛选参数
```javascript
const newOnly = url.searchParams.get('new_only') === '1'; // 是否仅看新用户（当日注册）
```

#### 3.2 修改SQL查询筛选逻辑
```javascript
// 筛选条件：使用 HAVING 子句
const havingConditions = [];

// 仅看付费用户：过滤有充值记录的
if (paidOnly) {
  havingConditions.push('paid_count > 0');
}

// 仅看新用户：过滤当日注册的用户
if (newOnly) {
  havingConditions.push('is_new_today = 1');
}

if (havingConditions.length > 0) {
  query += ` HAVING ` + havingConditions.join(' AND ');
}
```

**说明**：
- 使用 `is_new_today` 字段判断是否为当日新增用户
- 该字段在之前的修改中已经添加到SQL查询中
- 值为 1 表示当日注册，0 表示非当日注册

#### 3.3 修改总数统计
```javascript
// 新用户筛选（当日注册）
if (newOnly) {
    conditions.push(`u.created_at >= ${todayStart}`);
}
```

**说明**：
- 使用 `created_at >= todayStart` 判断是否为当日注册
- `todayStart` 是中国时区今天0点的UTC时间戳

## 使用说明

### 筛选功能
1. **仅看付费用户**：点击后只显示有充值记录的用户
2. **仅看新用户**：点击后只显示当日注册的用户
3. **组合筛选**：可以同时启用两个筛选，查看当日注册的付费用户

### 按钮状态
- **未激活**：灰色边框，显示"🆕 仅看新用户"
- **已激活**：蓝色背景，白色文字，显示"🆕 仅看新用户 ✓"

### 筛选逻辑
- 筛选条件使用 AND 逻辑组合
- 例如：同时启用"仅看付费用户"和"仅看新用户"，只显示当日注册且有充值记录的用户

## 技术细节

### 时间判断
- 使用中国时区（UTC+8）判断"当日注册"
- 基于之前修复的时区计算逻辑
- 确保与"新"标识的判断逻辑一致

### SQL优化
- 使用 `HAVING` 子句进行筛选，避免重复计算
- 总数统计使用 `WHERE` 子句，提高查询效率
