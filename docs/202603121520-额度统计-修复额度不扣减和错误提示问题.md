# 额度统计：修复额度不扣减和错误提示问题

## 修改日期
2026-03-12 15:20

## 问题描述
1. **额度不扣减**：生成2篇文章后，额度还是4次，没有扣减
2. **错误信息一直显示**：即使额度加载成功，之前的错误信息还在显示

## 问题原因

### 问题1：额度不扣减
- 后端统计额度时查询 `model = 'article-generation'` 的记录
- 但实际记录AI使用时，model字段是 `deepseek-chat`
- 导致生成文章的记录没有被统计到，额度不会扣减

### 问题2：错误信息一直显示
- 错误信息通过 `errorMessage` 状态显示
- 一旦设置后，没有清除机制
- 即使后续操作成功，错误信息仍然保留

## 解决方案

### 方案1：修改统计逻辑
将后端统计从"只统计 article-generation"改为"统计所有AI使用"，这样无论model是什么值，都会被统计。

### 方案2：添加关闭按钮
在错误提示框添加关闭按钮，让用户可以手动关闭错误信息。

## 修改内容

### 后端修改（backend/src/index.ts）

#### 修改额度统计逻辑
```typescript
// 获取已使用的免费次数（统计所有AI使用）
const usageCount = await env.DB.prepare(
  'SELECT COUNT(*) as count FROM ai_usage_logs WHERE user_id = ?'
).bind(userId).first('count') as number || 0;
```

**修改前**：
```typescript
// 获取已使用的免费次数（只统计文章生成）
const usageCount = await env.DB.prepare(
  'SELECT COUNT(*) as count FROM ai_usage_logs WHERE user_id = ? AND model = ?'
).bind(userId, 'article-generation').first('count') as number || 0;
```

**说明**：
- 移除了 `AND model = ?` 条件
- 移除了 `.bind()` 的第二个参数
- 现在统计该用户的所有AI使用记录，包括聊天和文章生成

### 前端修改（src/components/Home.tsx）

#### 添加错误提示关闭按钮
```tsx
{errorMessage && (
  <div className="w-full px-4 mb-2">
    <div className="bg-red-50 border border-red-200 text-red-600 px-4 py-3 rounded-lg text-sm flex items-start gap-2 text-left">
      <X className="w-4 h-4 mt-0.5 shrink-0" />
      <span className="break-words flex-1">{errorMessage}</span>
      <button 
        onClick={() => setErrorMessage(null)}
        className="text-red-400 hover:text-red-600 transition shrink-0"
        title="关闭"
      >
        <X className="w-4 h-4" />
      </button>
    </div>
  </div>
)}
```

**说明**：
- 添加了关闭按钮（X图标）
- 点击按钮调用 `setErrorMessage(null)` 清除错误信息
- 使用 `flex-1` 让错误文本占据剩余空间
- 使用 `shrink-0` 防止按钮被压缩

## 技术细节

### AI使用记录的model字段
- 文章生成：使用AI聊天接口，model = `deepseek-chat`
- AI聊天：使用AI聊天接口，model = `deepseek-chat`
- 两者使用同一个接口，model字段相同

### 统计策略变更
- **之前**：只统计 `model = 'article-generation'` 的记录（但实际没有这样的记录）
- **现在**：统计所有AI使用记录（包括聊天和文章生成）
- **影响**：AI聊天也会消耗免费额度

### 用户体验改进
1. **额度正确扣减**：生成文章后，额度立即减少
2. **错误可关闭**：用户可以手动关闭错误提示
3. **自动清除**：成功加载额度时，自动清除错误信息
