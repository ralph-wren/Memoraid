# 小红书简介 - 添加笔记简介功能

## 功能描述

在小红书发布页面添加话题时,先自动填充一段文章简介(50-100字),然后再添加话题标签。

## 简介格式标记

为了让AI生成的简介能够被准确提取,使用了明确的格式标记:

```
[简介]简介内容
```

**示例:**
```
[简介]最近发现一个超好用的工具，帮我节省了一半工作时间！分享给需要的姐妹们 ✨
```

## 实现原理

小红书的简介和话题是在同一个输入框中填写的:
1. 先在正文编辑器末尾添加简介文本
2. 然后添加话题标签(#话题名)
3. 话题标签会触发下拉菜单,选择第一个建议

## 修改内容

### 1. 修改提示词 (`src/utils/prompts.ts`)

在小红书提示词中添加了生成简介的要求:

```typescript
### 笔记简介（CRITICAL）
- 小红书笔记**必须**在正文开头包含一段简短的简介（50-80字）
- 简介**必须**使用以下格式标记：`[简介]简介内容`
- 简介要概括文章核心内容，吸引读者点击
- 简介要包含关键信息点，但不能剧透全部内容
- 简介语气要轻松自然，可以带1-2个emoji
- 示例格式：
  - `[简介]最近发现一个超好用的工具，帮我节省了一半工作时间！分享给需要的姐妹们 ✨`
  - `[简介]这个方法我用了3个月，效果真的绝了！建议收藏慢慢看 💡`
  - `[简介]踩了无数坑总结出来的经验，看完能少走很多弯路 🎯`
```

**位置:** 在"导出话题"部分之前

**注意:** 使用 `[简介]` 而不是 `【简介】`,因为中文括号会导致TypeScript编译错误。

### 5. 提取简介逻辑 (`src/background/index.ts`)

在 `handlePublishToXiaohongshu` 函数中添加简介提取逻辑:

```typescript
// 提取简介（使用[简介]标记）
// 格式: [简介]简介内容
let intro: string | undefined;
const introMatch = cleanedContent.match(/\[简介\](.+?)(?:\n|$)/);
if (introMatch && introMatch[1]) {
  intro = introMatch[1].trim();
  // 限制长度在100字以内
  if (intro.length > 100) {
    intro = intro.substring(0, 100);
  }
  console.log('[Background] Extracted intro:', intro);
  // 从正文中移除简介标记
  cleanedContent = cleanedContent.replace(/\[简介\].+?(?:\n|$)/, '').trim();
} else {
  // 如果没有找到[简介]标记,尝试从第一段提取(兜底逻辑)
  const firstParagraphMatch = cleanedContent.match(/^([^\n]+(?:\n[^\n]+)*?)(?:\n\n|$)/);
  if (firstParagraphMatch) {
    const firstParagraph = firstParagraphMatch[1].trim();
    // 如果第一段长度在30-150字之间，作为简介
    if (firstParagraph.length >= 30 && firstParagraph.length <= 150) {
      intro = firstParagraph.substring(0, 100);
      console.log('[Background] Extracted intro from first paragraph:', intro);
    }
  }
}
```

**提取规则:**
1. 优先查找 `[简介]` 标记
2. 如果找到,提取标记后的内容
3. 从正文中移除 `[简介]` 标记行
4. 如果没找到标记,尝试从第一段提取(兜底)
5. 限制最多100字

## 工作流程

### 完整流程

1. **AI生成内容**
   - 根据提示词生成标题、正文、简介(第一段)、话题

2. **后端处理** (`handlePublishToXiaohongshu`)
   - 提取标题(H1)
   - 提取简介(第一段,30-150字)
   - 提取话题(末尾的#标签)
   - 清理正文(移除H1和话题)
   - 保存到 `pending_xiaohongshu_publish`

3. **前端填充** (`autoFillContent`)
   - 步骤1-6: 填充标题、正文、排版、选择封面、下一步、原创声明
   - 步骤7: 调用 `addIntroAndTopics(intro, topics)`
     - 聚焦编辑器,移动光标到末尾
     - 添加简介: `\n\n${intro}`
     - 添加话题: `\n#话题1`, `\n#话题2`, ...
     - 每个话题触发下拉菜单,选择第一个建议
   - 步骤8-9: 设置内容类型声明、发布

### 示例

**AI生成的内容:**
```

[简介]最近看到张凌赫在社交平台上用了《逐玉》里谢征的进行曲，这波角色售后真的太会了！✨

(正文内容...)
```

## 注意事项

1. **简介格式标记**
   - 必须使用 `[简介]` 标记,不能使用中文括号 `【简介】`
   - 标记必须在正文开头
   - 标记后直接跟简介内容,不需要空格

2. **简介来源**
   - 简介由AI根据提示词生成
   - 使用明确的格式标记便于提取
   - 如果AI没有生成标记,会尝试从第一段提取(兜底)

3. **简介位置**
   - 简介添加在正文编辑器的末尾
   - 在话题标签之前
   - 与正文之间有两个换行符分隔

4. **兼容性**
   - 保留了旧的 `addTopics` 函数,确保向后兼容
   - 如果没有简介,行为与之前完全一致
   - 如果提取失败,不影响话题添加

5. **错误处理**
   - 如果简介提取失败,不影响话题添加
   - 如果话题添加失败,不影响其他步骤
   - 控制台会输出详细的日志信息

## 测试建议

1. **测试简介提取**
   - 生成一篇文章,查看控制台日志
   - 确认简介是否正确提取: `[Background] Extracted intro: ...`

2. **测试简介填充**
   - 打开小红书发布页面
   - 查看正文编辑器末尾是否有简介
   - 确认简介在话题之前

3. **测试话题添加**
   - 确认话题下拉菜单是否正常出现
   - 确认是否选择了第一个建议
   - 确认所有话题是否都添加成功

4. **测试边界情况**
   - 没有简介(第一段太短或太长)
   - 没有话题
   - 既没有简介也没有话题
