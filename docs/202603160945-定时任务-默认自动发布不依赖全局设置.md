# 定时任务默认自动发布，不依赖全局设置

## 问题描述

用户希望定时任务生成的文章默认自动发布，不需要依赖全局的"自动发布"设置。这样可以让定时任务更加自动化，无需手动点击发布按钮。

## 解决方案

### 1. 修改 Background 函数签名，添加 `isScheduledTask` 参数

在以下函数中添加 `isScheduledTask` 参数，用于标识是否来自定时任务：

- `handleInitiateProcess(platform, tabId, isScheduledTask = false)`
- `startArticleGenerationAndPublish(extraction, platform, isScheduledTask = false)`
- `handlePublishToToutiao(payload)` - payload 中添加 `isScheduledTask?: boolean`
- `handlePublishToZhihu(payload)` - payload 中添加 `isScheduledTask?: boolean`
- `handlePublishToWeixin(payload)` - payload 中添加 `isScheduledTask?: boolean`
- `handlePublishToXiaohongshu(payload)` - payload 中添加 `isScheduledTask?: boolean`

### 2. 在 Background 发布函数中设置 autoPublish

在各个平台的发布函数中，添加逻辑判断：
- 如果 `isScheduledTask === true`，则强制设置 `autoPublish = true`
- 否则使用全局设置 `settings.autoPublishAll`

```typescript
// 如果是定时任务，强制设置 autoPublish = true
const autoPublish = payload.isScheduledTask ? true : settings.autoPublishAll;
```

然后将 `autoPublish` 保存到 `pending_xxx_publish` 对象中，供 content script 读取。

### 3. 在 scheduler.ts 中传递标识

在定时任务执行时，调用 `handleInitiateProcess` 时传递 `isScheduledTask = true`：

```typescript
// 传递 isScheduledTask = true，标识这是定时任务，强制自动发布
await handleInitiateProcess(platform, tab.id!, true);
```

### 4. 修改 Content Script 读取 autoPublish

在各个平台的 content script 中，修改读取 `autoPublish` 的逻辑：
- 优先从 `pending` 对象中读取 `autoPublish` 字段（定时任务会强制设置为 true）
- 如果 `pending.autoPublish` 为 undefined，则默认为 true

```typescript
// 优先使用 pending 对象中的 autoPublish 标识（定时任务会强制设置为 true）
const autoPublish = pending.autoPublish !== undefined 
    ? pending.autoPublish  // 使用 pending 对象中的标识（定时任务强制为 true）
    : true;  // 默认开启自动发布
```

### 5. 更新 PublishData 接口

在各个平台的 content script 中，为 `PublishData` 接口添加 `autoPublish` 字段：

```typescript
interface PublishData {
  // ... 其他字段
  autoPublish?: boolean; // 是否自动发布（定时任务会强制设置为 true）
}
```

## 实现效果

- 定时任务生成的文章会自动发布，无需手动点击发布按钮
- 手动触发的发布流程仍然遵循全局"自动发布"设置
- 用户可以通过全局设置控制手动发布的行为，而定时任务始终自动发布

## 数据流程

1. 定时任务执行 → `scheduler.ts` 调用 `handleInitiateProcess(platform, tabId, true)`
2. `handleInitiateProcess` 调用 `startArticleGenerationAndPublish(extraction, platform, true)`
3. `startArticleGenerationAndPublish` 调用各平台发布函数，传递 `isScheduledTask: true`
4. 各平台发布函数根据 `isScheduledTask` 设置 `autoPublish = true`
5. `autoPublish` 保存到 `pending_xxx_publish` 对象中
6. Content script 从 `pending` 对象读取 `autoPublish`，执行自动发布

## 注意事项

1. 定时任务的自动发布是强制的，不受全局设置影响
2. 这样设计是为了让定时任务更加自动化，减少人工干预
3. 如果需要在定时任务中也支持手动发布，可以在定时任务配置中添加相应选项
4. Content script 默认 `autoPublish = true`，确保向后兼容

## 测试建议

3. 观察定时任务生成的文章是否自动发布
4. 手动触发发布流程，确认仍然遵循全局设置
