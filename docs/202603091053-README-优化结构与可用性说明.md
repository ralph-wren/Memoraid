# README 优化记录

## 背景

当前 `README.md` 存在以下问题：

- 信息量过大，首次阅读难以快速完成安装与配置。
- 功能点存在重复描述，重点不够聚焦。
- 截图 `alt` 文案重复，不利于阅读和维护。
- 权限表与 `src/manifest.ts` 存在不一致（例如 `notifications` 与 `scripting`）。

## 本次调整

1. 重排文档结构：前置入口链接与「30 秒快速开始」。
2. 压缩功能描述：从细项罗列改为能力级别概述。
3. 修复截图文案：统一并修正各截图的 `alt` 文本。
4. 对齐权限说明：以 `src/manifest.ts` 为准更新权限表。
5. 增加维护信息：补充「常用命令」与「项目结构」。

## 结果

- 新用户能更快完成首次安装和配置。
- 维护者更容易核对 README 与实际实现的一致性。
- 权限说明更准确，减少审核或沟通偏差。
