# 公众号图片 - 修复插入不稳定问题

## 问题描述
公众号发布时，图片插入不稳定：
- 有的地方图片没插入成功
- 有的地方插入了2张图片

## 问题原因

### 1. 占位符没有被删除
当前流程：
1. 选中占位符文本 `[图片: xxx]`
2. 打开图片对话框
3. 插入图片
4. **问题**：占位符文本还在编辑器中

结果：
- 图片插入到了占位符位置
- 但占位符文本没有被删除
- 下次循环可能还会找到同一个占位符，导致重复插入

### 2. 占位符和图片同时存在
- 插入图片后，占位符文本没有被删除
- 导致编辑器中同时存在占位符文本和图片
- 用户看到的是：`[图片: xxx] <图片>`

## 解决方案

### 1. 添加删除占位符函数
在 `src/content/weixin.ts` 中添加 `deletePlaceholderText` 函数：

```typescript
/**
 * 删除编辑器中的占位符文本
 * @param placeholderText 占位符文本（如 "[图片: xxx]"）
 * @returns 是否成功删除
 */
const deletePlaceholderText = (placeholderText: string): boolean => {
  const editor = findElement(SELECTORS.editor);
  if (!editor) return false;
  
  // 使用 TreeWalker 遍历所有文本节点
  const walker = document.createTreeWalker(
    editor,
    NodeFilter.SHOW_TEXT,
    null
  );
  
  let node: Text | null;
  while ((node = walker.nextNode() as Text | null)) {
    const text = node.textContent || '';
    const index = text.indexOf(placeholderText);
    
    if (index !== -1) {
      // 找到了占位符，删除它
      const range = document.createRange();
      range.setStart(node, index);
      range.setEnd(node, index + placeholderText.length);
      range.deleteContents();
      
      logger.log(`✅ 已删除占位符: ${placeholderText}`, 'success');
      return true;
    }
  }
  
  logger.log(`未找到需要删除的占位符: ${placeholderText}`, 'warn');
  return false;
};
```

### 2. 在插入图片后调用删除函数
修改 `generateAndInsertImageForPlaceholder` 函数，在插入图片成功后删除占位符：

```typescript
// 步骤6: 等待图片插入完成，弹窗会自动关闭
await new Promise(r => setTimeout(r, 1000));

// 步骤7: 删除占位符文本，避免重复处理和显示问题
if (!deletePlaceholderText(placeholder.text)) {
  logger.log('⚠️ 无法删除占位符文本，可能已被自动删除', 'warn');
}

logger.log(`占位符 "${placeholder.keyword}" 处理完成`, 'success');
return true;
```

## 效果
- 插入图片后，占位符文本会被自动删除
- 避免重复处理同一个占位符
- 避免占位符文本和图片同时显示
- 图片插入更加稳定可靠
