# 管理后台：订单审核改为支付记录展示

## 背景

支付链路已改为虎皮椒自动到账，管理员不再需要人工审核充值订单。

但管理后台订单页仍保留：

- “订单审核”命名
- “待审核订单”统计文案
- “通过 / 拒绝”操作按钮

这会让后台心智与实际业务流程不一致。

## 本次修改

已将管理后台订单区域改为只读展示：

1. 侧边栏名称从“订单审核”改为“支付记录”。
2. 统计卡片从“待审核订单”改为“待支付订单”。
3. 订单页标题从“订单审核”改为“支付记录”。
4. 状态筛选中的 `pending` 文案改为“待支付”。
5. 表格移除“操作”列。
6. 删除前端“通过 / 拒绝”按钮和对应的审核调用逻辑。
7. “支付方式”文案改为“支付渠道”。

## 结果

后台现在只承担支付记录查询和状态查看，不再暴露审核入口，和自动到账流程保持一致。
