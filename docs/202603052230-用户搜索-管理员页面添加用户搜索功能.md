# 管理员页面添加用户搜索功能

## 更新时间
2026年3月5日 22:30

## 功能描述
在管理员后台的用户管理页面,在"仅看付费用户"按钮旁边添加搜索框,支持按用户ID和邮箱前缀进行实时搜索。

## 实现内容

### 1. 后端API修改

#### 添加搜索参数支持
在 `GET /api/admin/users` 接口中添加 `keyword` 参数:

```typescript
const keyword = url.searchParams.get('keyword') || ''; // 搜索关键词
```

#### 修改查询逻辑
在SQL查询中添加WHERE条件,支持用户ID和邮箱前缀搜索:

```typescript
// 添加搜索条件：支持用户ID和邮箱前缀搜索
if (keyword.trim()) {
  query += ` WHERE (u.id LIKE '%${keyword}%' OR u.email LIKE '${keyword}%')`;
}
```

#### 修改总数统计
总数统计也需要考虑搜索条件:

```typescript
// 总数：需要考虑搜索条件和付费筛选
let totalQuery = 'SELECT COUNT(*) as total FROM users u';
if (keyword.trim() || paidOnly) {
  totalQuery = 'SELECT COUNT(*) as total FROM users u';
  const conditions = [];
  
  // 搜索条件
  if (keyword.trim()) {
    conditions.push(`(u.id LIKE '%${keyword}%' OR u.email LIKE '${keyword}%')`);
  }
  
  // 付费用户筛选
  if (paidOnly) {
    conditions.push(`EXISTS (SELECT 1 FROM payment_orders po WHERE po.user_id = u.id AND po.status IN ('paid', 'approved'))`);
  }
  
  if (conditions.length > 0) {
    totalQuery += ' WHERE ' + conditions.join(' AND ');
  }
}
```

### 2. 前端UI修改

#### 添加搜索框
在"仅看付费用户"按钮旁边添加搜索输入框:

```html
<!-- 工具栏：付费用户筛选按钮 + 搜索框 -->
<div style="margin-bottom:12px;display:flex;gap:12px;align-items:center">
```

#### 添加搜索状态变量
```javascript
let userSearchKeyword = ''; // 搜索关键词
```

#### 修改fetchUsers函数
在API请求中添加keyword参数:

```javascript
const params = new URLSearchParams({
    limit: usersLimit.toString(),
    offset: usersOffset.toString(),
    sort: userSort,
    order: userSortOrder,
    paid_only: userPaidOnly ? '1' : '0',
    keyword: userSearchKeyword // 添加搜索关键词参数
});
```

#### 添加搜索处理函数
实现实时搜索功能,带防抖优化:

```javascript
// 处理用户搜索（支持实时搜索）
let searchTimeout = null;
function handleUserSearch(event) {
    // 清除之前的定时器
    if (searchTimeout) {
        clearTimeout(searchTimeout);
    }
    
    // 获取搜索关键词
    const keyword = event.target.value.trim();
    
    // 延迟300ms执行搜索，避免频繁请求
    searchTimeout = setTimeout(() => {
        userSearchKeyword = keyword;
        fetchUsers(true); // 重置到第一页并搜索
    }, 300);
}
```

## 功能特点

1. **实时搜索**: 输入关键词后自动搜索,无需点击按钮
2. **防抖优化**: 延迟300ms执行搜索,避免频繁请求
3. **多字段支持**: 同时支持用户ID和邮箱前缀搜索
4. **组合筛选**: 可以与"仅看付费用户"筛选组合使用
5. **准确统计**: 搜索结果的总数统计准确反映筛选后的数量

## 搜索规则

- **用户ID搜索**: 模糊匹配,支持部分ID搜索
- **邮箱搜索**: 前缀匹配,输入邮箱开头即可搜索
- **大小写**: 不区分大小写(数据库默认行为)

## 使用示例

1. 搜索特定用户ID: 输入 `user_123`
2. 搜索邮箱前缀: 输入 `test` 可以找到 `test@example.com`
3. 组合筛选: 勾选"仅看付费用户" + 输入搜索关键词
