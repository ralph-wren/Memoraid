## 需求说明

根据用户反馈，调整额度扣除逻辑：

1. **优先扣除免费额度**，免费额度用完再扣除付费额度
2. **AI聊天不扣除额度**（已在之前修复）
3. **只有生成文章才扣除额度**，AI返回标题就算一篇（不管是否生成完毕或发布）
4. 匿名用户和登录用户逻辑一致

## 修改前的逻辑

```typescript
// 优先扣除付费额度，再扣除免费额度
if (paidQuota > 0) {
    const deductFromPaid = Math.min(paidQuota, newArticlesCount);
    await env.DB.prepare(
        'UPDATE user_quotas SET paid_quota_remaining = paid_quota_remaining - ? WHERE user_id = ?'

        }
    }

    // 全部从免费额度扣除
    for (let i = 0; i < newArticlesCount; i++) {
        await env.DB.prepare(
            'INSERT INTO ai_usage_logs (user_id, model) VALUES (?, ?)'
```

## 修改后的逻辑

```typescript
// 【修复2026-03-28】优先扣除免费额度，免费额度用完再扣除付费额度
if (freeRemaining > 0) {
    const deductFromFree = Math.min(freeRemaining, newArticlesCount);
    // 记录免费额度使用
    for (let i = 0; i < deductFromFree; i++) {
        await env.DB.prepare(
            'INSERT INTO ai_usage_logs (user_id, model) VALUES (?, ?)'
        ).bind(userId, 'article-generation').run();
    }
    console.log(`[Article Report] 已扣除免费额度: ${deductFromFree} 次`);
    
    const remainingToDeduct = newArticlesCount - deductFromFree;
    if (remainingToDeduct > 0) {
        // 免费额度不足，扣除付费额度
        await env.DB.prepare(
            'UPDATE user_quotas SET paid_quota_remaining = paid_quota_remaining - ? WHERE user_id = ?'
        ).bind(remainingToDeduct, userId).run();
        console.log(`[Article Report] 已扣除付费额度: ${remainingToDeduct} 次`);
    }
} else {
    // 免费额度已用完，全部从付费额度扣除
    await env.DB.prepare(
        'UPDATE user_quotas SET paid_quota_remaining = paid_quota_remaining - ? WHERE user_id = ?'
    ).bind(newArticlesCount, userId).run();
    console.log(`[Article Report] 已扣除付费额度: ${newArticlesCount} 次`);
}
```

## 修改效果

### 场景1：用户有免费额度和付费额度

假设用户有：
- 免费额度：20次（已使用0次，剩余20次）
- 付费额度：10次

生成1篇文章后：
- 免费额度：20 → 19次（扣除1次）
- 付费额度：10 → 10次（不变）

### 场景2：用户免费额度用完

假设用户有：
- 免费额度：20次（已使用20次，剩余0次）
- 付费额度：10次

生成1篇文章后：
- 免费额度：0 → 0次（不变）
- 付费额度：10 → 9次（扣除1次）

### 场景3：用户免费额度不足

假设用户有：
- 免费额度：20次（已使用19次，剩余1次）
- 付费额度：10次

生成2篇文章后：
- 免费额度：1 → 0次（扣除1次）
- 付费额度：10 → 9次（扣除1次）

## 完整的额度扣除流程

### 1. AI聊天（不扣除额度）

```typescript
// backend/src/index.ts 第3655-3670行
if (trackingType === 'user') {
    // 登录用户：AI聊天不记录使用，额度将在文章报告时统一扣除
    console.log(`[AI Chat] 用户 ${userId} AI聊天成功，额度将在文章报告时扣除`);
} else {
    // 匿名用户：记录免费额度使用（匿名用户没有文章上报功能）
    await env.DB.prepare(
        'INSERT INTO ai_usage_logs (anonymous_id, model) VALUES (?, ?)'
    ).bind(anonymousId, body.model).run();
}
```

### 2. 文章生成（AI返回标题就扣除）

前端在AI生成文章后（有标题后）调用 `reportArticlePublish`：

```typescript
// src/background/index.ts 第1183-1196行
const generatedId = await reportArticlePublish({
  platform: 'memoraid',
  title: newTitle,
  status: 'generated',  // 状态为 generated
  summary: refinedContent.substring(0, 200),
  extra: {
    sourceUrl: '',
    sourceTitle: title || 'Untitled Chat',
    promptTokens: tokenUsage?.promptTokens,
    completionTokens: tokenUsage?.completionTokens,
    totalTokens: tokenUsage?.totalTokens,
  }
});
```

### 3. 文章上报（后端扣除额度）

后端接收到文章上报请求后：

1. 检查文章是否已存在（去重）
2. 如果是新文章，优先扣除免费额度
3. 免费额度不足时，扣除付费额度

## 数据库结构

### ai_usage_logs 表（记录免费额度使用）

```sql
CREATE TABLE ai_usage_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT,
  anonymous_id TEXT,
  model TEXT,
  created_at INTEGER DEFAULT (strftime('%s', 'now'))
);
```

### user_quotas 表（记录付费额度）

```sql
CREATE TABLE user_quotas (
  user_id TEXT PRIMARY KEY,
  paid_quota_remaining INTEGER DEFAULT 0,
  free_quota_remaining INTEGER DEFAULT 0,
  updated_at INTEGER DEFAULT (strftime('%s', 'now'))
);
```
