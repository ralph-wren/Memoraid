## 需求说明

优化管理后台用户列表的额度显示：

1. **免费额度**：显示为"剩余/总额度"格式（如 3/5）
2. **付费额度**：显示为"剩余/总充值"格式（如 8/10）
3. **累计文章**：新增列，显示用户累计生成的文章总数
4. **数据一致性**：如果付费额度数据不一致，显示警告图标

## 修改内容

### 1. 表头修改

```html
<th title="免费额度：剩余/总额度">免费额度</th>
<th title="付费额度：剩余/总充值">付费额度</th>
<th title="累计生成的文章总数">累计文章</th>
```

### 2. SQL查询修改

添加 `paid_quota_total` 字段，统计用户累计充值的总额度：

```sql
-- 【新增2026-03-28】付费总额度：累计充值的总额度
(SELECT COALESCE(SUM(quota_amount), 0) 
 FROM payment_orders po 
 WHERE po.user_id = u.id 
 AND po.status IN ('paid', 'approved')) as paid_quota_total
```

### 3. 前端显示逻辑修改

**核心逻辑**：按照实际生成的文章数来计算额度使用，而不是按照 `ai_usage_logs` 的记录。

```javascript
// 【修改2026-03-28】按照实际生成的文章数来计算额度使用
const totalArticles = u.total_articles || 0;
const paidTotal = u.paid_quota_total || 0;
const paidRemaining = u.paid_quota_remaining || 0;
const paidUsed = paidTotal - paidRemaining;

// 优先使用免费额度，再使用付费额度
let freeUsed = 0;
let actualPaidUsed = 0;

if (totalArticles <= limit) {
    // 文章数未超过免费额度，全部算免费
    freeUsed = totalArticles;
    actualPaidUsed = 0;
} else {
    // 文章数超过免费额度，超出部分算付费
    freeUsed = limit;
    actualPaidUsed = totalArticles - limit;
}

const freeRemaining = Math.max(0, limit - freeUsed);
const freeQuotaText = `${freeRemaining}/${limit}`;

// 付费额度：如果实际使用超过了付费总额度，显示负数
const actualPaidRemaining = paidTotal - actualPaidUsed;
const paidQuotaText = `${actualPaidRemaining}/${paidTotal}`;
```

## 显示效果

### 场景1：免费用户，未超额

- 用户生成了 3 篇文章
- 免费额度：2/5（剩余2次，总共5次）
- 付费额度：0/0（没有充值）
- 累计文章：3

### 场景2：免费用户，超额使用

- 用户生成了 7 篇文章（超过免费额度5次）
- 免费额度：0/5（已用完，显示红色）
- 付费额度：0/0（没有充值）
- 累计文章：7

**注意**：免费用户超额使用不进行修复，按实际显示。

### 场景3：付费用户，正常使用

- 用户生成了 25 篇文章
- 免费额度：0/20（已用完）
- 付费额度：5/10（剩余5次，总充值10次）
- 累计文章：25

计算：
- 免费额度使用：20次（已用完）
- 付费额度使用：25 - 20 = 5次
- 付费额度剩余：10 - 5 = 5次

### 场景4：付费用户，数据不一致

- 用户生成了 25 篇文章
- 数据库记录：`paid_quota_remaining = 8`（应该是5）
- 免费额度：0/20
- 付费额度：8/10 ⚠️（显示警告图标）
- 累计文章：25

**警告提示**：数据不一致：实际使用 5 次，记录使用 2 次

## 数据一致性检查

系统会自动检查付费额度的数据一致性：

```javascript
// 实际使用的付费额度
const actualPaidUsed = totalArticles > limit ? totalArticles - limit : 0;

// 数据库记录的已使用付费额度
const paidUsed = paidTotal - paidRemaining;

// 检查是否一致
const dataConsistent = actualPaidUsed === paidUsed;
```

如果不一致，会在付费额度列显示警告图标 ⚠️，鼠标悬停可以看到详细信息。

## 额度扣除规则

1. **优先扣除免费额度**：前 N 篇文章（匿名用户5篇，登录用户20篇）使用免费额度
2. **再扣除付费额度**：超过免费额度的文章使用付费额度
3. **免费用户超额**：如果免费用户生成的文章超过免费额度，不进行修复，按实际显示
